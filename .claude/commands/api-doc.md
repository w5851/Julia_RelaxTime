# API 文档编写

## 三层视图（必须）

1. **面向用户入口** — 统一入口、主工作流、最短可运行示例。
2. **职责核心** — 关键算法、判据、数据流、模块职责边界。
3. **导出 API 全集** — 脚本自动生成，禁止人工维护。

## 文件布局

- 默认落点 `docs/api/`。
- 小模块三层同页；中大型模块拆为多页或主题子目录。
- `导出 API 全集` 通过 `scripts/dev/generate_api_export_index.jl` 生成。

## 入口判断启发

**面向用户入口（信号越强越靠前）：**
- 出现在顶层聚合模块 `export` 中。
- 被 README / Quickstart / HTTP 接口 / 脚本示例直接调用。
- 能完成完整任务闭环。

**职责核心：**
- 被多个上层入口复用。
- 直接实现关键物理/数值判据或算法分支。
- 在测试中以 algorithm/core/maxwell/cep 等关键词直接验证。

## 质量检查
- 人工维护页不手工列全导出符号。
- 若存在 facade 与底层实现并存，优先强调 facade。
- 正在替代旧页面时，把旧页有价值说明吸收入新页。
- 实验性接口显式标注稳定性。
