# 研究工程决策

## 适用场景
- 比较竞争方法或模型。
- 需要证据支撑的实现选择。
- 将文献/基准证据转化为具体工程或计算步骤。

## 研究协议
1. 定义范围：领域、假设、约束、成功标准。
2. 构建检索计划：关键词、变体、排除项。
3. 收集来源：优先同行评审和权威材料。
4. 评估质量：方法论、可复现性、时效、相关性。
5. 综合：共识、分歧、缺口、实际影响。

## 证据标准
- 区分既定事实与假设。
- 显式标记不确定声明。
- 快速发展领域优先选择近期来源。
- 高亮可复现信号（代码/数据可用性、基准质量）。

## 输出模板
```
## Executive Summary (3-6 条结论 + 置信度)
## Method Comparison (假设/优势/局限/计算成本/适用性)
## Recommended Path (短期可执行步骤 + 验证计划 + 风险与回退)
## Source Notes (编号来源 + 一行可信度备注)
```
