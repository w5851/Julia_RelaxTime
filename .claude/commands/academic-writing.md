# 学术写作

## 协作写作流程
1. 上下文捕获：读者、目的、约束、期望决策。
2. 结构设计：章节大纲 + 每节验收标准。
3. 逐节起草：显式声明和证据。
4. 精炼：消除歧义、收紧逻辑、统一术语。
5. 读者检查：模拟读者问题，修补薄弱点。

## 反"AI 腔调"规则
- 变化句式节奏和从句结构。
- 用内容相关的过渡替换通用过渡词。
- 用精确动词和具体名词替代模糊抽象。
- 删除冗余元短语和空洞强调词。
- 声明强度与证据强度匹配。

## 学术质量规则
- 开头声明贡献与范围。
- 区分方法、结果与解读。
- 显式报告局限性与假设。
- 符号和术语跨章节保持一致。

## 各章节指南
- Abstract: problem, method, key result, significance
- Introduction: motivation, gap, contribution map
- Methods: reproducible pipeline + parameter choices
- Results: objective findings before interpretation
- Discussion: implications, limitations, future work

## 输出模式
修改文本时输出：修订版、关键改动与理由、可选表达方案。
