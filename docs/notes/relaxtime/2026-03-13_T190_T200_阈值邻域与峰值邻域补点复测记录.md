# T190/T200 阈值邻域与峰值邻域补点复测记录（2026-03-13）

## 1. 问题拆分与判据

- 理论边界：`s_bo`，由入射/出射质量决定的动力学下边界。
- 数值峰位：`s_peak`，当前缓存采样点上 `sigma(s)` 最大值位置。
- 诊断量：`s_peak - s_bo`。

解释：
- 当 `s_peak - s_bo` 很小（贴近 0）时，属于阈值邻域敏感问题（T200 典型）。
- 当 `s_peak - s_bo` 显著大于 0 且峰值很高时，属于远离阈值的共振尖峰问题（T190 典型）。

## 2. 已实现规则

- 阈值邻域分层补点（已在主线启用）：在 `s_bo` 附近按层补点，改善阈值贴边时插值稳定性。
- 峰值邻域补点（已实现为触发式函数）：仅在峰值足够高且远离阈值时，围绕峰值窗口补点。

## 9. T190 深层根因分析（2026-03-14）

### 9.1 复现方式

- 使用固定态 probe，冻结 `T=190 MeV, muB=0` 对应平衡态，只改变 `xi` 进入输运核：
  - 粗扫输出：
    - `data/outputs/results/relaxtime/scan/_xi_probe_T190_tmp_summary.csv`
    - `data/outputs/results/relaxtime/scan/_xi_probe_T190_tmp_channels.csv`
    - `data/outputs/results/relaxtime/scan/_xi_probe_T190_tmp_switchlog.csv`
  - 细扫输出（`xi=-0.448:-0.002:-0.432`，仅保留主导通道）：
    - `data/outputs/results/relaxtime/scan/_xi_probe_T190_fine_summary.csv`
    - `data/outputs/results/relaxtime/scan/_xi_probe_T190_fine_channels.csv`
    - `data/outputs/results/relaxtime/scan/_xi_probe_T190_fine_switchlog.csv`

### 9.2 已确认的根因

- 该异常**不是**平衡态求解器或 phase seed 切换造成的：固定态 probe 在冻结 `masses/Phi/densities` 后，T190 爆点依然存在。
- 该异常主要来自**少数通道的 `sigma(s)` 共振峰分支切换**，而不是所有通道一起抖动：
  - `adaptive=true, sigma_grid_n=256` 时，`xi=-0.44` 的总 `tauinv_u` 爆到 `2.39e6`；
  - 其中 `uu_to_uu` 单通道贡献约 `2.39e6`，几乎独占总量；
  - 相邻点 `xi=-0.442/-0.438` 时，同一通道只在 `O(10~40)`，说明不是密度或整体尺度平滑放大。
- 细扫 switchlog 表明，问题点附近的**主导峰位置会突然换支**：
  - `uu_to_uu` 在 `xi=-0.442` 时峰位 `s_peak≈1.43`，到 `xi=-0.44` 跳到 `s_peak≈5.84`，下一点 `xi=-0.438` 又回到 `s_peak≈0.95`；
  - `ud_to_ud` / `uubar_to_ddbar` 也在邻域内出现类似的峰族切换，只是严重度低于 `uu_to_uu`。
- 因此，T190 的核心不是“T200 那种阈值贴边欠分辨”，而是：
  - **远离阈值的高窄峰在不同 `xi` 上会切换为不同峰族；**
  - 当前 cache 构造按“全局最大峰”触发自适应/局部补点，会把某个单点命中的超窄峰过度放大；
  - 结果是 `tauinv(xi)` 在单点上出现非物理的孤立爆点。

### 9.3 解决方案建议

- 低风险主线方案：
  1. **保留现有峰宽/spacing 门控**，继续作为 T200 防回归护栏；
  2. 对 T190 类远峰通道新增**峰族稳定性门控**，不要再只看单点 `argmax(sigma)`：
     - 若当前候选峰相对主阈值 `s_bo` 远离，且 `s_peak` 相对邻近局部峰族发生大幅跳支；
     - 或峰虽很高但局部面积/权重贡献不足，仅表现为“极窄高针”；
     - 则禁止该峰进入激进局部补点路径，回退到更保守的 cache。
  3. 将“是否触发峰值补点”的判据从“峰高”升级为“峰高 + 峰宽 + 局部面积/权重 + 峰位连续性”。
- 更具体的工程实现建议：
  - 在 `AverageScatteringRate.jl` 的 resonance-layer 触发前增加一个 `peak_stability_metrics`：
    - 记录前两大局部峰的 `s_peak`, `sigma_peak`, `fwhm`, `area_estimate`；
    - 若全局最大峰与次大峰高度接近、但峰位相距很远且 FWHM 极窄，则判为“不稳定峰族竞争”，跳过局部加密；
    - 对最终触发峰，要求 `area_estimate / total_area` 或 `weighted_area / total_weighted_area` 超过最小阈值。
  - 对 `uu_to_uu`, `ud_to_ud`, `uubar_to_ddbar` 这类已知问题通道，优先接入该门控，避免扩大影响面。
- 不推荐的路线：
  - 不要恢复“自适应后二次峰值补点”；已有证据表明这会进一步放大 T190 尖峰。
  - 不要直接刷新当前 T190 回归夹具；在接受新的稳定性判据前，现有 `_xi_probe_T190_summary.csv` 仍应保留为告警基线。

## 10. 2026-03-14 补充：异常主因进一步收敛到 adaptive midpoint refine

### 10.1 新证据

- 先尝试了“峰族竞争门控”原型，但定向核查 `uu_to_uu` 后发现：
  - 即使显式关闭 `resonance_layering`，`xi=-0.44` 处缓存主峰和 `rate` 仍保持不变；
  - 说明当前爆点**并不是** resonance-layer 局部补点触发出来的主回归路径。
- 对 `uu_to_uu` 的缓存主峰邻域直接检查可见：
  - `s_peak≈1.4252669290569004`；
  - 峰点 `sigma≈4.095365009649357e10`；
  - 两侧相邻点只有 `O(10^3)`；
  - 这是一个由单个采样点命中的极窄高针，而不是被局部 layering 新加密出来的宽峰。
- 因而本轮将根因进一步收敛为：
  - **adaptive refinement 在区间中点追误差时，会把远离阈值的孤立超高针当作“必须细化”的目标；**
  - 一旦中点正好命中该针，cache 会把该点保留下来，并通过 PCHIP 插值把其影响传播到 ω 积分；
  - 这就是 T190 在个别 `xi` 上出现孤立爆点的更直接数值来源。

### 10.2 本轮低风险实现

- 在 `AverageScatteringRate._adaptive_refine_sigma_samples` 中新增保守门控：
  - 若某个自适应中点样本同时满足
    - 远离阈值：`midpoint - s_th > isolated_peak_min_gap`；
    - 且实际值相对插值预测值异常大：`actual / predicted >= isolated_peak_ratio`；
  - 则视为“孤立高针”，跳过该中点加密，不把它写回 cache。
- 当前默认参数取值：
  - `isolated_peak_ratio = 1e6`
  - `isolated_peak_min_gap = 0.2`
- 设计意图：
  - 只拦截像 T190 这类“中点偶然命中的超窄离群针”；
  - 不改变 T200 的阈值邻域主路径，也不依赖额外的多峰识别逻辑。

## 11. 2026-03-15 补充：三层方案 A 已实现并完成最小复现

### 11.1 A 的实现内容

- 已将 adaptive refine 的误差判据从“点值误差优先”切到“区间贡献误差优先”：
  - 对每个区间 `[s_i, s_{i+1}]`，不再只看 `|σ(mid)-σ_interp(mid)|`；
  - 改为比较粗/细两级梯形-中点分裂后，对该区间面积的贡献差：
    - `coarse_contribution = 0.5 * Δs * (σ_i + σ_{i+1})`
    - `split_contribution = 0.25 * Δs * (σ_i + 2σ_mid + σ_{i+1})`
    - `contribution_err = |split_contribution - coarse_contribution|`
- 当候选点数量超过预算时，优先按 `contribution_err` 排序，而不是按点值误差排序。
- 这样做的目的，是让 refinement 更接近“积分收敛”目标，而不是盲目追峰顶高度。

- 仅仅全局增大 `n_points` 不是理想主线：

- 当前更合理的低风险方向应转到 `TotalCrossSection.jl`：
  1. 在 `t` 积分内做**局部异常检测**（如相邻节点 `dσ/dt` 比值、单点贡献占比、`π` 分母接近零）；
  2. 只对可疑子区间做**局部细分/递归积分**，而不是全局抬高 `n_points`；
  3. 必要时对近极点小窗做单独积分并与平滑区分开；
  4. 若后续证实局部自适应仍不稳，再考虑显式变量变换或对分母零点附近做解析型处理。
- 在这些证据补齐前，当前最稳妥的生产状态仍应保持在 **A 主线**，不要把 B/C 重新并回生产 cache。

### 15.7 关于“`t` 积分本身是否理论收敛”的当前判断

- 我进一步检查了峰心附近 `π` 传播子分母的局部标度。
- 对 `xi=-0.44`、`s0≈1.4252669290569004`：
  - 可通过二分法找到 `1 - 4K123_plus Π_pi(t) = 0` 的零点，约在
    `t0≈-0.18134424511971287`；
  - 在该点附近，分母实部呈线性过零，斜率约为 `-1.147337e-1`；
  - 同时 `dσ/dt` 满足
    `h^2 * dσ/dt(t0 ± h) ≈ 常数 ≈ 8.33e-3`
    （在 `h=10^-3,10^-4,10^-5,10^-6` 上都基本稳定）。
- 这意味着在当前**零宽度**实现下：
  - `D_pi ~ 1 / (t - t0)`；
  - `|D_pi|^2 ~ 1 / (t - t0)^2`；
  - `dσ/dt` 因而表现为 `1 / (t - t0)^2` 型奇性。
- 而 `1 / (t - t0)^2` 在穿越极点的实轴积分上是**不可积**的；对应地，
  对称挖去小窗后的积分满足 `excluded_integral(δ) ~ C / δ`，数值上也已观察到
  `δ * excluded_integral(δ)` 近似趋于常数。
- 因此，当前证据更支持如下判断：
  1. 在现有零宽度传播子模型里，这个 `t` 积分**不是“理论上有限、只是固定节点没算准”**；
  2. 它更像是一个真实的非可积近极点，需要**物理或数值上的额外正则化/展宽定义**后，才有有限可比较的“收敛值”；
  3. `MesonPropagator.jl` 里的 `PROPAGATOR_DENOM_EPS=1e-12` 只能避免恰好除零导致的 NaN/Inf，**不能**把该实轴积分变成稳定、与节点无关的有限积分。
- 这会直接影响下一阶段路线选择：
  - 如果目标是“逼近理论有限真值”，那必须先明确**理论上采用哪种宽度/主值/复平面处方**；
  - 如果暂时只想稳定生产数值，则需要承认当前是在对一个本来发散的 integrand 做**工程正则化**，而不是单纯提高数值积分精度。

## 16. 2026-03-15 补充：理论处方梳理（含“极点两侧能否抵消”）

### 16.1 先回答一个关键问题：线性过零的分母，左右两侧能否互相抵消？

- 对当前这里的量，**基本不能**。
- 原因不是分母本身，而是我们最后积分的对象是 `dσ/dt`：
  - 主导项来自 `M_t_squared ∝ |D_t_P|^2`；
  - 若 `D_t_P ~ 1 / (t - t0)`，则 `|D_t_P|^2 ~ 1 / (t - t0)^2`；
  - `1 / (t - t0)^2` 在极点两侧同号，面积都为正，因此不存在 Cauchy 主值意义下的左右抵消。
- 数值证据也一致：
  - `h^2 * dσ/dt(t0-h)` 与 `h^2 * dσ/dt(t0+h)` 都趋于同一个正数 `≈ 8.33e-3`；
  - 说明两侧发散强度相同且同号。
- 只有在**振幅本身**或某些奇核积分里，才可能出现 `1 / (t - t0)` 型奇性并通过主值积分发生左右抵消；
  但当前我们积分的是近似正定的截面 integrand，不是那一类对象。

### 16.2 可选理论处方一览

#### A. 给传播子引入有限宽度（最物理、也最贴近当前代码基础）

- 核心思想：把零宽度极点改成复极点，例如
  `1 - 4KΠ -> 1 - 4KΠ_re - i * 4KΠ_im`，或等价地把介子极点写成 `p0 = M + iΓ/2`。
- 物理含义：
  - 共振态不是严格稳定粒子，而有有限寿命/谱宽；
  - 原本的 `δ` 型或 `1/(t-t0)^2` 型尖峰会被展宽成有限面积的峰。
- 在本仓库中的现有基础：
  - `src/relaxtime/PolarizationAniso.jl` 已有 `polarization_with_width(...)`；
  - `src/relaxtime/MesonMass.jl` 已能解 `(mass, gamma)` 极点方程。
- 对数值实现的影响：
  - 这是最自然能把当前发散积分变成有限积分的方案；
  - 若 `Γ` 有了明确定义，`t` 积分就变成“解析上有限、数值上可收敛”的问题；
  - 然后才值得讨论局部自适应积分如何高效逼近有限峰面积。
- 风险：
  - 必须先明确：传播子里用的 `Γ` 来自哪里（极点方程自洽求解、阈值模型、常数展宽、还是经验参数）；
  - 一旦引入宽度，会系统性改变所有接近共振的截面，不只是 T190 这一个点。

#### B. 采用 `iε` / 复平面处方，并保留有限 `ε` 作为正则化

- 核心思想：把极点从实轴轻微推开，例如 `t0 -> t0  b1 iε`。
- 物理含义：
  - 严格的 `ε -> 0+` 更多是因果边界条件，不等于真实物理宽度；
  - 若最后保留有限 `ε`，本质上还是一种展宽/正则化模型。
- 数值实现的影响：
  - 与有限宽度方案很接近；
  - 但 `ε` 的物理解释通常弱于 `Γ`。
- 风险：
  - 如果 `ε` 只是为了数值稳定而选，最终结果会显式依赖 `ε`，需要把它当作模型参数而不是积分误差。

#### C. 主值积分（PV）

- 核心思想：对 `1 / (x-x0)` 型奇核取 Cauchy principal value。
- 本仓库的现有基础：
  - `src/integration/CauchyPV.jl` 已有 `cpvi`；
  - `docs/api/integrals/CauchyPV.md` 也写明了 Plemelj 公式。
- 但对当前问题的适用性有限：
  - PV 适合处理**线性奇核** `1/(t-t0)`；
  - 当前主导发散来自 `|D|^2 ~ 1/(t-t0)^2`，不是 PV 可抵消的对象。
- 因此：
  - PV 更适合放在极化函数/B0 那一层处理一次极点；
  - 不适合直接拿来给当前 `dσ/dt` 的二次极点“做消发散”。

#### D. 谱函数/Lehmann 表示（最系统，但工程量最大）

- 核心思想：不用裸传播子实轴极点，而用具有有限谱密度的传播子表示共振。
- 物理含义：
  - 截面由谱分布卷积得到，天然避免零宽度极点导致的不可积尖峰。
- 数值实现的影响：
  - 理论上最干净；
  - 但需要重构传播子层甚至更上游的数据流，不适合作为当前主线的首选低风险路线。

#### E. 纯工程 cutoff / clipping / exclusion window（仅工程正则，不建议当物理解）

- 核心思想：人为裁掉极点附近窗口，或限制 `σ/M²/D` 的最大值。
- 优点：
  - 实现最快，能立刻压住生产爆点。
- 缺点：
  - 缺乏明确物理意义；
  - 结果依赖窗口大小/截断阈值，难以解释为“收敛到真值”。
- 当前定位：
  - 可作为临时护栏；
  - 不应作为“证明 T190 跳变物理可接受”的证据来源。

### 16.3 结合当前仓库，最现实的优先级判断

- **最高优先级候选：有限宽度/复极点处方。**
  - 原因：仓库已经有 `polarization_with_width` 和 `solve_meson_mass(..., gamma)` 基础；
  - 这条路线最有希望把“当前无有限真值”的问题，转换成“有有限真值、再做高效积分逼近”的问题。
- **不建议把 PV 作为当前主解。**
  - 因为当前发散对象不是一次奇核，而是截面层的平方极点。
- **纯工程 clipping 只能算护栏，不算理论闭环。**

### 16.4 下一阶段建议

- 若继续深挖，最合适的顺序应是：
  1. 先明确 `Γ`/宽度的理论来源与作用层级；
  2. 再评估如何把宽度接入 `TotalPropagator` / `MesonPropagator` 的截面链路；
  3. 只有在有限宽度模型确定后，才继续设计 `t` 积分的高性能局部自适应算法。

## 17. 2026-03-15 补充：这种发散会不会在后续平均中被“小权重”抵消？

### 17.1 结构上基本不会被后续步骤抵消

- `average_scattering_rate` 的核心结构是
  `ω = ∫ w0(p_i,p_j,Ω_i,Ω_j,φ) * σ(s) dΠ`，最终再乘上有限归一化因子
  `DQ^2 / (32π^5 ρ_i ρ_j)`。
- 在当前实现里：
  - `w0` 由分布函数、相对速度、相空间 Jacobian 和求积权重组成；
  - 这些量在有效区间内都是**非负**的；
  - `σ(s)` 也是非负的（`M_squared`、`dσ/dt`、blocking factor` 都被夹到 `>=0`）。
- 因此后续 `ω` 积分不是带正负号振荡的积分，而是**非负量的累加**；
  不存在“发散尖峰在后续步骤靠符号抵消掉”的机制。

### 17.2 只有两种可能让后续结果不发散

- 对当前链路来说，只可能有两种“看起来没炸”的原因：
  1. **发散集合是测度零**，后续相空间积分几乎碰不到；
  2. **数值流程没有解析到发散**，把它当成了有限尖峰或直接错过。
- 第一种若成立，后续平均也许能天然有限；
  但本轮新证据更支持第二种，而不是第一种。

### 17.3 为什么这里更像“发散会传播”，而不是“权重太小所以被压住”

- 我额外检查了 `xi=-0.44`、`uu_to_uu`、`π` 分母过零是否只发生在孤立 `s0`：
  - 在 `s=1.41, 1.42, 1.423, 1.424, 1.425, 1.425266929..., 1.426, 1.427, 1.43, 1.44`
    这些点上，都能在对应 `t` 区间内找到 `1 - 4KΠ_pi = 0` 的过零；
  - 这表明不是只有单个 `s0` 才发散，而是**一段有限的 `s` 区间内，`t` 积分都存在实轴极点**。
- 只要后续相空间权重在这段 `s` 区间上不是严格为零，`ω` 就没有天然“自动收敛”的理由。

### 17.4 相空间权重虽小，但不是零

- 我用 `w0cdf` 设计所对应的相空间采样粗估了 `s0≈1.4252669290569004` 附近的权重分布：
  - `|s-s0| <= 1e-2` 时，累计权重分数约 `1.94e-5`；
  - `|s-s0| <= 5e-2` 时，累计权重分数约 `1.35e-3`；
  - `|s-s0| <= 1e-1` 时，累计权重分数约 `6.61e-3`。
- 这说明该区间的相空间权重**确实不大，但明确非零**。
- 对有限尖峰来说，小权重只会“压低影响系数”；
  但对当前这种 pointwise 发散的 `σ(s)` 来说，小但非零的正权重并不能把发散变成有限值。

### 17.5 因而当前最合理的判断

- 在现有零宽度实现下，若把 `σ(s)` 当作严格数学对象：
  - 这类发散**原则上会向后传播到 `ω`，进而传播到 `τ^-1`**；
  - 后续平均步骤没有提供符号抵消或主值消发散的机制。
- 现在生产链路里之所以还会得到“看似有限”的 `τ^-1`：
  - 更像是因为 `w0cdf + cache + PCHIP + 有限点 t 积分` 把原本的非可积结构投影成了一个**有限但强烈依赖采样的数值尖峰**；
  - 这是数值下采样/错峰/截断后的工程性有限值，不是理论上已经被后续平均自然正则化了。

## 18. 2026-03-15 补充：能否把 `σ(s)` 中所有远离阈值峰都归因为这类 `t` 积分发散？是否都等同于 Mott？

### 18.1 当前不能作出“所有远峰都由这同一种机制导致”的断言

- 对当前已深入诊断的 T190 / `uu_to_uu` 个案，证据很强：
  - 主导峰确实来自 `t` 道赝标量传播子分母过零；
  - 其后果是 `dσ/dt` 出现 `1/(t-t0)^2` 型非可积奇性。
- 但对**所有** `σ(s)` 中远离阈值的峰，当前还不能统一断言都是同一种机制。
- 原因是远峰至少可能来自几类不同来源：
  1. `t/u/s` 任一散射道传播子接近极点，但仍是**有限宽/有限面积**的共振峰；
  2. 像当前 `uu_to_uu` 这样，零宽度传播子在物理积分区间上真正过零，导致 **`t` 积分本身发散**；
  3. 不同传播子项与交叉项的峰族竞争，造成 cache 中 `argmax(σ)` 的切换；
  4. 数值层的欠分辨 / 插值放大，把本来有限但很窄的结构投影成异常高针。
- 因而目前更稳妥的说法是：
  - **当前已经确认存在一类“远离阈值峰”确实由 `t` 积分非可积极点导致；**
  - **但还没有证据表明所有远峰都必须归入这一类。**

### 18.2 当前个案与 Mott 的关系：有关联，但不能直接等同

- 仓库内关于 Mott 的标准定义是：
  - 当介子质量满足 `M_M = M_{q1} + M_{q2}` 时，介子从束缚态进入可衰变共振态；
  - 之后宽度 `Γ` 从 `0` 变为非零。
- 这一定义对应的是**timelike 零动量极点**：
  - 例如 `MesonMass_RPA_Pole.md` 中的
    `1 - 4K Π(M + iΓ/2, 0) = 0`；
  - 以及 `MottTransition.md` 中的 `M_M = M_q + M_q` 判据。

### 18.3 当前 `uu_to_uu` 奇点更直接地说是“spacelike t-道传播子零点”，而不是标准 Mott 点本身

- 对当前 `uu_to_uu` 个案，关键量是 `t` 道交换：
  - `k0 = |E1 - E3| = 0`
  - `k = sqrt(-t)`
- 对相同夸克质量的 `uu_to_uu` 而言，`t` 道传播子的赝标量分母在固定 `t` 下几乎只依赖 `k = sqrt(-t)`；
  也就是说，这个奇点本质上是 **`k0=0`、spacelike 动量转移**上的传播子零点。
- 而标准 Mott 判据描述的是：
  - `k=0`、`p0 = M + iΓ/2` 的 timelike 介子质量极点是否越过夸克对阈值。
- 所以：
  - **当前奇点不能简单地说“就是 Mott 点”**；
  - 更准确地说，它是**零宽度传播子在散射运动学区域出现的实轴极点/零点**。

### 18.4 那它与 Mott 完全无关吗？也不能这么说

- Mott 进入后的一个核心物理后果是：
  - 介子不再是严格稳定束缚态，应该获得有限宽度 `Γ > 0`；
  - 这会把传播子极点从实轴推离，从而把当前零宽度模型里的实轴奇点展宽为有限峰。
- 因此 Mott 与当前问题的关系更像：
  - **Mott/共振化告诉我们“零宽度假设何时开始失真”；**
  - **而当前发散则是这种失真在散射 `t` 通道里的一个具体后果。**
- 换句话说：
  - Mott 不是当前 spacelike `t` 奇点的同义词；
  - 但 Mott 区域意味着“应该开始出现非零宽度”的物理信息，这正是后续正则化该奇点最自然的来源。

### 18.5 当前最稳妥的结论

- 现在可以较强地说：
  1. **T190 / `uu_to_uu` 的已诊断主峰，确实属于 `t` 道零宽度传播子在物理积分区间过零导致的发散型机制；**
  2. **这类机制不能简单等同为标准 Mott 判据本身；**
  3. **但它很可能发生在“零宽度近似本应被 Mott 后有限宽度修正取代”的区域。**
- 现在还不能说：
  - `σ(s)` 里所有远离阈值峰都必然由这种 `t` 积分发散机制产生；
  - 或者它们都可以直接贴上“就是 Mott 峰”的标签。

## 19. 2026-03-15 补充：代表性远峰分类验证（发散型 vs 有限共振峰）

  - 这些异常过程都落入“**零宽度传播子在散射运动学区出现近实轴极点**”的大类；

    - `uu_to_uu`：单一 `t` 道赝标量主导；
    - `uubar_to_ddbar`：qqbar 过程，但主异常仍由 `t` 道主导；
    - `ud_to_ud`：`t/u` 两道都可能参与，峰族竞争更强。

  但与 `ss_to_ss/us_to_us/ssbar_to_ssbar` 这类稳定对照相比，它显然不属于“有限平滑峰”。
- 因而：
  - **仓库里的远峰至少可以分成两大类**：
    1. 有限、稳定的共振峰；
    2. 零宽度近极点导致的强节点敏感峰（其中有的已经表现为实质发散型）。

### 19.6 对“是否都是 Mott 导致”的进一步修正

- 从这组分类验证看，更稳妥的判断是：
  - **并不是所有远峰都由 Mott 后的零宽度失真触发；**
  - 因为稳定对照组表明，远峰也可以只是普通有限共振增强。

  - 它们都表现出“零宽度传播子在散射 kinematics 区域过于尖锐甚至实轴过零”的共同特征；

  - **但对发散型远峰，Mott 后应引入有限宽度这件事，很可能正是消除其零宽度病态的物理依据。**

## 20. 2026-03-15 补充：第二轮分类验证——按通道与极点标度细分子类型

- 到目前为止，代表性异常峰至少可以进一步分成三类：
  1. **稳定有限共振峰**：如 `ss_to_ss`、`us_to_us`、`ssbar_to_ssbar`；
  2. **单一 `t` 道平方极点型**：如 `uu_to_uu`、`uubar_to_ddbar`、`uubar_to_uubar`、`udbar_to_udbar`；
  3. **多通道平方极点竞争型**：如 `ud_to_ud`，其 `t/u` 两道都能在同一 `t` 区间内出现零宽度极点。
- 当前还没有在代表样本里看到“主异常来自 `s` 道自身发散”的清晰证据。
- 这意味着：
  - qqbar 过程的远峰也不能想当然地归给 `s` 道；
  - 至少在 T190 已抽样的主异常里，**`t` 道零宽度极点仍是最普遍的直接触发机制**。

### 20.6 对下一阶段路线的含义

- 如果后续要做物理处方/正则化，最低优先级不应再放在“只改全局 cache 补点”；
  而应更明确地面向**传播子零宽度极点**本身。
- 同时，`ud_to_ud` 这类双极点竞争过程提醒我们：
  - 后续方案不能只针对“单一 `t` 道零点”；
  - 还需要允许在同一 `t` 区间内识别多个候选零点，并区分单极点与多极点竞争情形。

## 21. 2026-03-15 补充：Fortran / C++ 旧实现是否处理了这类发散

### 21.1 本轮检查范围

- Fortran：`D:\Desktop\Relaxtime_fortran\codes\relax time\`
- C++：`D:\Desktop\Cpp\2026_03_08\20250413备份\codes\`
- 重点核查文件：
  - `z3 tintegrate.f90` / `PNJL_rextime.cpp::tint`
  - `z5 propagator.f90` / `PNJL_rextime.cpp::propagator_l, propagator_h`
  - `z6 polarization.f90` / `PNJL_rextime.cpp::polarization`
  - `z81 BPM.f90`, `z82 CPVI.f90` / `PNJL_rextime.cpp::BPM, CPVI`
  - `z2 averaged_rate.f90` / `PNJL_rextime.cpp::averaged_rate`

### 21.2 第一结论：旧 Fortran 与旧 C++ 在这条链路上基本是同一数值方案

- 两套旧实现的关键结构几乎一一对应：
  - `t` 积分都用**固定 64 点**高斯求积；
  - `ω` 平均前都先在 `s` 上预采样 **128 点**；
  - 后续 `average rate` 都对 `σ(s)` 做**线性插值**；
  - 简单传播子都写成
    `D = 2K / (1 - 4KΠ)` 的等价实虚分解形式。
- 因此如果 Julia 现在暴露出某类零宽度 `t` 道极点病态，旧 Fortran/C++ 在理论结构上并没有走另一条本质不同的路线。

### 21.3 第二结论：旧实现**没有**在 `t` 积分层显式处理零宽度平方极点

- Fortran `z3 tintegrate.f90`：
  - 直接对 `[t_min, t_max]` 做 `gauleg_ab(..., nt=64)`；
  - 被积函数就是 `amplitude2(s_cm, t_cm, qk)`；
  - 只在上下限上乘了 `0.999d0`，把积分区间从端点轻微缩进去。
- C++ `PNJL_rextime.cpp::tint` 也是同样做法：
  - `const int nt = 64`；
  - `gl_xw(nt, t_min, t_max, x, w)`；
  - 区间同样乘 `0.999`。
- 这说明旧实现对 `t`-道近极点没有：
  - 局部子区间细分；
  - 极点检测；
  - 主值/PV 处方；
  - 显式有限宽度；
  - clipping / exclusion window。
- 它们唯一做的只是：
  - 固定节点求积；
  - 再加一个轻微端点回缩 `0.999`。

### 21.4 第三结论：`CPVI` 确实存在，但它处理的是 **B0 / polarization 的能量积分奇点**，不是当前 `t` 积分发散

- Fortran `z82 CPVI.f90` 与 C++ `CPVI(...)` 都采用同一个思路：
  - 在能量积分变量上找到奇点 `x0`；
  - 用 `x0 ± 0.001 h` 在奇点两侧重新布点，避开 singular point 本身。
- 但它们只在 `BPM` / `B0SUM` / `polarization` 内部被调用：
  - Fortran：`z81 BPM.f90`
  - C++：`PNJL_rextime.cpp::BPM`
- 作用对象是：
  - 极化函数内部的 `E`-积分 / `B0`-积分；
  - 本质上是处理 loop integral 中的一次奇点或对数奇点。
- 它**不是**：
  - 对 `σ(s)=∫dt dσ/dt` 的 `t` 积分做 CPVI；
  - 也不是对 `|D|^2 ~ 1/(t-t0)^2` 的平方极点做正则化。
- 所以不能把旧代码里有 `CPVI` 直接理解成“旧实现已经处理了我们当前发现的 `t` 发散”。

### 21.5 第四结论：旧传播子实现也没有人为加入 `epsilon` / `Gamma`

- Fortran `z5 propagator.f90` 的简单传播子写法为：
  - `Re_D = 1 - 4K * pi_re`
  - `im_D = 4K * pi_im`
  - 然后 `fpol, im_pol` 都除以 `Re_D^2 + im_D^2`
- C++ `propagator_l` 也完全相同。
- 检查结果没有发现：
  - 在传播子分母上额外加固定 `eps`；
  - 在介子传播子层加入显式 `Gamma` / width；
  - 遇到 `Re_D≈0, im_D≈0` 时的专门保护。
- 因而当某个 spacelike `t` 点满足：
  - `1 - 4KΠ_re ≈ 0`
  - 且 `Π_im ≈ 0`
  时，旧代码在传播子层同样会出现非常尖的放大。

### 21.6 第五结论：旧实现更像是“把病态结构数值平滑/漏采样掉”，而不是从理论上处理它

- 在 `average rate` 层，Fortran 与 C++ 都是：
  - 先只在 `s` 上采样 `128` 个点；
  - 再对 `σ(s)` 做线性插值：
    - Fortran：`inc*(s_cm-s_cmk(i0)) + sig(i0)`
    - C++：`chazhi_detx_eq(...)`
- 这条链路的后果更像是：
  - 如果极窄峰没被 `s` 网格采到，就被直接漏掉；
  - 如果只采到单点高针，就会被线性插值“抹平”成有限斜边；
  - 如果 `t` 积分固定 64 节点刚好没踩到峰心，也会得到看似温和的有限值。
- 因此旧代码之所以可能没明显暴露当前问题，更可能是：
  - **固定 64 点 `t` 积分 + 128 点 `s` 采样 + 线性插值** 把零宽度病态投影成了一个粗分辨率下的有限数值；
  - 而不是它们已经从物理或数学上解决了该发散。

### 21.7 当前最稳妥的对比结论

- 可以较强地说：
  1. **旧 Fortran/C++ 并没有显式处理当前这类 `t` 道零宽度平方极点发散；**
  2. 它们真正处理的是更内层 `B0`/极化函数中的能量积分奇点，而不是 `σ(s)` 的 `t` 积分发散；
  3. 它们得到有限结果，更像依赖固定节点、端点回缩和粗网格插值的工程性平滑/漏采样。
- 因而如果我们现在要回答“旧程序是否考虑到了这个发散问题”，更准确的表述应是：
  - **它们考虑了 loop integral 层的奇点回避；**
  - **但没有专门处理当前已在 Julia 中明确暴露出来的 `t`-积分零宽度平方极点问题。**
