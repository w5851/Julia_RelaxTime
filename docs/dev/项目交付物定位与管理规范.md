# 项目交付物定位与管理

产物放入已有职责目录，记录足以定位来源和恢复工作的事实。普通任务由 issue/PR 追踪即可，跨主线状态使用 task ledger。

| 产物 | 位置 | 维护要求 |
| --- | --- | --- |
| 可复用 Julia 实现 | `src/` | 通过稳定入口调用；新行为有适当覆盖 |
| 模型参数/共享物理常数 | `config/models/`、`config/physics/` | 单位、默认值与生效优先级明确 |
| 行为测试/数值回归/外部验证 | `tests/unit/`、`tests/integration/`、`tests/regression/`、`tests/validation/` | 按验证目标分层，已有覆盖可复用 |
| 分析与性能探针 | `scripts/analysis/`、`scripts/perf/`、`benchmark/` | 记录必要输入、命令和适用范围 |
| API/稳定脚本说明 | `docs/api/`、`docs/guides/` | 稳定入口或合同变化时更新 |
| 公式与方法依据 | `docs/reference/formula/` | 保持来源、符号和实现映射 |
| 分析证据 | `docs/analysis/` | 结论绑定相关字段、点位或图件 |
| 活动任务/规划/历史 | `docs/dev/active/`、`backlog/`、`archived/` | 按真实执行状态整理，年龄仅提醒 |
| 运行结果/图像 | `data/outputs/results/`、`data/outputs/figures/` | 临时探索与正式冻结交付区分 |

## 来源与完整性

- 跟踪代码可使用 Git commit 和必要的有效配置；未提交代码需要可恢复的差异或快照。
- 临时探索保留必要参数和输出，不要求每次操作生成完整 hash/claim ledger 包。
- 冻结数据、外部下载、正式交付及归档恢复使用适用的完整性校验。
- 历史生成器按记录的代码版本核对；后续源码修改不改写旧记录。
- 图件遵循 [最新绘图 SOP](../guides/sop/workflows/figure_production.md)；验证该次产物，公共测试在公共代码变化时执行。

提交选择可复现源码、必要数据与证据；大体积产物说明用途和保存方式。保留用户工作及已有正式结果，清理动作按明确目标执行。
