# A+B 统一收口报告（v1）

日期：2026-02-14  
范围：RPNJL 主线；A 轨（Julia/Fortran 一致性）+ B 轨（低温失效归因）联合结论。

## 1. 结论摘要

- 总判定：**混合原因，算法主导**。
- 一致性现状（A 轨）：在当前可比样本上，核心字段仍未通过工程门槛（`rtol=1e-4, atol=1e-6`）。
- 低温失效（B 轨）：
  - `T=2,3`：共享低温刚性/失效候选（快筛口径下 Julia/Fortran 均无有效点）；
  - `T=4,5,6,8`：Fortran 出现“无有效分支或平坦锁定分支”，已具备算法性证据。

## 2. 关键证据与产物

### 2.1 A 轨一致性

- 明细：`outputs/results/fortran_julia_compare_detail.csv`
- 汇总：`outputs/results/fortran_julia_compare_summary.csv`
- 观察：
  - 双侧有效点上的 `phi_* / Phi / PhiBar / mu_* / mu_B / rho_u / rho_d` 存系统偏差；
  - Fortran 仍有字段完备性问题（`mu_s, mu_Q, mu_S` 缺列/缺值）。

### 2.2 B 轨低温归因

- 边界快筛：`outputs/results/lowT_boundary_compare_2s.csv`
- 可恢复性明细：`outputs/results/fortran_recoverability_detail.csv`

- 观察：
  - Fortran 在多起点下出现“有行数但无有效变化（平坦锁定）”现象；
  - Julia 在 `T>=4` 仍可解，支持“并非纯物理不可解”。

## 3. 当前可执行策略（不改物理参数）

1. Fortran 扫描改为**双向 continuation + 多种子**（最小实现：每温度两条链）；
2. 增加**有效分支判据**（拒绝平坦锁定解）；
3. 导出中强制记录约束残差（至少 `fvec(6..8)`）作为接受条件；
4. 保持 log 域防护作为稳健性措施，但不作为主修复路径。

### 11.8 J 阶段执行更新（2026-02-14，P2.2 加权残差原型）

- 输出：`outputs/results/julia_lowT_stubborn_weighted_recovery_after_p2p2.csv`
- 方法：
  - 对 stubborn 点先做 relaxed bootstrap；
  - 以多组分量权重（重点强化 `F2/F6/F8`）执行 weighted residual 求解；
  - 再进行 strict correction（二阶段接受）。
- 结果：
  - `strict_correction` 成功数：`0/10`（两点均未恢复严格收敛）；
  - `T=2,rho=0.05`：weighted 阶段最佳残差降至 `2.62e-3`（较 P2.1 进一步下降），但 strict 仍失败；
  - `T=3,rho=0.01`：weighted 阶段最佳残差仍约 `5.55e-2`，主导失配保持在 `F8/F6` 通道。
- 结论：
  - “加权 + 二阶段”可改善局部残差，但仍不足以跨越严格物理解门槛；
  - 剩余瓶颈更可能位于约束耦合结构本身（尤其 `F8` 与 `F6`），需考虑模式级求解策略改造（例如约束分裂求解或目标函数重构）。
