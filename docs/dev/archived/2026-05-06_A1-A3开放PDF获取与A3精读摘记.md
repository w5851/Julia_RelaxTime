## 2. A1 / A2 首轮确认

### A1 (`1608.05383`)

从正文首页与引言可直接确认：

1. 它不是单纯结果层文章，而是明确以 `2+1 flavor PNJL + Beth-Uhlenbeck` 为主框架；
2. 重点对象正是 `pi/K` 及其 Mott 解离；
3. 文中显式强调：
   - threshold phase-shift jump；
   - Levinson theorem；
   - scattering continuum 不能省略；
   - 高能端 phase shift 应回零，从而保证高温下 mesonic correlation 对 thermodynamics 的贡献自然消失。

这使它继续保持当前 `F4.6` 的第一优先级。

但这个“第一优先级”现在应精确理解为：

- `2+1 flavor + pi/K + BU/phase-shift + continuum` 机制层第一优先级；
- 不是“与当前项目含六费米子项的主拉氏量完全同构”的第一优先级。

### A2 (`1305.3907`)

从摘要与引言可直接确认：

1. 该文的核心是 generalized Beth-Uhlenbeck 形式；
2. 讨论了 resonance / continuum 分解；
3. 明确把 Mott effect 与 phase shift threshold jump、Levinson theorem、correlation pressure 联系起来。

因此它仍然是当前 `generalized BU` 参考 workflow 的最关键上游理论文献。

同时要加上边界：

- 它对 generalized BU 很重要；
- 但因为缺少当前项目里的六费米子项，不能单独承担当前主模型的强公式背书角色。

## 3. A3 精读要点

### 3.1 文献定位

A3 不是 `pi/K` 结果文献，也不是 `2+1 flavor` 文献；它研究的是：

- `2-flavor PNJL`
- `mu = 0`
- mesonic equation of state
- 全动量依赖的 meson polarization loop
- spacelike 区域 `ω^2 - q^2 < 0` 的 continuum / Landau damping

因此它**不能**直接作为当前 `pi/K` 数密度 workflow 的 formal validation target，
但它对当前仓库是否应忽略 off-shell / continuum / spacelike contribution 这个问题有直接约束力。

此外还要再加一条：

- 它同样不能作为当前含六费米子项主模型的同构文献。

### 3.2 与当前实现链最相关的结论

从摘要与引言前几页可直接提炼出四个关键点：

1. **不能只看 quasiparticle pole**
   - A3 明确指出：若只保留 quasiparticle 部分，而忽略 spacelike continuum / LD，热力学量会被系统性低估。

2. **full momentum dependence 对 pressure 有实质影响**
   - 文中强调：对 quasiparticle dispersion，本征峰位置相对 vacuum 改动不大；
   - 但对 thermodynamics，特别是 mesonic pressure，`full q` 依赖与 Landau cut 贡献不能简单忽略。

3. **Landau damping 在 `T ≳ 0.8 T_c^χ` 变得重要**
   - 文中把压力增强与 trace anomaly 的显著变化直接归因于 spacelike continuum contribution；
   - 这说明只用 on-shell / Breit-Wigner 结果去类比完整 BU 热力学，会天然漏掉一块物理贡献。

4. **meson momentum cutoff dependence 会变强**
   - A3 直接提醒：当 continuum / LD 被纳入后，mesonic pressure 会对 meson momentum cutoff 更敏感；
   - 这和当前仓库在 `qmax / q_nodes / omega_max` 上已经显式治理的方向是相容的。

### 3.3 对当前仓库的直接启示

对 `Julia_RelaxTime` 当前 meson-density / BU 主线，A3 的价值不在于“给我们一个现成 target 曲线”，而在于：

1. **支持继续保留 stricter reference 思路**
   - 因为它说明 off-shell / continuum 的确会改变 thermodynamics；
   - 所以当前把 `stable / BW` 视为降阶台阶、而不给完整 BU 强行设“必须接近 stable/BW”的要求，是合理的。

2. **支持不把 current BU 过早压缩为 pole-only 解释**
   - 即使 quasiparticle pole 仍然有意义，pressure / EOS 层面的 continuum contribution 仍不可忽略；
   - 这与当前 `generalized BU` 作为 stricter reference 的治理方向一致。

3. **提示 formal validation 若下沉到 pressure kernel，会比 `K/pi` 更硬**
   - A3 本身就是 pressure / off-shell kernel 文献；
   - 因此 `F4.6` 若后续真的选择 lower-layer target，应优先考虑：
     - `A1` 作为 `2+1 PNJL pi/K phase-shift` 主背书；
     - `A2` 作为 generalized BU 理论背书；
     - `A3` 作为 continuum / off-shell thermodynamics 补充背书。

### 3.4 A3 的边界

A3 当前不宜被误用为：

1. `pi/K` charged-ratio validation 文献；
2. `2+1 flavor` 精确公式同构文献；
3. 当前仓库 `mu_B ≠ 0` 路径策略的直接 target。

它的正确角色应固定为：

- **pressure / off-shell / continuum 物理解释层参考文献**

## 4. 当前建议

在后续 `F4.6` 继续推进时，推荐按下面顺序利用这三篇文献：

1. **A1**
   - 先对齐 `2+1 flavor PNJL`, `pi/K`, phase shift, continuum, Levinson 的机制层
2. **A2**
   - 再对齐 generalized BU 及 pressure 表达的机制层
3. **A3**
   - 最后把 off-shell / spacelike continuum / Landau damping 的 thermodynamics 含义补齐

这样可以避免把 A3 误当成直接数值 target，同时又不丢掉它对当前主实现链非常关键的物理约束价值。

但若后续目标升级为“寻找与当前项目含六费米子项主拉氏量更同构的强背书文献”，
则仍需新增一轮定向补检。
