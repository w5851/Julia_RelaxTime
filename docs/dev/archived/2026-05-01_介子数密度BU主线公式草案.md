# 介子数密度与 BU 主线公式草案

本文作为当前“介子数密度 / `K/\pi` 比值 / Beth-Uhlenbeck (BU)”主线的审核版公式草案，目的不是一次性给出最终实现文档，而是先固定：

1. 当前项目采用的主公式口径；
2. 与参考文献公式的对应关系；
3. 后续正式文档拆分时的边界；
4. 当前已确认的冲突处理规则。

本文面向任务单 [2026-04-30_介子数密度与BU工作流任务单.md](../active/2026-04-30_%E4%BB%8B%E5%AD%90%E6%95%B0%E5%AF%86%E5%BA%A6%E4%B8%8EBU%E5%B7%A5%E4%BD%9C%E6%B5%81%E4%BB%BB%E5%8A%A1%E5%8D%95.md) 的 `Phase A/B/C/D/E`，当前只固化“公式与口径”，不直接作为代码实现说明。

### 1.1 当前优先范围

- 介子道：`π` 与 `K`

- 当前项目主线：沿现有 PNJL + RPA + 极化函数 / 传播子实现向 BU 扩展

## 3. 当前项目主线口径

## 3.1 项目主传播子定义

当前仓库对 `π/K` 简单介子道采用如下 RPA 传播子：

```math
\mathcal{D}_M(\omega, q;\xi)
= \frac{2K_M}{1 - 4K_M \Pi_M(\omega, q;\xi)} ,
\quad M \in \{\pi, K, \sigma_\pi, \sigma_K\}.
```

对应实现与说明：

- [src/relaxtime/MesonPropagator.jl](../../../../../src/relaxtime/MesonPropagator.jl)
- [src/relaxtime/MesonMass.jl](../../../../../src/relaxtime/MesonMass.jl)
- [Propagator_传播子byPolarization.md](../propagator/Propagator_%E4%BC%A0%E6%92%AD%E5%AD%90byPolarization.md)
- [MesonMass_RPA_Pole.md](../propagator/MesonMass_RPA_Pole.md)

这一定义是当前项目和论文主线的首要约束。后续 BU 公式必须建立在这个传播子口径之上，而不是直接切换到文献中另一套归一化记号。

## 3.2 项目主极点条件

当前项目中 `π/K` 极点条件采用：

```math
1 - 4K_M \Pi_M(p_0, q;\xi) = 0,
\quad p_0 = M + i\Gamma/2.
```

对应实现：

- [src/relaxtime/MesonMass.jl](../../../../../src/relaxtime/MesonMass.jl) 中 `meson_mass_equation`

### 3.2.1 与文献极点条件的关系

部分 BU/BW 文献将极点条件写成

```math
1 - 2P_{ij}\Pi^M_{ij} = 0
```

或等价的 Bethe-Salpeter / propagator inverse 形式。

**当前处理规则：**

1. 项目正式文档以 `1 - 4K\Pi = 0` 为主定义；
2. 文献中的 `1 - 2P\Pi = 0` 仅作为“同类结构的不同记号/归一化对照”；
3. 不在当前文档中强行做两套记号的一一重写映射，避免把项目主线口径冲淡。

## 3.3 RS 各向异性的进入位置

当前项目中 RS 各向异性已经进入：

- 夸克分布函数
- 单圈积分修正
- 极化函数 `\Pi_M(\omega,q;\xi)`
- 介子传播子 `\mathcal{D}_M(\omega,q;\xi)`

对应实现：

- [src/relaxtime/PolarizationAniso.jl](../../../../../src/relaxtime/PolarizationAniso.jl)
- [Polarization_极化函数byB0.md](../polarization/Polarization_%E6%9E%81%E5%8C%96%E5%87%BD%E6%95%B0byB0.md)

**当前处理规则：**

1. `Phase D` 的稳定极限基线不显式修改介子色散关系 `E_M`；
2. 各向异性的主效应在后续 BU 阶段通过 `\Pi \to \mathcal{D} \to \delta_M` 链路进入；
3. 若后续需要构造各向异性的稳定 / BW 准粒子近似，必须从当前项目的极点条件重新导出 `E_M(q,\theta;\xi)`，不能直接手写经验型 `E_M(\xi)`。

## 4. 建议固化的核心公式

## 4.1 稳定粒子极限数密度

对稳定、无宽度的介子，采用玻色分布积分：

```math
n_M
= d_M \int \frac{d^3 q}{(2\pi)^3} g_M(E_M),
\quad
g_M(E_M) = \frac{1}{e^{(E_M - \mu_M)/T} - 1},
\quad
E_M = \sqrt{q^2 + m_M^2}.
```

### 来源

- `Blaschke:2020bzh` Eq. (23)
- `Blaschke:2021yml` Eq. (7)

### 当前采用理由

- 这是 `Phase D1-D2` 最合适的验证台阶；
- 可先验证单位、简并因子、温度趋势与 `K/\pi` 比值方向；
- 不依赖相移、宽度、连续谱实现细节。

### 当前备注

此处的 `E_M = \sqrt{q^2 + m_M^2}` 仅作为当前最小验证口径，不包含 RS 各向异性对介子色散关系的进一步修正。

## 4.2 `K/\pi` 比值定义

```math
\frac{K^\pm}{\pi^\pm} = \frac{n_{K^\pm}}{n_{\pi^\pm}}.
```

### 来源

- `Blaschke:2020bzh` 正文与 Eq. (23)-(25) 周边描述
- `Blaschke:2021yml` Eq. (7)-(8) 周边描述

### 当前采用理由

- 是当前任务单的直接输出物定义；
- 后续稳定极限、BW 与 BU 都落到这个比值层。

## 4.3 BU 相移数密度公式

采用广义 Beth-Uhlenbeck 形式：

```math
n_M(T)
= d_M \int \frac{d^3 q}{(2\pi)^3}
\int \frac{d\omega}{2\pi}
g_M(\omega)
\frac{d\delta_M(\omega, q)}{d\omega}.
```

### 来源

- `Blaschke:2020bzh` Eq. (24)
- `Blaschke:2021yml` Eq. (8)

### 当前采用理由

- 这是后续 `Phase E` 的主目标公式；
- 能统一描述束缚态、共振态与散射连续谱；
- 是相对 BW 更完整的主线表达。

### 当前项目化解释

对于当前项目，后续相移应优先从项目主传播子定义：

```math
\delta_M(\omega, q;\xi) = \arg \mathcal{D}_M(\omega + i\eta, q;\xi)
```

而不是从文献中的另一套耦合常数记号直接搬运。

## 4.4 BU 的分部积分等价形式

对上式分部积分后，可得到：

```math
n_M(T)
= \frac{d_M}{T}
\int \frac{dq\, q^2}{2\pi^2}
\int_0^\infty \frac{d\omega}{2\pi}
g_M(\omega)\bigl[1+g_M(\omega)\bigr]\delta_M(\omega).
```

### 来源

- `Blaschke:2020bzh` Eq. (25)

### 当前采用理由

- 是 `Phase B3` 必须显式比较的另一候选实现形式；
- 数值上可能比直接对 `d\delta/d\omega` 做差分更稳；
- 但具体实现优先级应在看过相移数值噪声后再定。

### 当前处理规则

1. 文档层先同时收录 `d\delta/d\omega` 与 `\delta` 两种形式；
2. 当前不提前指定哪一种先进入实现；
3. 后续在实现设计文档中再比较导数噪声、积分稳定性与边界项处理。

## 4.5 BW 相移与 BW 数密度

对窄宽度共振近似，文献采用：

```math
\delta_M(\omega)
= - \arctan \frac{\Gamma_M/2}{\omega - E_M},
```

其导数为

```math
\frac{d\delta_M}{d\omega}
= \frac{1}{2}
\frac{\Gamma_M}{(\omega - E_M)^2 + \Gamma_M^2/4}.
```

相应数密度公式为

```math
n_M(T)
= d_M \int \frac{d^3q}{(2\pi)^3}
\int \frac{d\omega}{2\pi}
g_M(\omega)
\frac{\Gamma_M}{(\omega - E_M)^2 + \Gamma_M^2/4}.
```

### 来源

- `Blaschke:2020bzh` Eq. (26), Eq. (27)

### 当前采用理由

- 是 `Phase D3-D4` 最自然的过渡验证台阶；
- 明确展示“稳定粒子 -> BW 共振 -> BU 全相移”的层级关系；
- 可用来对照 BU 相比 BW 多出了什么。

### 注意

文献中的 BW 相移写法是现象学近似；当前项目若要做 BW 层验证，仍建议从项目主极点条件 `1-4K\Pi=0` 求得 `M,\Gamma` 后再回填，而非独立脱离当前传播子口径。

## 4.6 稳定极限作为 BU/BW 的退化情形

### BW 退化到稳定粒子

当 `\Gamma_M \to 0` 时，BW 数密度退化回稳定粒子玻色积分。

### BU 退化到稳定粒子

若束缚态相移表现为

```math
\delta_M(\omega) \sim \pi \Theta(\omega - M_{\rm bound}),
```

则

```math
\frac{d\delta_M}{d\omega}
\sim \pi \delta(\omega - M_{\rm bound}),
```

代回 BU 数密度公式后恢复稳定粒子极限。

### 来源

- `Blaschke:2020bzh` Eq. (27) 后正文说明
- `Blaschke:2016sqn` 关于束缚态 / 连续谱相移跳变的讨论

### 当前采用理由

- 这是整条实现路线最关键的一致性检查；
- 若此退化关系不成立，则后续 BU 数值结果不可直接信任。

## 5. 相移定义与 Levinson 约束

## 5.1 相移的极坐标定义

文献中采用：

```math
S^M_{ij}(\omega, q)
= |S^M_{ij}(\omega, q)| e^{i\delta_M(\omega,q)},
```

```math
\delta_M(\omega, q)
= -\arctan
\frac{\Im[S^M_{ij}(\omega+i\eta, q)]}
{\Re[S^M_{ij}(\omega+i\eta, q)]}.
```

### 来源

- `Blaschke:2020bzh` Eq. (20), Eq. (21)
- `Blaschke:2021yml` Eq. (6) 周边正文

### 当前项目化解释

对当前项目简单介子道，可优先等价理解为：

```math
\delta_M(\omega,q;\xi) = \arg \mathcal{D}_M(\omega+i\eta,q;\xi).
```

## 5.2 束缚态与连续谱的相移判据

根据文献讨论：

- 束缚态出现时，相移在相应能量处发生 `+\pi` 跳变；
- 高能端相移应回到 `0`；
- Mott 解离后，原束缚态跳变转为连续谱/共振结构。

### 来源

- `Blaschke:2016sqn`
- `Blaschke:2020bzh` Section 3.2 周边正文
- `Blaschke:2021yml` Section 3 周边正文

### 当前采用理由

- 这是 BU 相移实现的物理门禁；
- 后续数值验证不能只看曲线形状，还要检查其是否满足 Levinson 约束。

## 6. 化学势口径的当前取舍

文献中常见设定包括：

```math
\mu_{K^+} = \mu_u - \mu_s,
\qquad
\mu_{K^-} = \mu_s - \mu_u = -\mu_{K^+}.
```

并在现象学应用中额外引入：

- nonequilibrium pion chemical potential `\mu_\pi`
- `\mu_\pi(x)`、`\mu_s(x)` 的经验拟合
- `x = T/\mu_B` 路径上的冻结线扫描

### 当前处理规则

1. 当前最小实现阶段不把 `\mu_\pi(x)`、`\mu_s(x)` 拟合写成主公式；
2. 若做 `\mu_B = 0` MVP，则优先采用最小平衡口径；
3. 现象学化学势拟合保留到后继阶段文档，不与当前数密度主线混写。

## 8. 当前结论

在当前项目语境下，后续介子数密度 / BU 工作流应遵循：

1. 传播子与极点条件服从项目现有 RPA 主线；
2. 稳定极限先作为验证台阶；
3. BU 相移公式作为后续主目标；
4. RS 各向异性不在当前阶段直接改写稳定粒子 `E_M`，而应通过项目现有 `\Pi` 与 `\mathcal{D}` 链路进入；
5. 现象学冻结线与拟合化学势暂缓，不并入当前最小实现。
