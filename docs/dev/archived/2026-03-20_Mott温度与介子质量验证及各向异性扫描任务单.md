## 1. 背景与目标

当前仓库已具备 PNJL/NJL 相关求解与输运计算能力，但针对以下两项缺少统一、可复现的研发闭环：

- 各向同性条件下（`xi = 0`）的 `Mott` 相变温度与介子质量结果验证，且与主工作区 Fortran 参考实现进行对照。
- 各向异性条件下（`xi != 0`）的 `Mott` 相变温度与介子质量随 `xi` 变化的系统扫描脚本（本期仅 `mu = 0`）。

本任务目标是先建立“可追踪的验证基线”，再建立“可复现的参数扫描工具链”，用于后续物理结论分析与回归测试接入。

## 3. 术语与口径对齐（防语义模糊）

为避免后续实现偏差，本任务采用如下默认口径：

- `Mott` 相变温度：按指定介子通道满足阈值条件（例如与夸克连续谱阈值关系）时对应的温度，具体判据需在实现前写入代码注释与文档。
- 介子质量：沿用仓库既有质量求解入口，单位默认 `MeV`（内部若用自然单位，需在输出中显式转换）。
- 各向同性：`xi = 0`。
- 各向异性：`xi` 在预设网格扫描，建议先采用对称网格（例如 `[-0.6, 0.6]`，步长可调）。
- 化学势：本期固定 `mu = 0`。
- 参考一致性：以“相对误差 + 绝对误差”双阈值评估，不使用单一误差指标。
