## 已实现的输出字段补齐（RTA 归一化）

`scripts/relaxtime/run_gap_transport_scan.jl` 已新增并写入 CSV 的列：

- `sigma_over_T`：$\sigma/T$（维度归一化后无量纲）
- `sigma_over_T_over_eta_over_s`：$(\sigma/T)/(\eta/s)$（对应“电导率比剪切”，使用归一化量）
- `zeta_over_s_over_eta_over_s`：$(\zeta/s)/(\eta/s)$（对应“体粘滞比剪切”，使用归一化量）


注意：体粘滞相关列需要运行时加 `--compute-bulk`，否则 `zeta`/`zeta_over_s` 可能为空/NaN。

## 一键生成（推荐）

新增脚本：`scripts/relaxtime/run_outputs_2026_02_05.jl`，会自动：

1. 产出散射截面（多过程）CSV + 图片
2. 在 $\mu_B=0$ 下取手征相变温度上下两点（默认 190/210 MeV），扫描 $\xi$
3. 在 $\mu_B=0,\,\xi=0$ 下扫描温度

并将结果归档到 `data/outputs/results/...` 与 `data/outputs/figures/...` 的不同子文件夹。

示例：

```bash
julia --project=. scripts/relaxtime/run_outputs_2026_02_05.jl --overwrite
```

常用可选参数：

- `--xs-T 200 --xs-muB 0 --xs-xi 0`：截面扫描的固定点
- `--xi-min -0.6 --xi-max 0.6 --xi-step 0.1`：$\xi$ 扫描范围
- `--T-below 190 --T-above 210`：相变上下温度点
- `--Tmin 120 --Tmax 350 --Tstep 10`：$T$ 扫描范围
- `--mode finite_15`：与现有扫描脚本一致的积分模式
- `--no-plots`：只产出 CSV
- `--no-bulk`：关闭体粘滞（更快，但缺少 ζ 相关需求输出）

散射截面，固定温度和化学势，xi=0下,输出不同散射过程数据随sqrt(s)的变化(这个功能应该对应脚本scripts\relaxtime\scan_total_cross_section.jl)
固定零化学势，手征相变上下各一个点(化学势为0，xi=0时，手征相变温度应该在200MeV左右)，分别输出随xi变化的数据，包括不同夸克弛豫时间，电导率除以温度(目前应该没有这个输出，需要补充sigma_over_T)，电导率比剪切，体粘滞比剪切(这两个也没有，也需要补充，注意这里做出发的时候需要使用归一化后的输运系数，即sigma_over_T, eta_over_s等)
固定零化学势，xi=0下，输出数据随温度的变化
