# Phase E3 结果字段与最小扫描说明

更新日期：2026-05-02

目的：说明当前 Phase E3 最小正式扫描输出中，哪些字段应视为当前物理结果，哪些字段仅用于数值收敛/截断诊断；同时记录首轮 `208:2:220 MeV` 扫描的最小观察结果。

相关脚本：

- `scripts/relaxtime/run_phase_shift_meson_density_scan.jl`

相关输出：

- [phase_shift_meson_density_scan_208_220_step2.csv](../../../data/outputs/results/relaxtime/scan/phase_shift_meson_density_scan_208_220_step2.csv)

---

## 1. 当前扫描口径

本轮正式扫描采用：

- `workflow_entry = Models.solve_gap_and_phase_shift_meson_density_point`
- `μ_B = 0`
- `xi = 0`
- `T = 208:2:220 MeV`
- `qmax = 12`
- `q_nodes = 48`
- `omega_min = 0.05`
- `omega_max = 10`
- `omega_nodes = 48`
- `eta = 1e-6`

因此，这一页记录的是 **当前 Phase E3 最小相移双积分口径** 的结果，不是更严格 BU 公式最终收口版，也不是稳定粒子极限结果。

---

## 2. 当前输出字段如何解读

### 2.1 当前应优先视为物理结果的字段

下列字段属于当前扫描最核心的物理输出：

- `m_pi`, `m_K`
  - 当前 workflow 返回并被数密度后处理消费的介子质量
- `n_pi`, `n_K`
  - 当前 Phase E3 相移双积分口径下的聚合通道介子数密度
- `kpi_ratio`
  - `n_K / n_pi`

如果当前阶段只关心“这条主线给出了什么最小结果”，应优先看这几列。

### 2.2 当前属于背景输入/配置回显的字段

下列字段主要用于说明这一行结果是在什么 workflow 和数值配置下得到的：

- `T_MeV`, `muB_MeV`, `xi`
- `T_fm`, `muB_fm`, `mu_fm`
- `Phi`, `Phibar`
- `m_u`, `m_d`, `m_s`
- `d_pi`, `d_K`
- `qmax`, `q_nodes`
- `omega_min`, `omega_max`, `omega_nodes`
- `eta`

这些字段不是“额外物理观测量”，但它们对复现实验和比较不同口径非常重要。

### 2.3 当前主要用于收敛/截断诊断的字段

下列字段当前不应直接当成最终物理论文结果，而应视为数值诊断量：

- `pi_q_integral_estimate`
- `K_q_integral_estimate`
- `pi_omega_shell_at_qmax`
- `K_omega_shell_at_qmax`

它们的含义是：

- `*_q_integral_estimate`
  - 在最终乘上 `d_M / T` 前，外层 `q` 积分本体的估计值
- `*_omega_shell_at_qmax`
  - 最外层 `q = q_last_node` 处的壳贡献代理，用于判断 `qmax` 是否已经足够大

当前它们的主要用途是回答：

1. 双积分是否已经进入相对稳定的数值窗口
2. 某个温点是否还明显受 `q` 截断影响

---

## 3. 首轮最小扫描结果

### 3.1 `n_pi(T)` 在当前窗口内略有下降

当前结果显示：

- `T = 208 MeV`：`n_pi ≈ 2.825`
- `T = 220 MeV`：`n_pi ≈ 2.798`

因此在这段窗口内，`n_pi(T)` 不是上升，而是 **缓慢下降**。

### 3.2 `n_K(T)` 在当前窗口内上升

当前结果显示：

- `T = 208 MeV`：`n_K ≈ 3.867`
- `T = 220 MeV`：`n_K ≈ 3.915`

因此 `n_K(T)` 在当前窗口内是 **单调上升** 的。

### 3.3 `K/pi(T)` 在当前窗口内上升

当前结果显示：

- `T = 208 MeV`：`K/pi ≈ 1.3688`
- `T = 220 MeV`：`K/pi ≈ 1.3990`

因此当前最小 Phase E3 口径下，`K/pi(T)` 在 `208:2:220 MeV` 内表现为 **缓慢上升**。

---

## 4. 当前诊断量告诉了什么

### 4.1 最外层壳贡献仍然不大

在本轮结果里：

- `pi_omega_shell_at_qmax ≈ 1.15e-3 -> 1.61e-3`
- `K_omega_shell_at_qmax ≈ 1.42e-3 -> 1.90e-3`

这说明当前 `qmax = 12` 下，最外层壳贡献已经维持在 `10^-3` 量级，没有重新长回到 `10^-2` 量级。

### 4.2 但这些诊断列暂时不该当成“物理图”直接使用

当前更恰当的处理方式是：

- 用 `n_pi`, `n_K`, `kpi_ratio` 画最小结果图
- 用 `*_omega_shell_at_qmax` 辅助判断某段结果是否仍可能受截断影响

而不是把诊断列和主结果列混在同一层叙事里。

---

## 5. 当前阶段应如何使用这份结果

如果当前目的是继续推进任务单主线，这份扫描结果适合做两件事：

1. 作为当前 Phase E3 最小正式输出的第一版结果表
2. 作为后续结果图与 stable / BW / 更严格 BU 口径比较的基线

但当前仍不宜直接把这组数值写成最终物理结论，因为：

- 这还是 Phase E3 最小口径
- 更严格 BU 公式收口尚未完成
- 当前结果解释还需要与 stable / BW 或更严格相移口径进一步对照

## 6. 当前判断一句话版

- **Phase E3 当前最小正式扫描已经跑通；当前应把 `n_pi` / `n_K` / `K/pi` 当作主结果，把 `q_integral_estimate` 与 `omega_shell_at_qmax` 当作数值诊断量分开使用。**
