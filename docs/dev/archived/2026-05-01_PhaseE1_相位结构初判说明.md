# Phase E1 相位结构初判说明

更新日期：2026-05-01

目的：对 `Phase E1` 首轮最小相位诊断结果做人工可审阅总结，判断当前 `delta_M(omega,q)` 诊断链是否已经足以进入 `Phase E2`。

## 1. 当前诊断范围

当前首轮诊断固定为：

- `muB = 0`
- `xi = 0`
- `meson = pi, K`
- `T = 208, 210, 212 MeV`
- `q = 0.0, 0.2, 0.4`

脚本输出了：

- `Pi_M(omega)`
- `D_M(omega)`
- `phase_raw`
- `phase_unwrapped`
- `mass_ref`
- `gamma_ref`
- `threshold_ref`
- `gap_ref`

因此当前诊断已经能同时对照：

- 传播子峰位
- 极点质量
- Mott 阈值
- 相位跨度

## 2. 首轮可读结论

### 2.1 传播子峰位与参考质量基本协调

当前 `|D_M|` 最大值对应的 `omega` 峰位与 `mass_ref` 大体一致，并位于 `threshold_ref` 附近或其上方。

例如：

- `T = 210 MeV, q = 0`
  - `pi`：
    - `peak_omega ≈ 0.89`
    - `mass_ref ≈ 0.91`
    - `threshold_ref ≈ 0.70`
  - `K`：
    - `peak_omega ≈ 2.51`
    - `mass_ref ≈ 2.57`
    - `threshold_ref ≈ 2.38`

这说明当前 `PolarizationAniso + MesonPropagator` 相位诊断链没有出现明显的峰位错配。

### 2.2 相位跨度已经显著，不是数值噪声级别

当前 `phase_span` 大致处于：

- `pi`：约 `2.38 ~ 2.58`
- `K`：约 `2.25 ~ 2.58`

这说明：

- `arg D_M` 的相位变化已经足够大
- 当前脚本输出不是围绕 `0` 的微小浮动
- 继续做分支/阈值结构分析是有意义的

### 2.3 随 q 增大，传播子峰强度下降

当前首轮结果中，`D_abs_max` 随 `q` 增大普遍下降。

例如：

- `T = 210 MeV, pi`
  - `q = 0.0`：`D_abs_max ≈ 31.53`
  - `q = 0.2`：`D_abs_max ≈ 30.83`
  - `q = 0.4`：`D_abs_max ≈ 28.97`

- `T = 210 MeV, K`
  - `q = 0.0`：`D_abs_max ≈ 7.61`
  - `q = 0.2`：`D_abs_max ≈ 7.57`
  - `q = 0.4`：`D_abs_max ≈ 7.47`

这至少说明当前 `q` 方向的传播子响应没有出现明显失控。

## 3. 当前还不能下的结论

虽然首轮输出已经可读，但它还不足以直接声称：

1. 已严格识别出束缚态对应的完整 `+pi` 跳变
2. 已严格确认高能端相位回零
3. 已完整分离 bound-state 与 continuum 的贡献
4. 已可直接接入正式 BU 数密度积分

原因是当前脚本仍然只是：

- 少量温点
- 少量 `q`
- 固定 `eta`
- 有限 `omega` 扫描窗

所以它更像是“相位结构可诊断性检查”，不是“相位实现已完全验收”。

## 4. 对 Phase E2 的直接含义

当前结果已经足以支持进入 `Phase E2`，但进入方式应保持克制。

建议的 `Phase E2` 目标不是立刻做完整 BU 数密度积分，而是先补三类检查：

1. **分支检查**
   - 确认 `phase_unwrapped` 的解包是否稳定
   - 排除由 `atan` 主值分支造成的伪跳变

2. **阈值邻域补点**
   - 对 `omega ≈ threshold_ref`
   - 以及 `omega ≈ mass_ref`
   - 做更细步长局部扫描

3. **高能端回零检查**
   - 扩大 `omega_max`
   - 看 `delta_M(omega,q)` 在更高能端是否确实回到接近 `0`

也就是说，`Phase E2` 应该是：

- “相位结构验收”

而不是：

- “立即做正式 BU 数密度积分”

## 5. 当前推荐判断

当前推荐判断可以压成一句话：

- **Phase E1 已证明：当前项目的传播子相位诊断链是通的、可读的，并且足以支持进入以分支/阈值/高能行为为中心的 Phase E2。**

## 6. 下一步建议

下一步建议按以下顺序推进：

1. 固定 `T = 208, 210, 212 MeV`
2. 固定 `q = 0`，必要时保留 `q = 0.2`
3. 对每个通道围绕：
   - `threshold_ref`
   - `mass_ref`
   做局部加密扫描
4. 同时把 `omega_max` 适度外推，检查高能端相位行为
5. 在这些检查清楚后，再决定正式 BU 积分的区间与数值策略
