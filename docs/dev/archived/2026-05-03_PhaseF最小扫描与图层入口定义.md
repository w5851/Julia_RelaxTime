## 1. 进入 Phase F 的当前前提

当前已经满足进入最小 `Phase F` 整理的工程前提：

1. `stable / strict BW / current / gbu_reference` 四条链都已有正式 workflow / scan 入口；
2. 当前默认生产主线与 stricter reference 的治理分工已固定；
3. `scattering / normalization` 仍可继续深化，但已不再阻塞 workflow 治理闭环。

但当前**尚未满足**“直接把 Phase F 当成最终物理解读层”的前提：

1. `arg D` 总相位中的 scattering-part 边界仍未完全收口；
2. `generalized BU` 的优势中，物理修正与 normalization 低敏感性的相对权重仍未完全分离；
3. 因而当前 `Phase F` 结果应按**阶段性结果层**管理，而不是最终论文图层。

## 3. 当前最小图层定义

### 3.1 图 1：`n_pi(T)` 与 `n_K(T)` 主图

建议先做两张并列子图，或同一画布上下两栏：

1. 上栏：`n_pi(T)`
2. 下栏：`n_K(T)`

每张图当前最多放四条曲线：

1. `stable`
2. `strict BW`
3. `current BU`
4. `gbu_reference`

解释层级固定为：

1. `stable` 与 `strict BW` 是降阶对照层；
2. `current BU` 是默认生产主线；
3. `gbu_reference` 是更严格参考层。

当前不建议在主图中直接加入：

1. phase normalization 诊断曲线；
2. derivative-vs-byparts 偏差曲线；
3. Levinson 偏差曲线。

这些内容应继续保留在 `Phase E5` 分析页，不直接挤进主图层。

### 3.2 图 2：`K/pi(T)` 比值图

当前单独做一张 `K/pi` 比值图即可。

比较对象仍固定为：

1. `stable`
2. `strict BW`
3. `current BU`
4. `gbu_reference`

当前图例解释应写清：

1. `current BU` 是正式默认口径；
2. `gbu_reference` 不是替代主线，而是 stricter reference；
3. 若 `current BU` 明显高于 `stable / strict BW`，当前首先解释为“BU 口径与相位结构效应”，而不是自动视为实现错误。

## 4. 当前应读取的核心字段

当前最小图层只读取每份 CSV 中的下列字段：

1. 横轴：
   - `T_MeV`
2. 主结果：
   - `n_pi`
   - `n_K`
   - `kpi_ratio`

当前不进入主图的字段，但应保留用于结果说明或诊断附表：

1. `m_pi`, `m_K`
2. `gamma_pi`, `gamma_K`（strict BW）
3. `pi_q_integral_estimate`, `K_q_integral_estimate`
4. `pi_omega_shell_at_qmax`, `K_omega_shell_at_qmax`
5. `stage`, `mode` 等实现诊断字段

## 5. 当前不建议在 Phase F 立刻做的事

当前先不做：

1. 文献图直接并排拟合；
2. 把 `gbu_reference` 升格成正式默认主线；
3. 把 Phase E5 的 normalization / Levinson 诊断直接混入主结果图；
4. 扩成完整 `T-\mu_B` 或 `T-\xi` 图组；
5. 直接把当前扫描结果包装成论文终图。

## 5.1 文献验证目标的后续位置

当前建议把“本地参考文献库结果提取并转化为验证目标”列为 `Phase F` 后续正式化工作的一部分，而不是拖到完全独立的新任务里。

原因：

1. 介子数密度主线目前已经有项目内四条链的内部对照；
2. 但当结果进入正式 baseline / regression 固定时，还需要一层外部参照；
3. 本地 `paper_lib` 中的相关文献结果，若能提取到与当前口径可比的 `n_pi(T)` / `n_K(T)` / `K/\pi(T)`，就适合转成项目验证目标。

建议后续把文献结果先分三类管理：

1. 可直接提取为数值点或曲线目标；
2. 需人工转录或重新读图；
3. 因口径差异过大而暂不适合作为回归目标。

## 6. 建议的执行顺序

进入 `Phase F` 时，顺序建议固定为：

1. 先整理四条链在 `208:2:220 MeV` 上的最小并排结果；
2. 先出 `n_pi(T) / n_K(T)` 与 `K/pi(T)` 两类最小图层；
3. 结果说明只写“口径分工 + 数量级关系 + 哪些属于对照层”；
4. scattering / normalization 的更深解释继续留在 `Phase E5` 文档链中推进；
5. 只有当 `Phase E5` 进一步收口后，才考虑把当前 `Phase F` 图层升格为最终叙事层。

## 7. 本页结论

当前最合理的 `Phase F` 进入方式不是“开始完整结果分析”，而是：

**先把 stable / strict BW / current BU / generalized BU reference 四条正式扫描链，收成两张最小结果图与一页简短口径说明；并明确这些图当前仍属于阶段性结果层。**
