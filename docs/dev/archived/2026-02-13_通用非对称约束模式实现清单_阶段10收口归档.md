# 通用非对称约束模式实现清单（最小切片）

日期：2026-02-13  
范围：在现有 PNJL/rPNJL 通用求解框架中，新增一个“与具体模型解耦”的非对称约束模式。

## 1. 目标与结论先行

- 目标不是分别实现 `PNJL` 与 `RPNJL` 两套非对称求解器；
- 目标是实现一个通用约束模式：
  - 共享状态变量：`x = [φ_u, φ_d, φ_s, Φ, Φbar, μ_u, μ_d, μ_s]`；
  - 共享约束接口：`5 个 gap 条件 + 3 个外部约束`；
  - 模型差异仅通过 `thermo_backend/model_kind` 注入（`PNJL` 或 `RPNJL`）。

这与 Fortran `funcv_quark.f90` 的结构一致：
- `fvec(1..5)`：场方程（gap + Polyakov）；
- `fvec(6)`：重子密度约束；
- `fvec(7)`：`rho_u/rho_d` 比值约束（示例值 0.876）；
- `fvec(8)`：`rho_s = 0` 约束。

## 2. 与现状差异（Julia 当前）

当前 `FixedRho` 仍内置对称化学势约束：
- `μ_u=μ_d`, `μ_d=μ_s`；
- `ρ` 目标约束。

因此尚不能直接覆盖 Fortran 的“非对称模式”三约束。

## 3. 实现原则

- 原则 A：约束层可配置，模型层不分叉。
- 原则 B：先最小可用，再扩展更多约束表达。
- 原则 C：每步 smoke，失败可回退。

## 5. DoD（完成定义）

- 至少有一个通用非对称约束模式可运行（不按模型分叉）。
- `PNJL` 与 `RPNJL` 在同一模式下都可求解单点。
- 三约束（`nB`、`rho_u/rho_d`、`rho_s`）可配置并有最小测试覆盖。

## 6. 风险与边界

- 风险 1：`rho_u/rho_d` 在低密度附近可能数值不稳定，需要阈值与回退策略。
- 风险 2：legacy 与 models 路径在非对称点的收敛性可能不同，需要分 backend 记录。
- 边界：本阶段不做文献再标定，不调整 `config/models/rpnjl/default.toml` 文献参数。

## 7. 立即下一步
