# 散射截面性能优化任务单（执行版，可勾选）

## 目标

梳理散射截面计算链路，清理历史冗余代码并完成热点优化，降低计算耗时且不改变数值口径。

## 架构依赖图联动（执行前置）

- 依赖图文档基线：`docs/architecture/dependencies.md`
- 依赖审计报告：`docs/architecture/dependency_review.md`
- 生成脚本：`scripts/dev/gen_deps.jl`
- 审计脚本：`scripts/dev/analyze_deps.jl`

执行命令（每轮性能优化前后各执行一次）：

```powershell
julia --project=. scripts/dev/gen_deps.jl
julia --project=. scripts/dev/analyze_deps.jl
```

产物要求：

- `dependencies.md` / `dependencies.mmd` 必须与当前代码结构一致；
- `dependency_review.md` 必须记录跨目录依赖与违规检查；
- 如出现新增跨层依赖，需在本任务单“执行记录”中说明原因与处置。
