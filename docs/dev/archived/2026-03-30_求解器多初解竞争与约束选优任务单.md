# 求解器多初解竞争与约束选优任务单

## 1. 目标

- 在 `src/models/constraint_solver.jl` 引入“候选解竞争”机制。
- 将连续性解作为候选之一，不再默认唯一。
- 仅从满足硬约束的候选中按 `pressure_max` 选优。

## 2. 范围

- [x] 多初解候选集合构造（连续性、默认种子、扰动、回退种子）。
- [x] 候选硬约束过滤（质量正值、残差阈值、有限值、Phi/Phi_bar 区间）。
- [x] 选优器实现（可解释的失败原因与候选比较摘要）。
- [x] 统一结果契约输出（给脚本/前端复用）。
