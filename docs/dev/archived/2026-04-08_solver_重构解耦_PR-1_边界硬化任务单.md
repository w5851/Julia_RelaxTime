- 入口层新增统一运行时参数解析 helper：`_resolve_common_runtime_options`、`_resolve_fixedmu_runtime_options`、`_resolve_fixedmu_multi_runtime_options`，统一承接 `xi/p_num/t_num/residual_norm_max` 的默认值与类型校验。
