# 旧架构（src/pnjl）到新架构（src/models）迁移执行任务单

更新日期：2026-02-20

---

## 1. 背景与目标

- [x] 已确认当前仓库存在双路径：`src/pnjl`（流程与兼容主链）+ `src/models`（模型抽象与新接口）。
- [x] 已确认现阶段不是“全量替换”，而是“渐进迁移”。
- [x] 目标：在不破坏现有扫描/workflow/服务入口的前提下，逐步把模型内核能力收敛到 `src/models`。
- [x] 目标：将 `src/pnjl` 收敛为编排层与兼容层，减少重复实现与耦合点。

---

## 2. 范围与非范围

### 2.1 本期范围（MVP）

- [x] 迁移/收敛“模型内核”相关能力（质量、热项、Ω组装、gap residual、求解器对接）到 `src/models`。
- [x] 维持 `src/pnjl/scans/*`、`src/pnjl/workflows/*` 作为流程入口，不做结构性搬迁。
- [x] 保证 `thermo_backend=:legacy|:models` 与 `solver_backend=:legacy|:models` 双后端可用。

### 2.2 非范围（本期不做）

- [x] 不将所有 `src/pnjl` 文件直接复制/重命名到 `src/models`。
- [x] 不重写前端/服务调用协议（`src/simulation/*` 入口保持稳定）。
- [x] 不在本期引入新增物理模型功能（仅做架构收敛与行为对齐）。

---

## 3. 现状盘点（已确认）

### 3.1 已确认事实

- [x] `src/models/pnjl/PNJLModel.jl` 仍复用 legacy solver（`src/pnjl/solver/Solver.jl`）。
- [x] `src/pnjl/core/ThermoFacade.jl`、`src/pnjl/core/EquilibriumFacade.jl` 已承担新旧后端桥接。
- [x] `src/simulation/FullServerApp.jl` 仍直接通过 `src/pnjl/PNJL.jl` 进入主链。
- [x] 单测 smoke 主链同时覆盖 `tests/unit/models/*` 与 `tests/unit/pnjl/*`，说明双路径均为在用路径。

### 3.2 核心缺口

- [x] `models` 的 PNJL gap 求解尚未完全摆脱 legacy solver 依赖。（通过显式开关与 fallback 收敛，默认行为保持兼容）
- [x] 部分模型能力在 legacy 与 models 间仍有重复/桥接层转发成本。（已形成裁剪候选清单）
- [x] 迁移完成判据（何时可裁剪 legacy core）尚未形成明确门槛清单。（已补齐并绑定测试）

## 4. 任务分解（可执行）

## P0（先做，1~2 天）：冻结边界 + 建立迁移门槛

- [x] 明确“模型层 vs 流程层”边界文档：
  - 模型层：`src/models/*`
  - 流程层：`src/pnjl/scans/*`、`src/pnjl/workflows/*`、`src/simulation/*`
  - 验收：文档提交并经自检无冲突描述。

- [x] 建立“可裁剪 legacy core”的门槛清单（Checklist）：
  - `PNJLModel.solve_gap` 可在 `solver_backend=:models` 稳定替代关键路径。
  - 关键 smoke 用例在 models 后端通过。
  - 回归基线偏差在容差内。
  - 验收：门槛清单写入本任务单并绑定对应测试。

- [x] 固化本期回归命令模板（最小集）：
  - `julia --project=. tests/unit/runtests.jl`
  - `UNIT_FILES=pnjl/test_tmu_scan_solver_backend_models_smoke.jl;pnjl/test_trho_scan_solver_backend_models_smoke.jl julia --project=. tests/unit/runtests.jl`

  - 验收：命令可在 CI/本地复现，失败能定位到具体层。

## P1（主工作，3~5 天）：收敛模型求解链到 models

- [x] 梳理并减少 `src/models/pnjl/PNJLModel.jl` 对 legacy solver 的硬依赖：
  - 优先保证 `solver_backend=:models` 在对称 μ 场景覆盖常用点。
  - 保留 `solver_backend=:legacy` 作为回退。
  - 验收：后端切换 smoke 全绿。

- [x] 在 models 路径补齐/统一 gap 相关接口语义：
  - `solve_gap` 入参与返回值在 PNJL/RPNJL/LegacyPNJL 间行为一致。
  - `omega/omega_components/number_densities` 参数语义一致。
  - 验收：新增或更新最小契约测试（models 目录）。

- [x] 降低桥接重复计算风险：
  - 检查 `ThermoFacade` / `ModelThermodynamics` / `EquilibriumFacade` 的重复转换与缓存点。
  - 仅做不改行为的收敛（提取公共转换逻辑）。
  - 验收：功能结果不变，回归通过。

## P2（收口，2~3 天）：裁剪候选与文档对齐

- [x] 更新架构说明文档（docs/api + docs/architecture）：

  - 验收：文档与代码实际行为一致。

- [x] 决策评审：是否进入“删除 legacy 冗余实现”的下一任务单。（结论：进入下一任务单，先从 C1/C3 的“转发收敛”开始）
  - 验收：输出评审结论（继续收敛 / 延后 / 拆分子任务）。
