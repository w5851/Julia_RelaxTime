# BU 介子数密度文献对齐审查

更新日期：2026-05-12

## 1. 任务目标

围绕当前仓库中的 BU 介子数密度实现，先从 `D:\Desktop\paper\docs\papers\介子数密度(及其比值)` 目录中选择**一篇最适合当前实现状态的主文献**，再用这篇文献的物理描述、变量定义、公式口径与适用边界做 fixed-point 审查，回答：

1. 当前 `current BU` 相比 `stable` 的主要抬升来自哪里；
2. `generalized BU` 为什么又把结果拉回 `stable` 量级；
3. `K/\pi` 的大偏差主要由 `n_K` 还是 `n_pi` 驱动；
4. 当前实现最值得怀疑的偏差源是什么。

本轮审查只做实验分支上的分析文档、诊断脚本和输出，不直接修改主线数值行为。

## 2. 候选文献清单

以下相关性说明只基于本地可读文件名、txt 转写稿或 PDF 首页/摘要，不引入外部信息。

1. `Wergieluk 等 - 2013 - Pion dissociation and Levinson\`s theorem in hot PNJL quark matter`
   - 相关性：给出 pion-only 的 generalized BU / Levinson 定理背景，适合做方法底座，不适合作为 `K/\pi` 审查主尺。
2. `Blaschke 等 - 2014 - Generalized Beth--Uhlenbeck approach to mesons and diquarks in hot, dense quark matter`
   - 相关性：是 generalized BU 热力学与 Mott/Levinson 结构的重要方法文献，但主体是 SU(2) meson/diquark，不直接面向当前 `2+1 flavor π/K` 数密度与 `K/\pi` 比值。
3. `Costa 等 - 2004 - Pseudoscalar mesons in hot, dense matter`
   - 相关性：偏介子谱与热致密介质中的性质演化，不是 BU 数密度或 `K/\pi` 主线。
4. `Costa 等 - 2005 - Analysis of the U(A)(1) symmetry-breaking and restoration effects on scalar-pseudoscalar spectrum`
   - 相关性：偏谱结构与对称性恢复，不是当前 BU 数密度主线。
5. `Blaschke 等 - 2017 - Mott dissociation of pions and kaons in hot, dense quark matter`
   - 相关性：直接讨论 `2+1 flavor` 下 `π/K` 的 Mott 解离、相移、连续态与异常 `K^+` 模，是当前 BU 传播子/相移底座的重要方法来源。
6. `Friesen 等 - 2019 - Kaon to Pion Ratio in SU(3) PNJL Model`
   - 相关性：直接讨论 `K/\pi` 比值与 charged splitting，但主要还是 pole / mass-splitting 现象学，不是完整 BU continuum 数密度口径。
7. `Blaschke 等 - 2020 - Using the Beth–Uhlenbeck Approach to Describe the Kaon to Pion Ratio in a 2 + 1 Flavor PNJL Model`
   - 相关性：直接给出 BU `K^\pm/\pi^\pm` 数密度公式、相移解释、异常 `K^+` 模与文献曲线来源；当前仓库的 `Blaschke:2019col` 目标资产就是沿这篇文献的 Figure 4 right panel 落盘。
8. `Blaschke 等 - 2020 - Chiral phase transition and kaon-to-pion ratios in the entanglement SU(3) PNJL model`
   - 相关性：同样直接讨论 BU/BW 与 `K/\pi`，但引入了 EPNJL、vector interaction、freezeout/critical-line 现象学层，比当前主线的最小 BU kernel 更“厚”。
9. `Blaschke 等 - 2021 - Mott dissociation and kaon to pion ratio in the EPNJL model`
   - 相关性：与上一篇接近，仍然是 BU/BW + EPNJL 的更完整现象学版本，适合作为扩展对照，不是最小 fixed-point 主尺。
10. `Blaschke 等 - 2024 - Thermodynamics of quark matter with multiquark clusters in an effective Beth-Uhlenbeck type approach`
    - 相关性：是更一般的 effective BU 集群热力学框架，范围明显超出当前 `π/K` 最小实现。

## 3. 主文献选择

### 3.1 结论

本轮审查选用：

- `Blaschke 等 - 2020 - Using the Beth–Uhlenbeck Approach to Describe the Kaon to Pion Ratio in a 2 + 1 Flavor PNJL Model`

### 3.2 选择理由

它比同目录下其他候选更适合作为**当前实现状态**的审查标尺，原因如下：

1. **直接讨论目标物理量**
   - 该文直接讨论 `K^\pm/\pi^\pm` 比值；
   - 文中把介子数密度写成 BU 相移积分，并明确把 anomalous `K^+` mode 与比值行为联系起来。

2. **公式层与当前实现可直接对照**
   - txt 转写稿中给出稳定粒子数密度公式（文中 Eq. (7) 周边）；
   - 给出 generalized BU 数密度公式
     ```math
     n_M(T)=d_M \int \frac{d^3q}{(2\pi)^3}\int\frac{d\omega}{2\pi} g_M(\omega)\frac{d\delta_M(\omega,q)}{d\omega},
     ```
     并说明其来自 meson phase shift；
   - 这正好对应当前仓库的：
     - `stable_meson_number_density`
     - `phase_shift_meson_number_density_derivative_reference`
     - `phase_shift_meson_number_density`（分部积分口径）

3. **与当前 `current BU / generalized BU` 口径最接近**
   - 当前 `docs/reference/formula/relaxtime/meson_density/MesonDensity_BU相移公式.md` 已把 BU 主公式的直接参考写法落到 `Blaschke:2020bzh` / `Blaschke:2021yml`；
   - 但就“最小 kernel 审查”而言，这篇 `Using the Beth–Uhlenbeck Approach...` 更直接，因为它不再额外引入 EPNJL/向量耦合/更厚的 freezeout 现象学层。

4. **适合 fixed-point 最小对照**
   - `2017 Mott dissociation...` 更偏方法底座，不够直接落到数密度；
   - `2020/2021 EPNJL` 两篇虽然更完整，但比当前主线多了一层 entanglement / vector / path 拟合设定；
   - 当前仓库最需要先查清的不是“哪条 phenomenology path 拟合最好”，而是“同一 fixed point 下为什么 current/gbu/stable 会分叉得这么大”。

### 4.2 当前最关键的口径提醒

本轮 fixed-point 审查最重要的不是文献 path reproduction，而是下面两件事：

1. **主文献中的 `μ_K` 不是默认零**
   - 如果 charged `K/\pi` 还沿用 `μ_K = 0`，就已经偏离主文献定义；
   - 这条偏离会直接作用到 `n_K`，不是小修小补级别。

2. **主文献的 BU 结果要求相移/连续态处理是自洽的**
   - 如果 `current BU` 主要由大面积正相位窗口直接抬高，而不是由受控的 bound + continuum 结构给出，就要优先怀疑 phase normalization / Levinson 边界治理。

### 5.2 neutral aggregate fixed points

选点：

- `μ_B = 0`
- `T = 208 MeV`
- `T = 220 MeV`

理由：

- 当前主 regression 已覆盖这两点；
- 它们足够暴露 `stable / strict BW / current BU / generalized BU` 的量级分叉；
- 不需要先引入 freezeout/crossover 路径噪声。

  - `n_K = 0.1960`

### 5.4 直接回答四个问题

#### Q1. 当前 `current BU` 相比 `stable` 的主要抬升来自哪里？

主要来自 **`n_K` 的异常抬升比 `n_pi` 更强**。

以 `T = 208 MeV` 为例：

- `n_pi(current) / n_pi(stable) ≈ 8.20`
- `n_K(current) / n_K(stable) ≈ 19.73`

所以 `K/pi` 被抬高首先是 `K` 通道更激进，而不是 `π` 通道单独失真。

#### Q2. `generalized BU` 为什么会把结果拉回 `stable` 量级？

因为当前实现中的 `gbu` 不是换了一套传播子，而是**对同一个相位结构改用了更强抑制的 phase weight**

```julia
F_gbu(δ) = δ - 0.5 * sin(2δ)
```

这会显著压低 current 口径下大面积正相位区对 `g(1+g)` 积分的贡献。现有 fixed-point 输出表明：

- `current` 与 `gbu` 的差别主要不是来自不同的 meson mass / gamma；
- 而是来自**同一 phase profile 被不同 weighting 方式处理**。

#### Q3. `K/pi` 的大偏差主要由 `n_K` 还是 `n_pi` 驱动？

在 neutral aggregate fixed point 上，**主要由 `n_K` 驱动**。

在 charged finite-density 诊断点（`T=170 MeV, μ_q=80 MeV, μ_s=0.2 μ_q, μ_\pi=100 MeV`）上，`μ_K` 规则切换时也是 `n_K` 在动、`n_pi` 基本不动：

- `K^+/\pi^+`
  - `μ_K = 0` 时：`0.0261`
  - `μ_K = μ_u - μ_s = 64 MeV` 时：`0.2485`
- `K^-/\pi^-`
  - `μ_K = 0` 时：`0.0303`
  - `μ_K = μ_s - μ_u = -64 MeV` 时：`0.0207`

这说明 charged ratio 的文献偏差若出现大幅变化，首先要查 `n_K` 的口径，而不是先怪 `n_pi`。

#### Q4. 是否存在明显的口径不对称、重复计数风险、阈值处理问题或归一化问题？

有，且最明显的是两类：

1. **charged `μ_K` 口径不对称**
   - 文献要求 `μ_{K^\pm}` 跟随 flavor chemical potentials；
   - 当前 `blaschke2019_mu_pi_100` profile 取 `μ_K = 0`；
   - 这是定义层偏差，不是纯数值误差。

2. **phase normalization / Levinson 边界治理不够显式**
   - `current BU` 相比 `stable` 的放大过强；
   - `meson_density_phase_e5_derivative_vs_byparts.csv` 显示，在相同窗口下 `current` 的分部积分值仍系统性高于导数离散参考，约在 `20%` 量级；
   - `meson_density_phase_e5_strict_candidates.csv` 又显示，简单的“尾部相位平移”会直接把 current/gbu 拉到大负值，说明问题**不是单个常数偏移可修好**，而是 phase baseline / branch / continuum compensation 的整体处理需要重查。

## 6. 最可疑的三个问题源

按当前证据强度排序：

### 1) charged `μ_K` 规则与主文献不一致

最直接，且一改就显著影响 `n_K` 与 `K^+/\pi^+`。

具体位置：

- `config/physics/meson_chemical/blaschke2019_mu_pi_100.toml`
- `src/models/scans/MesonChemicalProfiles.jl`

### 2) current BU 的 phase-weight / by-parts 口径过于依赖未显式治理的 phase baseline

当前 `phase_shift_meson_number_density` 直接把 unwrapped `δ(ω,q)` 送入 `g(1+g)·δ/T` 双积分，但没有把“高能端回零 / Levinson 归一化”做成显式条件。

具体位置：

- `src/relaxtime/MesonDensity.jl`
  - `_unwrap_phases`
  - `_phase_shift_weighted_phase`
  - `phase_shift_meson_number_density`

### 3) aggregate neutral kernel 与 charged literature target 之间存在边界错位

当前主 regression gate 在 `μ_B=0` aggregate `:pi/:K` 上跑；主文献讨论的却是 charged ratio、有限密度、`μ_\pi`/`μ_K` 非平衡口径。

这不意味着 current kernel 一定错，但意味着：

- 不能把 aggregate fixed-point 与 charged literature curve 混成同一类结论；
- 也不能仅凭 charged reproduction 偏差，就跳过 kernel fixed-point 审查。

## 7. 最小修复 / 最小验证建议

如果只做最小改动，建议顺序如下：

1. **先做 profile 层最小修复验证**
   - 新增一个面向 `Blaschke:2019col` 的 meson chemical profile 变体；
   - 只改 `μ_K_rule = "mu_u_minus_mu_s_signed"`；
   - 不动 kernel，先量化 charged `K^\pm/\pi^\pm` 能被拉动多少。

2. **再做 current BU 的最小 kernel 诊断**
   - 不直接改生产 helper；
   - 先在分析脚本层把 phase baseline / branch / Levinson 检查输出固化；
   - 核查 current by-parts helper 与导数参考 helper 在同一 `(q, ω)` 窗口下为何仍有系统偏高。

3. **最后才考虑是否需要动正式 `current` 口径**
   - 只有当 phase normalization 的误差来源被物理上说清楚后，才考虑改 `src/relaxtime/MesonDensity.jl`；
   - 否则应继续把修订停留在 analysis/reference 层。
