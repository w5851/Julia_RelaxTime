# Friesen 2019 曲线验证口径说明

更新日期：2026-05-04

目的：固定 `Friesen:2019ojk` 曲线提取结果在当前仓库中的角色、边界与后续接入方式，避免把“已结构化外部曲线数据”误当成“已满足 formal validation 条件的严格真值”。

补充说明（热项积分口径）：

1. `Friesen:2019ojk` 正文公式(2)把 PNJL 热项明确写成 `∫_0^∞ dp`；
2. 同页真空项使用显式三维 cutoff `Λ`，即真空项与热项在正文层是不同正则化口径；
3. 因此，在本仓库做 Friesen 风格复现时，热项动量积分上限不应默认绑定到仓库历史实现中的 `p_max = 10 fm^-1`；
4. 当前仓库已把该热项上限下沉为 profile/config 项，可显式配置 `thermal_p_max_MeV`；
5. 诊断上看，`20 fm^-1 × ħc` 已足够接近该热项上限的数值收敛区，但当前 PNJL solver/continuation 链在该更大上限下尚不稳定；
6. 因此，`friesen2019_poly` 当前默认仍保留 legacy-stable 的 `10 fm^-1 × ħc`，待 solver 稳定化后再正式升格到更接近 `∫_0^∞ dp` 的近似值。

补充说明（正文明写范围）：

1. 截至当前核查，`Friesen:2019ojk` 正文与当前已读引用链能明确支持的是“热项写作 `∫_0^∞ dp`”这一公式层口径；
2. 但尚未在正文中找到“热项数值积分实际取到多大上限”“是否在实现里采用有限截断近似 `∞`”的明确说明；
3. 因此，若后续发现本仓库在更大 `thermal_p_max` 下得到的 `μ_B=0` crossover 温度高于文献图值，这可以作为一个合理诊断方向，但当前不能把它表述为文献已明说的事实。

## 2. 这些数据的来源与可信边界

这些曲线不是从截图做 path 拟合得到的，而是基于 arXiv source 中 EPS 文件内嵌的 Mathematica `GraphicsBox -> LineBox` 对象直接提取。

这意味着：

1. 对于“曲线形状与采样点”这一层，当前可信度较高；
2. 它们适合作为：
   - 外部结果层 target
   - 文献曲线复现输入
   - 后续 charged / freeze-out 子链的结构化样本

但也要明确边界：

1. 这些 CSV 只给出**曲线结果**；
2. 它们并不自动给出生成这些曲线所需的**完整路径参数化 / 化学势构造 / 现象学设定**；
3. 因此不能仅凭这些曲线，就反推出一条可严格重复运行的 literature workflow。

## 3. 当前治理定位

当前建议把这批 `Friesen 2019` 曲线固定为：

- **B 类外部结果样本**
- **charged / freeze-out / charged-ratio 子链的结果层参考**
- **可结构化、可留档、可后续消费的 literature target**

而不是：

- 当前 `\mu_B = 0` 总 `K/\pi` 主线的 regression 真值
- 当前 formal validation 的首个 pass/fail 样本

  - 当时脚本没有显式固定 `pnjl / physics profile`

进一步隔离实验显示：

1. 在默认 profile 下：
   - 若使用 charged meson chemical profile（`mu_pi=135` rule），当前 overlap 区间内：
     - `K+/pi+` mean rel diff 约 `0.23`
     - `K-/pi-` mean rel diff 约 `0.13`
2. 在默认 profile 下改成 neutral meson chemical profile 后：
   - `K+/pi+` mean rel diff 反而升到约 `0.94`
   - `K-/pi-` mean rel diff` 反而升到约 `2.86`
   - 说明 charged chemical profile 不是主要误差源；它反而把结果朝文献 target 拉近了一些
3. 在真正切到 `friesen2019_poly / friesen2019_base` 后：
   - `K+/pi+` 与 `K-/pi-` 偏差显著放大
   - 这说明当前主误差源不在 comparison 代码本身，也不主要在 `mu_pi / mu_K` 口径，而更可能在：
     - Friesen 风格 EOS / 参数映射仍未完全对齐
     - phase-line 语义与文献 target 的对应关系仍有偏差
     - thermal cutoff / 有效势 / convention 等更上游实现口径

因此，当前“可比较点误差来源”的优先级判断应固定为：

- **第一优先级**：确认并收口真正的 `Friesen profile` 口径及其上游实现差异
- **第二优先级**：再讨论 charged profile、插值比较等下游细节

补充新增（2026-05-05，`m_\pi` 异常偏大的直接根因）：

- 进一步把问题收缩到最简单单点后发现：
  - 在 `Friesen profile`（`friesen2019_poly / friesen2019_base`）下，
  - 即使在 `\mu_B = 0, T = 150 MeV`，
  - 当前仓库也会给出：
    - `m_\pi ≈ 788 MeV`
    - `\Gamma_\pi ≈ 1166 MeV`
    - `m_K ≈ 756 MeV`
  - 这已经足以证明问题不是 phase-line 几何或 comparison 插值造成的

- 同一点上，当前平衡态的轻夸克质量只有：
  - `m_u ≈ m_d ≈ 74.9 MeV`
  - `m_s ≈ 305 MeV`
  - 对比仓库默认 profile 在同一点：
    - `m_u ≈ 364 MeV`
    - `m_s ≈ 547 MeV`

- 因此，当前 Friesen profile 下 `K/\pi` 被整体抬高的最直接链条是：

1. constituent light-quark masses 被压得异常低
2. pion 通道阈值被压低，导致当前求解落到高质量宽共振支
3. `m_\pi` 异常偏大，`n_\pi` 被严重压低
4. `K/\pi` 因分母过小而整体偏高

- 一个很重要的判断是：
  - `\mu_B=0` 下的 order-parameter 归一化曲线看起来并不算离谱（例如 quicklook 给出的 `T_c ≈ 228.5 MeV`）
  - 但这不能证明 profile 已对齐
  - 因为**真正出问题的是“同一组 condensate 经由当前 `(G,K)` convention 映射到 constituent masses”这一步**

- 进一步的 post-hoc convention 敏感性诊断（仅用于定位，不是正式物理结论）显示：
  - 在当前 Friesen 平衡态的同一组 condensate 上，
  - 若保持现有映射 `G=g_S/2, K=-g_D`，得到 `m_u ≈ 75 MeV`
  - 若只翻转 `K` 符号，可升到约 `297 MeV`
  - 若再把 `G` 提高到当前两倍、同时 `K` 取正/减弱，可进入约 `366–477 MeV` 区间
  - 这强烈暗示当前 `Friesen` 口径下最可疑的环节是 **`G/K` convention 映射及其符号/系数**

因此，当前主线判断可以进一步收紧为：

- `Friesen Fig.5` 的大误差首先不是 path 层问题
- 首先应回到 **`Friesen` 文献公式与本仓库 `\phi_i` / `G` / `K` 变量约定之间的精确映射** 去核查

补充新增（2026-05-05，当前 worktree 代码层复核）：

- 为避免把上面 `m_u ≈ 75 MeV` 的历史诊断快照误当成“当前树上仍然如此”，已在当前 worktree 上直接用

  - `physics_profile = friesen2019_base`

  - `T = 150 MeV`
  
  复核 `solve_gap -> calculate_mass_vec`。

- 当前树上的直接结果更极端：
  - `\phi_u = \phi_d ≈ -0.0665 fm^{-3}`
  - `\phi_s ≈ -1.5861 fm^{-3}`
  - `\Phi = \bar\Phi ≈ 0.405`
  - `m_u = m_d ≈ 8.77 MeV`
  - `m_s ≈ 235.76 MeV`

- 对比当前仓库默认 profile 同一点：
  - `\phi_u = \phi_d ≈ -1.8255 fm^{-3}`
  - `\phi_s ≈ -2.2198 fm^{-3}`
  - `\Phi = \bar\Phi ≈ 0.053`
  - `m_u = m_d ≈ 363.91 MeV`
  - `m_s ≈ 547.15 MeV`

- 因此，在**当前实现状态**下，`Friesen profile` 不只是“light-quark masses 偏低”，而是已经在 `T=150 MeV, \mu_B=0` 进入了几乎恢复手征的轻夸克质量区间。这会直接导致：

1. `\pi` 通道阈值被极大压低；
2. 后续介子极点求解极易落到高质量宽共振支；
3. `n_\pi` 被严重压低；
4. `K/\pi` 整体显著偏高。

- 这条代码层复核进一步强化了之前的优先级判断：
  - **主误差源一定在更上游**；
  - 当前首先要查的是 `Friesen` profile 在本仓库中的 EOS / gap / `(G,K)` convention / condensate 口径映射；
  - 而不是 charged profile、插值方法或 path overlap 这类下游细节。

- 同时也要注意：上面 `m_u ≈ 8.8 MeV` 与此前文档内记录的 `m_u ≈ 75 MeV` 并不一致，因此后续若继续引用单点数值，应优先以“当前 worktree 复核值”为准，并把旧数值视作早期诊断快照而非稳定基线。

补充新增（2026-05-05，更上游的 branch / pressure 诊断）：

- 对 `Friesen profile` 在同一个最小单点
  - `profile = friesen2019_poly`
  - `physics_profile = friesen2019_base`
  - `T = 150 MeV`
  - `\mu_B = 0`
  
  继续做 seed 分支隔离后发现：当前并不只有“一组略偏低的平衡态”，而是至少存在两支可收敛自洽解：

1. `hadron-like` 支（由 `HADRON_SEED_5` 或大凝聚人工 seed 收敛到）
   - `\phi_u \approx -2.73 fm^{-3}`
   - `\phi_s \approx -3.83 fm^{-3}`
   - `\Phi \approx 0.379`
   - `m_u \approx 74.9 MeV`
   - `m_s \approx 305 MeV`
2. `quark-like` 支（由 `QUARK_SEED_5` 或小凝聚人工 seed 收敛到）
   - `\phi_u \approx -0.0665 fm^{-3}`
   - `\phi_s \approx -1.586 fm^{-3}`
   - `\Phi \approx 0.405`
   - `m_u \approx 8.77 MeV`
   - `m_s \approx 235.76 MeV`

- 更关键的是，这两支不是单纯“不同初值导致的数值漂移”，因为其热力学势明显不同：
  - `hadron-like` 支：`P \approx 27.45`
  - `quark-like` 支：`P \approx 28.08`
  - 即 `quark-like` 支压强更高、`\Omega` 更低

- 因而，至少在当前仓库这套 `Friesen profile` 实现下：
  - `T=150 MeV, \mu_B=0` 的**全局平衡态**更接近 `quark-like` 小凝聚支；
  - `m_u \approx 75 MeV` 那支更像是一个局域/亚稳分支，而不是当前 profile 的全局平衡解。

- 这条结论会直接改变之前对 `\mu_B=0` quicklook 的解读：
  - 之前那条“看起来不算离谱”的 order-parameter 归一化曲线，不能再当作 `Friesen profile` 已基本对齐的证据；
  - 它很可能只是 continuation 沿着某个局域支续算出来的结果；
  - 换言之，**目前 `Friesen profile` 在当前仓库里首先暴露的是 EOS / branch-selection 层异常，而不是 meson-density comparison 层异常。**

- 进一步做“耦合块 vs Polyakov 块”拆分后，结论也更清晰：

1. `default couplings + friesen polynomial Polyakov`
   - 仍给出 `m_u \sim 354 MeV`
   - 说明仅替换 `Friesen` 的多项式 Polyakov 势，并不会把轻夸克质量压塌
2. `friesen couplings + default log Polyakov`
   - 仍会掉到 `m_u \sim 9 MeV`
   - 说明主问题不在 Polyakov 势参数化本身，而在更上游的：
     - `Friesen` 耦合参数进入当前 EOS / gap 方程后的口径
     - `\phi_i / G / K` convention 映射
     - 或当前仓库对该 profile 的 branch-governance / equilibrium selection 语义

- 因此，这一轮诊断后，应把优先级再进一步收紧为：

1. **第一优先级**：确认 `Friesen` 文献公式与本仓库 mean-field / EOS / gap 链之间的精确映射是否真的闭合；
2. **第二优先级**：确认在 `Friesen` 口径下，当前 solver 的 branch selection 是否与文献隐含的“物理解”选择一致；
3. **第三优先级**：在上面两点未澄清前，不再把 meson ratio 偏差解释成 path / charged profile / 插值问题。

补充新增（2026-05-05，branch-direction 受控实验）：

- 在确认主公式层 `Ω / m_i / \langle\bar q q\rangle / U(\Phi)` 与 `Friesen 2019` 已基本闭合之后，继续在**不改公式映射**前提下做了最小 branch 实验：
  - 固定同一条 `Friesen 2019 Fig.5 top` 复现路径（`fig3_left / case1_pnjl`）；
  - 固定同一套 `\mu_s = 0.55 \mu_u` 与 charged meson chemical profiles；
  - 只改变：
    1. 初始 seed（`HADRON_SEED_5` vs `QUARK_SEED_5`）
    2. 路径 continuation 方向（从高 `T/\mu_B` 端正向扫，还是从高密低温端反向扫）

- 结论一：**只改第一点 seed，不足以稳定切 branch；路径方向本身会决定 branch。**

  - 若按当前默认排序，从 `\mu_B \approx 0, T \approx 217 MeV` 的高 `T/\mu_B` 端开始 continuation：
    - `HADRON_SEED_5` 与 `QUARK_SEED_5` 都会快速落到同一条小质量支；
    - 前几个点上两者给出的
      - `m_u`
      - `\Phi`
      - `m_{K^+}`
      基本重合；
    - 因而“只换首点初值”不足以把这条路径锁在另一支上。

- 结论二：**若反向从高密低温端开始 continuation，则两条平衡态支可以被稳定分开。**

  反向 continuation 下：

1. `reverse_hadron`
   - 起始点保持在较大轻夸克质量支：
     - `m_u \sim 0.36\text{--}0.38 GeV`
   - `K^+` 质量约 `455\text{--}466 MeV`
2. `reverse_quark`
   - 起始点保持在较小轻夸克质量支：
     - `m_u \sim 0.040\text{--}0.042 GeV`
   - `K^+` 质量约 `478\text{--}538 MeV`

  这说明当前 `Friesen profile` 的 branch 选择不仅受 seed 影响，还强依赖 continuation 的起点和扫描方向。

- 结论三：**若以文献 `Fig.5 top` 曲线为弱判据，反向 hadron-like 分支比反向 quark-like 分支更接近 target，但仍明显偏高。**

  先看当前 stable 口径下能稳定比较的 `K^-/\pi^-`：

  - `reverse_hadron`
    - 在代表点
      - `x=T/\mu_B=0.2`：model `0.0728` vs target `0.0282`
      - `x=0.4`：model `0.1776` vs target `0.0812`
      - `x=0.7`：model `0.2485` vs target `0.1234`
      - `x=1.0`：model `0.2760` vs target `0.1408`
      - `x=1.8`：model `0.3148` vs target `0.1620`
  - `reverse_quark`
    - 对应代表点则更高：
      - `x=0.2`：`0.0862`
      - `x=0.4`：`0.1945`
      - `x=0.7`：`0.2667`
      - `x=1.0`：`0.2948`
      - `x=1.8`：`0.3349`

  因此：
  - hadron-like 分支在结果层上确实“朝文献靠近一些”；
  - 但无论 hadron-like 还是 quark-like，当前都明显高于 target，量级上仍未复现文献曲线。

- 结论四：**branch 不是唯一根因，但已经确认是当前 workflow 误差的重要组成部分。**

  更具体地说：

1. branch 方向/起点会显著改变 `m_u` 与 charged-kaon 有效质量；
2. 这会显著改变 `K^-/\pi^-`；
3. 但即便选取更接近文献的 hadron-like 分支，结果仍整体偏高约 `2x` 左右；
4. 因而后续仍需继续排查：
   - `Friesen` 文献 phase-line 本身的生成语义；
   - stable 口径是否已足够接近文献所用 meson treatment；
   - charged channel / chemical profile 与 branch 之外的上游 EOS 差异。

- 当前主线可据此固定一条工作判断：

  - **可以把“路径方向 / branch 锁定”视作当前 Friesen 复现链中的一个真实治理维度；**
  - 但在当前证据下，**不应把它误判成全部误差的唯一来源。**

## 6. 与当前 formal validation 主线的关系

当前 formal validation 的优先入口，仍应按已固定判断继续下沉到 lower-layer target：

1. `Blaschke:2016sqn` Figure 8
   - mesonic partial pressure
   - explicit `\mu/T = const` trajectories
2. `Blaschke:2020bzh` Figure 2 left panel
   - `\mu_B = 0`
   - meson masses

而 `Friesen:2019ojk` 当前更适合作为：

- 后续 charged-ratio phenomenology 的结构化对照层

不是第一批 formal validation kernel target。

## 7. 当前结论

截至 `2026-05-04`，可以把 `Friesen 2019` 曲线数据的项目内角色固定为：

1. **已成功结构化的外部结果层数据**
2. **可复用的 charged-ratio literature target 来源**
3. **不直接升格为当前 formal validation / regression 真值**

这批数据当前最主要的价值是：

- 证明本地 paper-dev 已具备从 source EPS 稳定提取高质量文献曲线的能力；
- 为后续 charged / freeze-out / `K^\pm/\pi^\pm` 子链提供更可靠的外部结果输入；
- 让 formal validation 可以更从容地优先落在路径定义充分、公式口径更硬的 lower-layer 文献目标上。

- 为避免继续把 `Friesen Fig.5` 的大偏差归因到 path/interpolation/charged-profile，下游链路之外又做了一轮更小的 `μ_B=0` 单点诊断：
