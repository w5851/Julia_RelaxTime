# 物理主链路验收矩阵 v1（截面/弛豫时间）

## 目标

建立固定验证点与统一容差口径，为 CI 与对比报告提供同一基线。

## 固定点集（v1）

- $(T, \mu)$ = (0.75, 0.00)
- $(T, \mu)$ = (0.90, 0.00)
- $(T, \mu)$ = (1.05, 0.00)
- $(T, \mu)$ = (0.90, 0.15)

说明：单位遵循项目自然单位口径；若输入为 MeV，先统一换算。

## 比较量

- 传输系数：`η`、`σ`、`ζ`
- 链路中间量（可选）：总截面、平均散射率、关键道矩阵元

## 容差（v1）

- `rtol = 8e-2`
- `atol = 1e-6`

## 输出与归档

- 原始结果：`data/outputs/results/`
- 结构化报告：`docs/dev/archived/`（阶段收口时归档）
- 脚本入口：`scripts/relaxtime/` 与 `tests/perf/relaxtime/`

## 变更规则

当算法升级需调整容差时，必须同步记录：

1. 变更原因
2. 新旧口径对比
3. 对应 smoke/full 回归结果
