# Phase F F4 文献结果验证目标分层清单

更新日期：2026-05-03

目的：把本地参考文献库中与介子数密度 / `K/\pi` 比值相关的结果，按“当前主线可直接对比 / 需单独现象学链 / 暂不适合做回归目标”分层，作为后续验证目标治理清单。

相关输入：

- 本地文献库目录：
  - `paper_lib/docs/papers/介子数密度(及其比值)/`
- 当前主线口径：
  - `μ_B = 0`
  - `ξ = 0`
  - 总 `π/K` 数密度
  - `μ_π = 0`
  - `μ_K = 0`
  - 当前阶段性窗口 `T = 208:2:220 MeV`

## 1. 分层标准

### A 类：可直接提取并进入当前主线验证

要求至少满足：

1. 与当前主线是同一类物理量：
   - 总 `K/\pi` 或可直接换算到总 `K/\pi`
2. 不依赖 freeze-out 线 / critical line / collision-energy 映射
3. 不依赖 `μ_π`、`μ_s` 等额外现象学输入
4. 最好是 `μ_B = 0` 温扫，或至少可直接抽出对应极限

### B 类：需人工转录或需单独现象学链后才可比

典型特征：

1. 讨论的是 `K^+/\pi^+`、`K^-/\pi^-`
2. 依赖 freeze-out 线 / critical line / `T/μ_B`
3. 需要 `μ_π`、`μ_s`、anomalous mode 等额外设定
4. 当前主线若不扩展口径，不能直接做 regression 真值

### C 类：当前暂不适合作为验证目标

典型特征：

1. 主要提供公式来源或方法论支持
2. 不直接给当前链可比的 `n_π(T)` / `n_K(T)` / `K/\pi(T)`
3. 或口径与当前项目主线差得太远，短期内没有可执行对齐路径

## 2. 当前文献分层结果

### 2.1 A 类：当前未发现强候选

截至本轮盘点，当前本地文献库中**没有明显属于 A 类的强候选**。

原因不是文献无价值，而是当前库中与 `K/\pi` 直接相关的几篇核心文献，主目标几乎都偏向：

1. `K^+/\pi^+` horn
2. freeze-out / critical line
3. `μ_π` / `μ_s`
4. charged-yield phenomenology

而不是当前项目最小主线的：

1. 总 `K/\pi`
2. `μ_B = 0`
3. 平衡态温扫

### 2.2 B 类：可作为后续现象学验证目标的主力

#### `Blaschke:2016sqn` (2017)

角色：

1. 传播子 / BU / Mott 公式的重要来源
2. 含 freeze-out / horn 讨论

当前分层：`B`

原因：

1. 文中明确使用 `μ_s = 0.2 μ`
2. 沿 `μ/T = const` 轨迹讨论
3. 结果与 freeze-out / heavy-ion yield 语境绑定
4. 涉及 `K^+/\pi^+` 与 `K^-/\pi^-`

当前建议：

1. 不进入当前 `μ_B = 0` 主线 regression
2. 作为未来 charged / freeze-out 子链的重要验证目标

#### `Blaschke:2019col` (2020, Particles)

角色：

1. 当前最直接的 BU `K^+/\pi^+` 现象学文献之一
2. generalized BU 与 partial density/pressure 比较来源

当前分层：`B`

原因：

1. 明确比较 `K^+/\pi^+` 与 `K^-/\pi^-`
2. 使用 chemical freeze-out line / critical line
3. 结果对 `μ_π` 很敏感
4. generalized BU 也在 charged-ratio 场景下出现

当前建议：

1. 未来若开 `charged + freeze-out + μ_π` 子链，应优先提取此文的图/点
2. 当前先不把它当作总 `K/\pi` regression 目标

#### `Blaschke:2020bzh` (2020, EPNJL)

角色：

1. EPNJL 版本的 charged `K/\pi` 现象学链
2. 比较 BW 与 BU、freeze-out 与 critical proxy 的重要参考

当前分层：`B`

原因：

1. 目标是 `K^+/\pi^+` / `K^-/\pi^-`
2. 沿 `(pseudo-)critical line` 作为 freeze-out proxy
3. 引入 `x = T/μ_B`
4. 文中明确使用 `μ_s = 0.55 μ_u`、非平衡 pion chemical potential 等设定

当前建议：

1. 后续做 horn 子链时，优先作为 EPNJL 侧验证目标
2. 当前不直接进入主线 regression

#### `Blaschke:2021yml` (2021)

角色：

1. 2020 EPNJL horn 逻辑的延伸和总结
2. charged ratio、freeze-out、`μ_π` 的压缩版本参考

当前分层：`B`

原因：

1. 文中明确围绕 `K^+/\pi^+` horn
2. 沿 phase transition / freeze-out line
3. 强调 nonequilibrium pion chemical potential

当前建议：

1. 可作为后续 charged-horn 子链的补充验证文献
2. 不直接做当前总 `K/\pi` 主线 regression

#### `Friesen:2019ojk` (2019)

角色：

1. SU(3) PNJL 下 charged `K/\pi` 的前置现象学参考
2. 强调 freeze-out / chiral transition line

当前分层：`B`

原因：

1. 文章主目标就是 `K^+/\pi^+`
2. 使用 freeze-out line 语境
3. 不是当前 BU 主线的总比值口径

当前建议：

1. 未来可作为“非-BU charged 现象学对照”
2. 当前不进入主线 regression

新增状态（`2026-05-04`）：

1. 已在外部 paper-dev 侧完成 source-EPS 级曲线结构化：
   - Figure 6 `K^+/\pi^+` 三条 matter-assumption 曲线
   - Figure 5 top panel `K^+/\pi^+` / `K^-/\pi^-` 曲线
2. 当前这些曲线的最佳定位是：
   - charged-ratio literature target 来源
   - 后续 charged / freeze-out 子链的结果层对照输入
3. 当前仍不建议直接升格为 formal validation，原因是：
   - 曲线结果虽已结构化，但 path / profile / workflow 对齐仍未闭环
4. 相关口径页：
   - `docs/dev/active/2026-05-04_Friesen2019曲线验证口径说明.md`

## 3. 当前最合理的验证优先级

### Priority 1：先把项目内四条链的 baseline/regression 固定

这是当前已完成的部分：

1. stable
2. current BU
3. gbu reference
4. strict BW Stage2

这一步先保证：

1. workflow 契约不漂移
2. 项目内数量级分工不漂移

### Priority 2：若要接文献，先做“当前主线可比口径”的补充目标

当前文献库里没有强 A 类候选，因此这一层可能需要：

1. 继续筛查是否有 `μ_B = 0`、总 `K/\pi`、平衡态温扫图
2. 若没有，就先不强行把 horn 文献塞进当前主线 regression

### Priority 3：单开 charged / freeze-out 现象学子链

这是当前最有希望把文献结果真正对上的方向：

1. `K^+/\pi^+`
2. `K^-/\pi^-`
3. freeze-out / critical line
4. `μ_π`
5. `μ_s`

若未来进入这条链，最优先提取目标建议是：

1. `Blaschke:2019col`
2. `Blaschke:2020bzh`
3. `Blaschke:2021yml`

## 4. 当前可执行结论

就 `F4` 当前阶段而言，可以明确写下：

1. 本地文献库中与 `K/\pi` 直接相关的核心文献，大多属于 `B` 类
2. 当前主线没有明显的 `A` 类强候选可直接拿来做 regression 真值
3. 因此当前更合理的做法是：
   - 先固定项目内 baseline/regression
   - 再单独规划 charged / freeze-out 文献对照子链

## 5. 新增筛查：formal validation 入口应否下沉到更低层

截至 `2026-05-04`，结合当前 `Blaschke:2019col` right-panel 已被降格为

- workflow / path semantics reproduction
- charged / freeze-out 生产链路打通样本

之后，重新回看本地库，一个更稳妥的判断是：

**如果 formal validation 坚持“必须直接对 `K/\pi` 比值”，那么当前本地库里仍然没有强的首选目标；但如果允许 formal validation 先下沉到更低层的 BU thermodynamics / meson-spectrum 口径，则已经有更硬的候选。**

### 5.1 候选 F1：`Blaschke:2016sqn` (2017) Figure 8 mesonic partial pressure

当前判断：**最适合作为首个严格 external validation 入口**

原因：

1. 路径定义充分：
   - 文中明确写出 pressure-vs-temperature 沿 `\mu/T = 0, 0.5, 1.0, 2.0` 轨迹计算；
   - 对 `\mu/T = 0` 尤其简单，可先从当前最接近主线的零化学势轨迹开始。
2. 输出口径明确：
   - 目标量是 mesonic partial pressure / total pressure 分量；
   - 图注与正文都明确了各分量的含义。
3. 结构化复现友好：
   - 不依赖 stitched freeze-out path；
   - 不依赖 `\mu_\pi(x)`、`\mu_s(x)` 拟合函数；
   - 不依赖 charged-ratio 的现象学配方。
4. 与当前项目主线关系近：
   - 同样是 BU / phase-shift thermodynamics；
   - 更适合作为“相移热力学核”的 formal validation。

代价：

1. 这不是直接的 `K/\pi` 比值；
2. 需要把当前 meson-density / meson-pressure 结果出口再整理成一条更明确的 thermodynamics validation 链。

建议角色：

- 作为 **formal validation Tier-1 / kernel-level external target**

### 5.2 候选 F2：`Blaschke:2020bzh` Figure 2 left panel meson masses at `\mu_B = 0`

当前判断：**适合作为辅助 formal validation 入口，但更偏 meson-mass 层**

原因：

1. 路径定义充分：
   - 明确是 `\mu_B = 0` 下的温度扫描；
2. 输出口径明确：
   - 介子质量与阈值线；
3. 结构化复现容易：
   - 不涉及 freeze-out / horn / `x = T/\mu_B`。

限制：

1. 这更像 meson-mass workflow 的文献验证；
2. 它不能单独验证 meson-density / BU thermodynamics 的最终结果层。

建议角色：

- 作为 **formal validation Tier-0 / upstream spectrum target**

### 5.3 候选 F3：`Blaschke:2016sqn` Figure 11 phase-shift contour along mapped freeze-out line

当前判断：**可做后续更高阶 external validation，但不宜做第一个**

原因：

1. 它仍然依赖 `Fig. 9` 的 freeze-out to pseudocritical mapping；
2. 虽然比 `Blaschke:2019col` right-panel 更明示，但仍然比 fixed-trajectory target 更复杂；
3. 需要 phase-shift field/contour 的结构化提取与可视化契约。

建议角色：

- 作为 **formal validation Tier-2 / phase-structure target**

## 6. 当前建议的正式 validation 入口顺序

建议把“formal validation 的第一入口”明确改成下面的顺序：

1. **先做 `Blaschke:2016sqn` Figure 8 mesonic partial pressure**
   - 这是当前最硬、最不含糊的 external target；
2. 再把 `Blaschke:2020bzh` Figure 2 left panel 的 `\mu_B=0` meson masses 结构化
   - 作为上游谱层对照；
3. 最后才考虑更复杂的 charged / freeze-out / horn 文献。

这意味着：

- 当前 right-panel 样本继续保留为 reproduction，不升格；
- 当前 `Friesen:2019ojk` 虽然已经具备高质量外部曲线数据包，也继续只保留为 charged-ratio 结果层 target 来源；
- formal validation 的第一步应优先选择**路径和口径都不含糊的低层 target**。

## 7. 本页结论

当前 `F4` 的阶段性结论是：

**本地文献库已经足够支持后续的 charged / freeze-out 现象学验证，但还不足以直接为当前 `μ_B = 0` 总 `K/\pi` 最小主线提供强的现成 regression 真值。若要尽快建立正式 external validation，最合理的入口应先下沉到 `Blaschke:2016sqn` Figure 8 这类路径定义充分、口径明确的 BU thermodynamics target。**
