## 1. D3 要比较的对象

`Phase D3` 只比较两类结果：

1. 稳定粒子极限
2. BW 宽度修正后的近似数密度

对每个介子道 `M in {pi, K}`，只关心：

- `n_M^stable(T)`
- `n_M^BW(T)`
- `Delta n_M(T) = n_M^BW(T) - n_M^stable(T)`

以及比值：

```math
R_{K/\pi}^{stable}(T)=\frac{n_K^{stable}(T)}{n_\pi^{stable}(T)},
\qquad
R_{K/\pi}^{BW}(T)=\frac{n_K^{BW}(T)}{n_\pi^{BW}(T)}.
```

## 2. 固定输入

`Phase D3` 继续消费 meson workflow 的输出，不单独重解极点：

- `T = thermo_params.T`
- `M_M = meson_results[M].mass`
- `Gamma_M = meson_results[M].gamma`

当前最小窗口先固定为：

- `muB = 0`
- `xi = 0`
- `M in {pi, K}`

因此，D3 里的 `M_M` 与 `Gamma_M` 是**外部给定输入**，不是 D3 内部再拟合出来的参数。

## 3. 起点公式

从 BU 的导数形式出发：

```math
n_M(T)
= d_M \int \frac{d^3q}{(2\pi)^3}
\int \frac{d\omega}{2\pi}
g(\omega;T)\frac{d\delta_M(\omega,q)}{d\omega},
```

其中

```math
g(\omega;T)=\frac{1}{e^{\omega/T}-1}.
```

在 D3 中，用最小 BW 相移近似：

```math
\delta_M^{BW}(\omega,q)
= -\arctan\frac{\Gamma_M(q)/2}{\omega-E_M(q)}.
```

于是

```math
\frac{d\delta_M^{BW}}{d\omega}
= \frac{1}{2}
\frac{\Gamma_M(q)}
{\left[\omega-E_M(q)\right]^2+\Gamma_M^2(q)/4}.
```

代回后得到：

```math
n_M^{BW}(T)
= d_M \int \frac{d^3q}{(2\pi)^3}
\int \frac{d\omega}{2\pi}
g(\omega;T)
\frac{\Gamma_M(q)}
{\left[\omega-E_M(q)\right]^2+\Gamma_M^2(q)/4}.
```

这里省略了更完整 BU 中的 continuum / Levinson 结构；这正是 D3 与 Phase E 的边界。

## 4. D3 的最小冻结近似

为了避免 D3 先扩成完整二维谱积分，当前建议固定以下最小近似：

### 4.1 先取零三动量近似

先令：

```math
E_M(q)\approx \sqrt{q^2 + M_M^2},
\qquad
\Gamma_M(q)\approx \Gamma_M(q=0)\equiv \Gamma_M.
```

即：

- 质量参数直接用 workflow 给出的极点质量 `M_M`
- 宽度先冻结为该点返回的 `Gamma_M`
- 暂不引入 `q` 依赖宽度

这是 D3 最重要的降阶步骤。  
它让我们先检查“宽度作为一个有限展宽量进入后，会把稳定极限推到哪里”，而不是立即卷入完整谱函数建模。

### 4.2 暂不做自洽色散修正

当前 D3 不再单独求解：

- `Re D_M^{-1}(omega,q)=0` 给出的 `q` 依赖壳面
- 由极化函数实时更新的 `M_M(omega,q)`、`Gamma_M(omega,q)`

这些内容推迟到 Phase E 或其后的更完整谱实现。

## 5. D3 实际建议采用的积分口径

对于脚本级最小验证，当前再补一个实现约束：

- 朴素的正能量 `omega in [0, +infty)` Lorentzian 直接乘 Bose 分布，在 `omega -> 0` 会出现红外问题；
- 因此 D3 的**最小分析脚本**先采用“BW 质量分布 smearing 代理”；
- 即把有限宽度的影响先解释为对壳质量 `M_M` 的展宽平均，而不是直接把未修正的正半轴 Lorentzian 当作最终数值积分核。

若写成脚本代理口径，可表示为：

```math
n_M^{BW-proxy}(T)
= d_M \int_0^\infty dm\,\rho_M^{BW}(m; M_M,\Gamma_M)\,n_M^{stable}(T;m),
```

其中

```math
\rho_M^{BW}(m; M_M,\Gamma_M)
\propto \frac{\Gamma_M/2}{(m-M_M)^2+\Gamma_M^2/4},
```

并在 `m >= 0` 的有限积分区间上重新归一化。

它对应的稳定粒子核为：

```math
n_M^{stable}(T;m)
= d_M \int_0^\infty \frac{dq\,q^2}{2\pi^2}
\frac{1}{\exp\left(\sqrt{q^2+m^2}/T\right)-1}.
```

从“设计目标”的角度，D3 仍然对应 BW 宽度进入后的最小诊断。  
从“脚本数值实现”的角度，当前先采用上述 `BW-proxy`，而不是直接把完整 BU 导数形式数值化。

作为理论对照，D3 想要逼近的最小 BW 目标形式仍然是：

```math
n_M^{BW}(T)
= d_M \int_0^\infty \frac{dq\,q^2}{2\pi^2}
\int_0^\infty \frac{d\omega}{2\pi}
g(\omega;T)
\frac{\Gamma_M}
{\left[\omega-\sqrt{q^2+M_M^2}\right]^2+\Gamma_M^2/4}.
```

配套固定口径：

- `d_pi = 3`
- `d_K = 4`
- `mu_M = 0`

这里的逻辑是：

- `q` 依赖只通过自由色散 `E_M(q)=sqrt(q^2+M_M^2)` 进入
- `omega` 方向的展宽只由常数 `Gamma_M` 控制
- 但在当前脚本实现中，先由 `BW-proxy` 稳定地承载“有限宽度展宽”的诊断任务

## 6. 与稳定粒子极限的关系

当

```math
\Gamma_M \to 0
```

时，Lorentzian 核应退化回稳定粒子极限对应的壳上贡献。  
因此 D3 必须检查以下退化关系是否数值成立：

- `n_M^{BW} -> n_M^{stable}`
- `R_{K/pi}^{BW} -> R_{K/pi}^{stable}`

若这一点不成立，优先怀疑：

- 归一化因子
- `omega` 积分范围
- `2pi` 因子
- 稳定极限与 BW 口径不一致

## 7. D3 暂不采用的更强形式

当前先不采用以下更重的公式口径：

1. `Gamma_M(omega, q)` 依赖的完整谱函数
2. 从传播子数值相位反推出的完整 `delta_M(omega,q)`
3. 分部积分后的 `delta_M` 本体积分形式
4. continuum 与 bound-state 联合处理
5. Levinson 定理约束下的相移重建

这些不是不重要，而是它们已经进入 Phase E 的职责区。

## 8. D3 的最小验收问题

只要这页公式进入实现，D3 的最小验证就应至少回答：

1. 在 D2 已通过的温区里，`n_M^{BW}` 是否连续退回 `n_M^{stable}`
2. 接近 Mott 的窄温区里，`n_M^{BW}` 是否比稳定极限更平滑
3. `K/pi` 比值在 BW 下是否出现可解释的有限宽度修正
4. 这些修正是否只是“宽度进入效应”，还是已经暴露出必须进入 BU 相移层的问题

## 9. 当前结论

`Phase D3` 的最小公式口径可以收敛为一句话：

- **用 meson workflow 给出的 `M_M` 和 `Gamma_M`，在 `muB=0, xi=0, pi/K` 窗口下，先做“自由色散 + 常数宽度”的 BW 数密度对照积分。**

这一步的目标不是替代 BU，而是把“稳定极限失效”与“必须上完整相移”之间的诊断边界先画出来。

---

## 10. 与后续 strict BW 的关系

本页固定的是 `Phase D3` 的**最小 BW 代理口径**，不是最终 strict BW。

若后续在当前项目中实现严格 BW，对应目标应是：

1. 从当前项目传播子
   ```math
   \mathcal{D}_M(\omega,q)=\frac{2K_M}{1-4K_M\Pi_M(\omega,q)}
   ```
   的复极点出发；
2. 在固定 `q` 下求
   ```math
   z_p(q)=E_M(q)-i\Gamma_M(q)/2
   ```
   满足
   ```math
   1-4K_M\Pi_M(z_p(q),q)=0;
   ```
3. 再把得到的 `E_M(q)` 与 `\Gamma_M(q)` 代入 strict BW 双积分公式。

也就是说：

- `BW-proxy` 是当前 D3 的最小可运行验证层；
- `strict BW` 是后续可以在本项目中真正实现的正式对照层；
- 二者不应混写为同一个实现层级。
