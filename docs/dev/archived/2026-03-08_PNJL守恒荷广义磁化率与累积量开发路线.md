# PNJL 守恒荷广义磁化率与累积量开发路线

更新日期：2026-03-08

> 目的：基于 [docs/reference/formula/models/pnjl/守恒荷广义磁化率与累积量.md](docs/reference/formula/models/pnjl/守恒荷广义磁化率与累积量.md) 的静态热力学定义，为 Julia 主线补齐守恒荷广义磁化率 `χ_{ijk}^{BQS}`、累积量 `C_{ijk}^{BQS}` 及实验常用比值量，并明确这条路线与当前 `kappa_BB / kappa_QQ / kappa_SS / lambda` 输运补齐任务互不冲突。

---

## 1. 背景与目标

- 当前仓库已有一条正在推进的 active 任务，聚焦 legacy 输运系数家族 `kappa_BB / kappa_QQ / kappa_SS / lambda` 的补齐。
- 这些量属于 RTA / kinetic theory 下的动态输运系数，显式依赖弛豫时间 `τ`，不是静态热力学涨落。
- 参考公式文档 [docs/reference/formula/models/pnjl/守恒荷广义磁化率与累积量.md](docs/reference/formula/models/pnjl/守恒荷广义磁化率与累积量.md) 给出的是另一条独立物理线：
  - 广义磁化率 `χ_{ijk}^{BQS}`
  - 累积量 `C_{ijk}^{BQS}`
  - 观测量 `Sσ = χ_3^B / χ_2^B`
  - 观测量 `κσ^2 = χ_4^B / χ_2^B`

本文档目标：

- 明确守恒荷广义磁化率实现的物理范围与工程边界。
- 约束实现主路线必须采用自动微分，不使用有限差分作为正式计算路径。
- 识别当前主线对非对称 flavor 化学势支持的约束，并据此给出分阶段开发路线。
- 输出可执行任务单、测试要求与 DoD，作为正式实现前的开发文档。

---

## 2. 范围与非范围

### 2.1 范围

- 基于平衡态压强 `P(T, μ_u, μ_d, μ_s)` 或 `P(T, μ_B, μ_Q, μ_S)` 计算静态广义磁化率。
- 实现最小可用集合：
  - `χ_2^B`
  - `χ_2^Q`
  - `χ_2^S`
  - `χ_11^BQ`
  - `χ_11^BS`
  - `χ_11^QS`
- 实现高阶重子数观测量所需量：
  - `χ_3^B`
  - `χ_4^B`
  - `Sσ`
  - `κσ^2`
- 提供 `χ -> C` 的薄封装，满足 `C_{ijk}^{BQS} = V T^3 χ_{ijk}^{BQS}`。
- 为后续更高阶 `χ_{ijk}^{BQS}` 留出统一接口。

### 2.2 非范围

- 本任务不实现 `kappa_BB / kappa_QQ / kappa_SS / lambda` 及其派生 ratio。
- 本任务不把 finite difference 作为主线路径，也不接受“先用差分顶上”的过渡实现。
- 本任务不直接扩展到非平衡输运、Einstein relation 或 fluctuation-dissipation 的联立建模。
- 本任务不在一期承诺所有任意阶、任意指标组合的 `χ_{ijk}^{BQS}` 全覆盖。

---

## 3. 与当前输运任务的边界

### 3.1 不冲突原因

- `χ_{ijk}^{BQS}` 是 `P/T^4` 对 `μ/T` 的平衡态热力学导数。
- `C_{ijk}^{BQS}` 只是 `χ_{ijk}^{BQS}` 乘以 `V T^3` 的广延化版本。
- `kappa_BB / QQ / SS` 是守恒荷扩散输运系数，积分核与 `τ`、流体投影项相关。
- `lambda` 是由 `kappa_BB` 与 `(ε + P, n_B, T)` 组合构造出的热导率。

结论：

- 输运任务补的是“动态线”。
- 本任务补的是“静态线”。
- 两者可以共享平衡态求解与热力学核，但不应共享同一个 feature 文档或验收口径。

### 3.2 命名风险

- `κσ^2` 中的 `κ` 是峰度，不是输运系数 `kappa_*`。
- 新模块/API 必须避免把 `kappa_sigma2` 这类静态涨落观测量命名成会和 transport `kappa_*` 混淆的形式。

## 5. 总体技术路线

### 5.1 总原则

- 正式实现必须走 AD 主路线。
- 当平衡态由非线性方程隐式定义时，必须沿用现有模式：
  - `NLsolve` 只负责求 primal equilibrium
  - `ImplicitDifferentiation.jl` 负责 `dx/dθ`
  - `ForwardDiff` 负责外层热力学导数
- 有限差分仅允许作为测试或诊断对照，不进入生产 API。

### 5.1a 架构分层约定

为避免把“物理约束”“输入参数化”和“导数能力”混写到同一层，本路线后续默认按三层语义组织：

- 约束模式层：定义“要求解什么平衡态问题”，例如 `FixedMu`、`FixedRho`、`FixedEntropy`、`FixedSigma`。
- 参数化层：定义“同一个平衡态问题用什么输入坐标表达”，例如对称 `μ` 参数化与 flavor `μ_vec` 参数化。
- 求导层：定义“在平衡态之上需要多少导数能力”，例如只求 primal、求一阶 Jacobian，或为 susceptibility 提供高阶导数后端。

当前阶段的 flavor-μ 路线应被理解为：

- 不是新增一个物理约束模式；
- 而是在既有平衡态问题之上，引入新的参数化方式与隐式求导通道；
- 其主要服务对象是 `χ_{ijk}^{BQS}`、`C_{ijk}^{BQS}` 及相关静态涨落量，而不是通用 constraint solver 的 mode 扩展。

因此，本路线后续若补高层入口，应优先按“参数化选项”或“求导后端”纳入，而不是把 flavor-μ 直接命名为新的 `ConstraintMode`。

### 5.2 建议的导数分层

建议把实现拆成三层：

#### 第一层：flavor 基底压强导数

实现口径补充：

- 内部数值主对象应优先取 `P(T, μ_u, μ_d, μ_s)` 对 flavor 化学势的导数。
- `χ_n` 的 `T` 缩放通过解析关系 `χ_n = T^(n-4) ∂^nP/∂μ^n` 在导数完成后统一施加。
- 不建议把 `P/T^4` 直接作为高阶 AD 的最底层输入，尤其在小 `T` 区域，这会把压强基线误差和求解噪声额外放大。

目标对象：

$$
\frac{\partial^n}{\partial (\mu_f / T)^n}\left(\frac{P}{T^4}\right),\quad f \in \{u,d,s\}
$$

以及 mixed flavor 导数：

$$
\frac{\partial^{a+b+c}}{\partial (\mu_u/T)^a \partial (\mu_d/T)^b \partial (\mu_s/T)^c}\left(\frac{P}{T^4}\right)
$$

原因：

- 当前热力学核天然以 `mu_vec` 为 flavor 输入。
- `B/Q/S` 方向导数可视为 flavor 导数的线性组合。
- 先把 flavor 基底导数统一起来，比一开始直接把所有 `B/Q/S` 指标写死更稳。

#### 第二层：`B/Q/S -> flavor` 链式法则映射

根据公式文档中的映射：

$$
\mu_u = \frac{1}{3}\mu_B + \frac{2}{3}\mu_Q
$$

$$
\mu_d = \frac{1}{3}\mu_B - \frac{1}{3}\mu_Q
$$

$$
\mu_s = \frac{1}{3}\mu_B - \frac{1}{3}\mu_Q - \mu_S
$$

建立线性变换矩阵 `A`，使得：

$$
\mu_f = A \mu_{BQS}
$$

然后把 `B/Q/S` 方向的导数化为 flavor 导数的多线性组合。

#### 第三层：观测量层

在 `χ` 之上实现：

- `C_{ijk}^{BQS}(V, T) = V T^3 χ_{ijk}^{BQS}`
- `Sσ = χ_3^B / χ_2^B`
- `κσ^2 = χ_4^B / χ_2^B`

这一层应保持薄封装，不重复热力学求解。

## 6. 分阶段开发策略

### 6.1 阶段 A：对称化学势首版

目标：先交付与当前求解器骨架完全兼容的最小静态线能力。

范围：

- [x] 基于现有单一 `μ` 隐式求解器，实现 baryon-like 对称方向的高阶导数接口。
- [x] 明确标注此阶段只覆盖 `μ_u = μ_d = μ_s = μ_B / 3` 的对称路径。
- [x] 先交付：
  - `χ_1^B`
  - `χ_2^B`
  - `χ_3^B`
  - `χ_4^B`
  - `Sσ`
  - `κσ^2`

这一阶段的价值：

- 可以先把“静态涨落主线”的 API、单位、归一化和测试口径固定下来。
- 不必等待完整三味独立 `mu_vec` 隐式求解器成熟。

## 8. 关键数学与数值约束

### 8.1 固定的无量纲导数对象

广义磁化率定义必须固定为：

$$
χ_{ijk}^{BQS} =
\frac{\partial^{i+j+k}(P/T^4)}{\partial(\mu_B/T)^i\,\partial(\mu_Q/T)^j\,\partial(\mu_S/T)^k}
$$

不能偷换成：

- 直接对 `P` 而非 `P/T^4` 求导
- 直接对 `μ` 而非 `μ/T` 求导却不做换元修正

### 8.2 累积量只做代数封装

定义固定为：

$$
C_{ijk}^{BQS} = V T^3 χ_{ijk}^{BQS}
$$

因此：

- `χ` 是核心主实现。
- `C` 不应复制一套新的导数逻辑。

### 8.3 `μ/T` 导数与温度耦合

实现时必须显式说明：

- 在固定 `T` 下，对 `x = μ/T` 求导与对 `μ` 求导之间存在比例变换。
- 若直接对 `x = μ/T` 做 AD，必须保持 `μ = xT` 的参数耦合一致。
- 若先对 `μ` 求导再换算到 `μ/T`，应把换算因子写入统一 helper，禁止散落在各函数中手工相乘。

### 8.4 二阶以上导数的稳定性

- 嵌套 AD 的输入函数必须尽量纯净，避免夹带日志、缓存写入、副作用型状态修改。
- 隐式求解器缓存若依赖 `Float64` key，需要保证不污染 Dual 路径。
- 若某些高阶导数在临界区附近存在数值爆炸，先通过 guardrail 与测试标记管理，不允许退回有限差分主路。

## 12. 风险与回退策略

### 12.1 主要风险

- 当前隐式求解器对非对称 `mu_vec` 支持不足，可能拖慢完整 `BQS` mixed susceptibilities 落地。
- 二阶以上导数在临界区附近可能出现 AD 嵌套导致的数值不稳定。
- 若现有缓存或求解包装里存在 `Float64` 假设，Dual 传播会被静默截断。

### 12.2 回退策略

- 若阶段 B 超预期复杂，则先冻结阶段 A，先发布 baryon 静态涨落主线。
- 对完整 `B/Q/S` mixed susceptibilities，不以有限差分替代；而是把三味 `mu_vec` 隐式求解扩展列为显式前置任务。
- 高阶量若短期不稳，可先只开放 `χ_2` 与二阶 mixed 集合，`χ_3/χ_4` 继续保留在 baryon 方向。
