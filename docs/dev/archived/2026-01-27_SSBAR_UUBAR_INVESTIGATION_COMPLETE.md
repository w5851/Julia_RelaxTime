## 🎯 核心发现

**只有 ssbar→uubar 散射过程有显著差异,根本原因已找到!**

## ✅ 根本原因

### **σ(s) 插值点数不足** ⭐⭐⭐⭐⭐

**现象**:
- 增加缓存点数从 N=256 → N=512,结果下降 **20.8%**
- N=512 时,Julia 与 Fortran 的差异降至 **2.25%**

**原因**:
- Julia 使用 w0cdf 设计的非均匀网格,默认 N=256
- 在阈值附近,σ(s) 从 0.571 fm² 快速下降到 0.048 fm² (变化 10 倍)
- **256 个点不足以捕捉这种剧烈变化**
- Fortran 使用 128 个均匀点,在阈值附近有足够的采样密度

### **方位角积分节点数不足** ⭐⭐⭐

**现象**:
- phi_nodes=4 → phi_nodes=8,结果上升 **13.1%**

**原因**:
- 对于 `ssbar→uubar`,方位角依赖性较强
- **需要至少 8 个方位角节点**

## 🎯 为什么只有 ssbar→uubar 受影响?

### 物理原因

**阈值位置的差异**:

| 过程 | s_th (fm⁻²) | s_th/s_up | 阈值位置 |
|------|-------------|-----------|----------|
| ssbar→uubar | 4.265 | 0.12 | **高** |
| uubar→ssbar | 0.0065 | 0.0002 | **低** |

**关键差异**:
- `ssbar→uubar`: 阈值很高,接近积分上限
  - 在阈值附近,σ(s) 从 0.571 fm² 快速下降到 0.048 fm²
  - **变化率极大,需要更密集的采样**
  
- `uubar→ssbar`: 阈值很低,远离积分上限
  - 大部分积分区域都远离阈值
  - σ(s) 变化相对平缓
  - **插值误差小**

### 数值验证

**uubar→ssbar 的收敛性测试**:

| N | w (fm⁻¹) | 相对变化 |
|---|----------|----------|
| 256 | 4.466×10⁻² | baseline |
| 512 | 4.466×10⁻² | **0.012%** |

**结论**: `uubar→ssbar` 对缓存点数**不敏感**,证实了阈值位置是关键因素

## 📈 物理理解

### 为什么阈值附近的插值如此重要?

**积分权重分布**:
```
w(s) = ∫∫∫ σ(s) × f(p_i) × f(p_j) × δ(s - s_ij) dp_i dp_j dΩ
```

**关键点**:
1. **阈值附近的 σ(s) 很大** (0.571 fm²)
2. **但相空间很小** (√(s - s_th) → 0)
3. **两者的乘积决定了贡献**

**插值误差的影响**:
- 如果插值低估了阈值附近的 σ(s)
- 会导致整个积分偏小
- **误差被积分放大**

### Fortran 的优势

- 128 个均匀点确保了阈值附近有足够的采样
- 线性插值虽然简单,但在点数足够时也很准确
- 不依赖于 w(s) 的估计,更稳定

## 💡 已确认的原因

### 原因 1: σ(s) 插值点数不足 ⭐⭐⭐⭐⭐ **已确认!**

**现象**:
- N=256 → N=512: 结果下降 20.8%
- 差异从 36% 降至 2.2%

**物理解释**:
- ssbar→uubar 的阈值很高 (s_th = 4.265 fm⁻²)
- 在阈值附近,σ(s) 变化极其剧烈 (10 倍变化)
- 256 个点不足以捕捉这种变化
- **需要 512 个点**

### 原因 2: 方位角积分节点数不足 ⭐⭐⭐ **已确认!**

**现象**:
- phi_nodes=4 → phi_nodes=8: 结果上升 13.1%

**物理解释**:
- 对于 ssbar→uubar,方位角依赖性较强
- 4 个节点不足以捕捉方位角的变化
- **需要至少 8 个节点**

### 原因 3: 角度积分方式不同 ⭐⭐ **可能存在,但影响小**

**Fortran**:
```fortran
! 1D 角度积分
angel ∈ [0, π]  ! 两粒子动量夹角
s = m1² + m2² + 2(E1 E2 - p1 p2 cos(angel))
```

**Julia**:
```julia
# 3D 角度积分
cosθ_i ∈ [-1, 1]  # 粒子 i 的极角
cosθ_j ∈ [-1, 1]  # 粒子 j 的极角
φ ∈ [0, 2π]       # 方位角
cosΘ = cosθ_i cosθ_j + sinθ_i sinθ_j cos(φ)
s = m1² + m2² + 2(E1 E2 - p1 p2 cosΘ)
```

**关键差异**:
- Fortran 假设粒子动量方向各向同性,直接积分夹角
- Julia 完整考虑每个粒子的动量方向

**影响评估**:
- 在修复了插值点数和方位角节点数后,差异降至 2.2%
- 剩余的 2.2% 差异可能部分来自角度积分方式
- **但影响远小于插值点数的影响**
