# 项目结构治理与一致性修复任务单（执行版，可勾选）

## 目标

在不改动核心物理实现的前提下，收敛当前“文档状态、路径引用、自动检查”三类一致性问题。

## 问题与改进方向（本任务覆盖）

- 文档状态口径不一致：README 标注部分链路仍修复中，但 guides 存在“完全就绪/无已知问题”。
- 路径与命令漂移：guides 中仍含历史路径（`server.jl`、`test_unit`、`doc/...`、根目录 `start.bat`）。
- 目录规范缺少自动门禁：缺少针对文档路径漂移与状态词冲突的 CI 校验。
