# Phase B：记号对照与最小物理口径

本文对应任务单 `Phase B`，目的不是给出完整 BU 实现，而是先统一：

1. 项目内与参考文献中的核心记号；
2. `\mu_B = 0` 下 `\pi/K` 数密度最小实现的物理口径；
3. 后续 BU 数值积分优先采用的表达形式。

## 1. 当前主线的统一约束

## 1.1 项目主传播子与极点条件

后续介子数密度 / BU 主线必须服从当前项目已有 RPA 传播子定义：

```math
\mathcal{D}_M(\omega, q;\xi)
= \frac{2K_M}{1 - 4K_M \Pi_M(\omega, q;\xi)}.
```

对应极点条件为：

```math
1 - 4K_M \Pi_M(p_0, q;\xi) = 0,
\qquad p_0 = M + i\Gamma/2.
```

这一定义是当前项目的主口径。文献中常见的

```math
1 - 2P_{ij}\Pi^M_{ij} = 0
```

只作为同类结构的记号对照，不作为当前仓库主定义。

## 1.2 RS 各向异性的进入位置

当前项目中 RS 各向异性通过

```math
\Pi_M(\omega,q;\xi)
\rightarrow
\mathcal{D}_M(\omega,q;\xi)
\rightarrow
\delta_M(\omega,q;\xi)
```

进入介子侧。

因此在 `Phase D` 的稳定粒子极限中，不额外手写经验型 `E_M(\xi)`。后续若需要各向异性的介子准粒子色散关系，必须从当前项目的极点条件重新导出。

## 2. 记号对照表

## 2.1 热力学与动力学变量

| 介子化学势 | `\mu_M` | `mu_M_inv_fm` | `fm^-1` | 文档中统一写 `\mu_M`，代码命名显式带单位后缀 |

## 2.2 “`g_M`” 的冲突处理

文献中 `g_M` 可能表示：

1. 玻色分布函数；
2. 简并因子；
3. 个别上下文中的其他通道权重。

为避免冲突，当前主线统一约定：

- `d_M`：介子简并因子
- `g_M(E)`：玻色分布函数，仅在积分公式中保留
- 若需要代码层函数名，优先写成 `g_B` 或 `bose_distribution`

## 2.3 相移与传播子记号

文献中 BU 相移常通过传播子的极坐标形式给出：

```math
S^M_{ij}(\omega,q) = |S^M_{ij}(\omega,q)| e^{i\delta_M(\omega,q)}.
```

当前项目简单介子道统一解释为：

```math
\delta_M(\omega,q;\xi) = \arg \mathcal{D}_M(\omega+i\eta,q;\xi).
```

这样可以直接与当前 `MesonPropagator` / `MesonMass` 口径对接。

## 3. `\pi/K` 道的最小物理口径

## 3.1 MVP 的范围约束

当前 `Phase C` 之前先为 `Phase D` 和后续 `Phase E` 固定如下最小物理口径：

1. `\mu_B = 0`
2. 静态、均匀介质
3. 仅做 `\pi/K` 数密度与 `K/\pi` 比值
4. 先不引入冻结线、非平衡 `\mu_\pi(x)`、`\mu_s(x)` 经验拟合

## 3.2 `\mu_B = 0` 下的默认化学势约束

在当前最小平衡口径下，默认采用：

```math
\mu_u = \mu_d = \mu_s = 0.
```

因此：

```math
\mu_\pi = 0,
\qquad
\mu_K = 0.
```

### 说明

1. 这是当前最小实现的平衡态默认口径；
2. 它不否定文献中用于重离子碰撞现象学拟合的 `\mu_\pi \neq 0` 或 `\mu_s \neq 0`；
3. 但这些非平衡 / 拟合化学势不应先于最小平衡实现进入代码主线。

## 3.3 简并因子的默认约定

当前建议区分“总道数密度”和“单电荷态数密度”两种口径。

### 3.3.1 聚合通道（默认）

若输出目标写作：

- `n_pi(T)`
- `n_K(T)`
- `n_K/n_pi(T)`

则默认解释为电荷多重态聚合后的总数密度，采用：

```math
d_\pi = 3,
\qquad
d_K = 4.
```

对应：

- `\pi` 三重态：`(\pi^+, \pi^0, \pi^-)`
- `K` 四重态：`(K^+, K^0, K^-, \bar K^0)`

### 3.3.2 电荷分辨通道（仅在后续现象学阶段）

若后续要比较 `K^+/\pi^+` 或 `K^-/\pi^-`，则每个单态默认采用：

```math
d_{\pi^+} = d_{\pi^-} = d_{\pi^0} = 1,
\qquad
d_{K^+} = d_{K^-} = d_{K^0} = d_{\bar K^0} = 1.
```

### 当前选择

当前主线优先采用 **聚合通道口径**，因为这更符合任务单里 `n_pi`、`n_K`、`n_K/n_pi` 的最小输出定义。

## 4. 数密度公式的优先实现形式

## 4.1 稳定粒子极限

当前 `Phase D` 的稳定粒子极限采用：

```math
n_M
= d_M \int \frac{d^3q}{(2\pi)^3}
\frac{1}{e^{(E_M-\mu_M)/T}-1},
\qquad
E_M = \sqrt{q^2 + m_M^2}.
```

这是后续一切验证的基线，不涉及相移。

## 4.2 BU 的两种等价形式

文献中当前最相关的两种 BU 表达为：

### 导数形式

```math
n_M(T)
= d_M \int \frac{d^3q}{(2\pi)^3}
\int \frac{d\omega}{2\pi}
g_M(\omega)\frac{d\delta_M(\omega,q)}{d\omega}.
```

### 分部积分后的相移本体形式

```math
n_M(T)
= \frac{d_M}{T}
\int \frac{dq\,q^2}{2\pi^2}
\int_0^\infty \frac{d\omega}{2\pi}
g_M(\omega)\bigl[1+g_M(\omega)\bigr]\delta_M(\omega).
```

## 4.3 当前优先实现选择

**当前建议优先实现：分部积分后的 `\delta_M` 本体形式。**

即优先采用：

```math
n_M(T)
= \frac{d_M}{T}
\int \frac{dq\,q^2}{2\pi^2}
\int_0^\infty \frac{d\omega}{2\pi}
g_M(\omega)\bigl[1+g_M(\omega)\bigr]\delta_M(\omega).
```

## 4.4 选择理由

### 选择 `\delta_M` 本体形式的理由

1. 当前项目后续相移将从传播子数值相位提取，直接对数值相位做 `\omega` 导数更容易放大噪声；
2. 相移在束缚态跳变、Mott 阈值附近和分支选择处更容易出现数值不光滑，导数形式对这些问题更敏感；
3. 本体形式更利于先做“相移是否满足 Levinson 约束”的人工检查；
4. 对当前项目来说，先把 `\delta_M(\omega)` 本身做对，比先对它求稳定导数更重要。

### 当前不优先采用导数形式的理由

1. `d\delta_M/d\omega` 需要额外的差分、拟合或平滑策略；
2. 一旦相移存在数值跳变或 branch unwrap 问题，导数会直接把误差放大；
3. 对当前主线而言，它更适合保留为理论参考和交叉检查口径，而不是第一实现口径。

## 4.5 保留导数形式的原因

虽然当前不优先实现导数形式，但它仍必须保留在文档中，因为：

1. 它是文献中最直接的 BU 原始表达；
2. 稳定束缚态极限通过 `d\delta/d\omega \sim \delta(\omega-M)` 的解释最直观；
3. 若后续获得解析导数或更稳的相移插值方案，它仍可作为交叉验证实现。

## 5. 当前 Phase B 的结论

基于当前任务单与项目主线，`Phase B` 固定如下：

1. 项目主记号以现有 `Π`、`\mathcal{D}`、`1-4K\Pi=0` 口径为准；
2. `d_M` 统一表示简并因子，`g_M` 只保留给玻色分布函数；
3. `\mu_B=0` MVP 默认采用平衡态：
   - `\mu_u=\mu_d=\mu_s=0`
   - `\mu_\pi=\mu_K=0`
4. `n_pi`、`n_K` 默认指聚合通道数密度：
   - `d_\pi=3`
   - `d_K=4`
5. BU 数密度后续优先实现分部积分后的 `\delta_M` 本体形式；
6. RS 各向异性当前不直接改写稳定粒子 `E_M`，后续通过 `\Pi \to \mathcal{D} \to \delta_M` 进入。
