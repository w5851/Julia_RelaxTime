创建日期：2026-07-10

关联决策：`docs/decisions/0005-scientific-sop-and-document-authority.md`

## 1. 背景与目标

首期科学计算 SOP 已覆盖公共生命周期、PNJL 相结构和 transport。本任务把同一 written/configured/effective/usable 框架扩展到：

1. 介子热力学 canonical `mu_B=0` phase-shift EOS 链；
2. 介子数密度的 scan-path × density-regime 组合链及 formal production 治理。

## 2. 范围

### 本期范围

- 新增介子热力学 SOP；
- 新增介子数密度 SOP；
- 更新 SOP 总索引、README/STATUS 导航和 authority map；
- 将介子热力学 canonical 脚本补入全量 run-script catalog；
- 修正与现有 regression 状态冲突的介子热力学 API 文档；
- 运行专题 integration/contract smoke 与现有文档治理检查。

### 非范围

- 不修改介子 pressure/density 公式、积分核、分支选择或默认 policy；
- 不新增或重生 baseline；
- 不改变 `phase_shift_current`、`gbu_reference`、strict BW 或 Bose-domain 的数值语义；
- 不把专题脚本提升到 Phase A 核心稳定 CLI 白名单；
- 不宣称尚未建立的 external validation；
- 不重跑现有高精度 production case。

## 7. 风险与回退方案

- 风险：把 canonical/regression 资产误写成 external validation。
  - 回退：介子热力学明确保留“无 external validation gate”边界。
- 风险：把 density diagnostic policy 写成唯一物理处方。
  - 回退：逐项标明 project policy、适用 regime 与不可外推范围。
- 风险：combined CLI 本地数值 smoke 过慢。
  - 回退：contract smoke 为最低自动门禁；远程 production workflow 与既有 production audit 作为长任务证据。
- 风险：专题入口被误解为核心白名单。
  - 回退：authority map 只登记 `entrypoints`，`stable_entrypoints` 保持为空，并在 SOP 中标注 `domain-candidate`。
