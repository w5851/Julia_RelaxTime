# 求解器兼容层迁移映射表（Wave-A）

## 目标

统一 `Models` 求解入口，明确兼容层边界，避免双轨调用继续扩散。

主入口：`Models.solve_constraint`

## 迁移映射

| 旧入口 | 新入口 | 当前状态 | 删除门槛 | 目标波次 |
|---|---|---|---|---|
| `Models.solve_fixedmu_constraint` | `Models.solve_constraint(model, FixedMu(), T; μ_fm=...)` | active (compat) | 调用方清零 + 回归通过 | C |
| `Models.solve_fixedrho_constraint` | `Models.solve_constraint(model, FixedRho(...), T)` | active (compat) | 调用方清零 + 回归通过 | C |
| `Models.solve_fixedasymrho_constraint` | `Models.solve_constraint(model, FixedAsymmetricRho(...), T)` | active (compat) | 调用方清零 + 回归通过 | C |
| `Models.solve_fixedentropy_constraint` | `Models.solve_constraint(model, FixedEntropy(...), T)` | active (compat) | 调用方清零 + 回归通过 | C |
| `Models.solve_fixedsigma_constraint` | `Models.solve_constraint(model, FixedSigma(...), T)` | active (compat) | 调用方清零 + 回归通过 | C |

## 非破坏迁移标记

代码侧标记点：

- `src/models/solver/Solver.jl`：`solve_constraint` 分发注记 `COMPAT`。
- `src/models/constraint_solver.jl`：`solve_fixed*` 兼容入口注记 `COMPAT`。

运行时行为保持不变，不引入 breaking change。

## 验证

- `tests/unit/models/test_solver_compat_markers.jl`
  - 兼容入口仍可用
  - 统一入口与旧入口在 FixedMu 样例上的数值一致
  - `solver_migration_map()` 提供可追溯映射
