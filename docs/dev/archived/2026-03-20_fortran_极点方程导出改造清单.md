# Fortran 工程极点方程导出最小改造清单

## 1. 目标

在保持 legacy 主求解链路稳定的前提下，为 Fortran 工程增加“介子极点质量/宽度 + Mott 判据”直接导出能力，输出可用于 Julia_RelaxTime 对照验证的 CSV。

工程基路径：

- `D:/Desktop/Fortran/NJL-ReTime/PNJL-shear-mu-T-method2/Meson-mass-0703`

## 2. 现状与约束

- 现有 `main.f90` 主要输出平衡态与输运相关数据（`parameter.dat`, `shear.dat` 等）。
- 已有传播子/极化函数实现（`propagator.f90`, `polarization.f90`），但未提供“按介子类型独立求极点质量”的外部导出入口。
- 代码依赖历史工程配置（Visual Fortran 工程），不建议先做大规模语法迁移。

## 3. 最小改造原则

1. 不改现有 `main.f90` 默认行为（避免影响已有结果）。
2. 新增独立导出入口文件，复用已有公共块与子程序。
3. 先支持 `muB=0` 与本期网格，后续再扩展。
4. 输出字段一次到位对齐规范（避免多次改 schema）。

## 4. 文件级改造清单

### 4.1 新增文件

- [x] `meson_pole_export_main.f90`
  - 独立程序入口。
  - 负责温度/xi 网格循环、平衡态调用、极点求解调用、CSV 写出。
- [x] `meson_pole_solver.f90`
  - 提供 `solve_meson_pole(meson, T, muB, xi, mass, gamma, converged, residual)`。
  - 内部复用 `propagator/polarization` 相关函数构建方程。
- [x] `meson_export_io.f90`
  - 统一 CSV 行写出接口，避免主程序混杂 I/O 细节。

### 4.2 最小修改现有文件

- [ ] `Meson-mass-0703.vfproj`
  - 加入上述新源文件并创建独立 target（或独立可执行配置）。
- [ ] `propagator.f90`（可选）
  - 若需暴露更细粒度中间量（如单通道逆传播子实部），新增轻量接口。
- [ ] `main.f90`
  - 默认不改；仅在需要共享初始化函数时抽取公共子程序。

## 5. 核心实现步骤

### Step A：抽取公共初始化

- [ ] 抽出参数初始化与 `gauleg` 节点初始化到公共子程序（或 include 段）。
- [ ] 确保新入口与旧入口使用相同常数/参数。

### Step B：定义介子方程接口

- [ ] 为 8 个目标通道建立统一符号映射：
  - `pi, K, eta, eta_prime, sigma_pi, sigma_K, sigma, sigma_prime`
- [ ] 提供 `meson_inverse_real(meson, k0, ...)` / `meson_inverse_imag(...)`。

### Step C：极点求解

- [~] 对每个通道在 `k=0` 求解极点条件（已接通 `pi/K`，其余通道仍为 proxy）。
- [x] 首版采用两段式：
  1) 实轴扫描定位候选区间；
  2) 局部迭代（牛顿/二分混合）收敛。
- [ ] 对混合通道（eta/eta', sigma/sigma'）使用矩阵本征模式分离。

### Step D：Mott 与 CSV 导出

- [ ] 计算 `threshold_MeV`（按通道阈值定义）。
- [ ] 计算 `gap_MeV = mass_MeV - threshold_MeV`。
- [ ] 写 `mott_flag = (abs(gap_MeV) <= tol)`。
- [ ] 输出到：
  - `quark_phase/legacy_meson_scan_fortran_muB0_v1.csv`

## 6. 输出字段（必须）

- `record_id,source_impl,T_MeV,muB_MeV,xi,meson`
- `mass_MeV,threshold_MeV,gap_MeV,mott_flag,solver_status`

`solver_status` 推荐：

- `exact_pole_success`
- `exact_pole_fallback`
- `exact_pole_fail`

## 8. 风险与兜底

- 数值不收敛风险：先保证 `solver_status` 不缺失，不可静默吞掉失败点。
- 混合通道本征模式错配风险：先在少量固定点与 Julia 侧单点对照。
- 工程配置风险：优先在原 `.vfproj` 配置内加 target，不跨工具链重构。
