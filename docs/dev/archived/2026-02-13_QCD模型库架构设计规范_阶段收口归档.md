# QCD模型库架构设计规范

## 1. 核心设计理念

### 1.1 多态+抽象接口+独立文件夹结构
这是Julia项目中处理多种相关模型的最佳实践，通过多重分派实现类型安全与编译优化，保持架构清晰且易于扩展。

### 1.2 分层抽象结构
采用分层设计，从通用接口到具体实现逐步细化：

```
src/
├── core/
│   ├── interface.jl          # 核心抽象类型
│   └── traits.jl            # 特质/标记类型（可选）
├── models/
│   ├── isotropic/
│   │   ├── types.jl         # 各向同性相关抽象类型
│   │   └── pnjl.jl          # PNJL具体实现
│   ├── anisotropic/
│   │   ├── types.jl         # 各向异性相关抽象类型
│   │   └── rpnjl.jl         # rPNJL具体实现
│   └── magnetic/
│       ├── types.jl         # 磁场相关抽象类型
│       └── magnetic_pnjl.jl # 磁场PNJL具体实现
└── base/
    ├── integrals.jl         # 数值工具
    └── polyakov.jl          # Polyakov通用工具
```

## 2. 抽象类型定义

### 2.1 核心抽象接口
```julia
# src/core/interface.jl
abstract type AbstractQCDModel end

# 必需方法接口
function vacuum_contribution end
function thermal_contribution end
function polyakov_potential end
function dispersion_relation end
function calculate_mass_vec end
function calculate_chiral end
```

### 2.2 领域抽象类型
```julia
# 各向同性模型抽象基类
abstract type AbstractIsotropicModel <: AbstractQCDModel end

# 各向异性模型抽象基类
abstract type AbstractAnisotropicModel <: AbstractQCDModel end

# 磁场模型抽象基类
abstract type AbstractMagneticModel <: AbstractQCDModel end
```

## 3. 代码复用策略

### 3.1 基础数值工具（base/）
- **通用数值积分器**：支持不同维度的积分，接收energy_fn回调
- **Polyakov对数项**：所有模型共享的通用实现
- **安全数值计算**：safe_log、safe_vandermonde等

### 3.2 默认实现提供
各领域抽象类型可以提供领域相关的默认实现：
- 各向同性模型：默认一维色散关系、一维积分
- 磁场模型：Landau简并度计算工具

## 4. 模型实现规范

### 4.1 具体模型结构
每个具体模型需要：
1. 定义具体类型继承相应抽象类型
2. 实现必需方法接口
3. 可选覆盖默认实现

### 4.2 示例：PNJL模型
```julia
struct PNJLModel <: AbstractIsotropicModel
    params::Dict{Symbol, Float64}
end

# 只实现需要特化的方法
function calculate_mass_vec(model::PNJLModel, φ)
    # PNJL特定的质量计算
end

# 其他方法使用默认实现
```

## 5. 优势分析

1. **代码复用最大化**：基础数值工具和Polyakov项被所有模型共享
2. **扩展性**：添加新模型只需定义新类型和实现必需方法
3. **类型安全**：编译器可检查接口实现
4. **性能优化**：Julia的JIT编译器为每种模型类型生成优化代码
5. **清晰的分层**：基础工具→模型接口→具体实现
