## 图片格式要求汇总

- 推荐格式：首选 `PDF`（矢量），也接受 `EPS`，并保留高分辨率 `PNG` 备份。
- 分辨率：线条/矢量图建议 `600 dpi`（位图导出时），照片/灰度图至少 `300 dpi`。
- 颜色模式：在线版 `RGB`，印刷会转换为 `CMYK`；黑白稿使用灰度并保证可读性。
- 尺寸：单栏宽度约 `8.6 cm`（3.4 in），双栏宽度约 `17.8 cm`（7 in），高度通常不超过 `24 cm`。
- 字体：使用无衬线/衬线兼容字体，期刊常用 `Times New Roman`；正文字号 `8–10 pt`，建议 `10 pt`。
- 线条与标记：线宽不小于 `0.5 pt`（建议 1.0–1.5 pt 以确保可视性）；标记大小适中（例如 markersize 3–6）。
- 导出设置：使用 `bbox_inches='tight'`、`pad_inches≈0.05`；优先使用 `pdflatex` / `xelatex` 编译流程以直接包含 PDF 图。
- 元数据与来源：在投稿时提供可编辑源文件（Python/Matlab/Origin 脚本）和独立图注文本。

## 对 `scripts/plot_scan_csv.py` 的修改建议与已实现变更

- 推荐默认输出格式：`pdf`（矢量）并同时保存 `png` 作为位图备份；支持通过 `--formats` 指定更多格式（例如 `eps`）。
- 推荐默认 `dpi=600`，脚本现在已增加 `--dpi` 参数并将 `savefig.dpi` 设置为 600。
- 字体与样式：脚本中新增了 `configure_publication_style()`，默认使用 `Times New Roman`、字号 `10`、线宽 `1.0`，并设置保存参数（`bbox`、`pad_inches`）。
- 导出行为：`plot_lines` 与 `plot_heatmaps` 支持多格式保存并为位图格式使用 `bbox_inches='tight'`，矢量格式使用标准保存流程。
- 检查项（建议未来实现）：自动检查生成图像的实际 DPI、尺寸（cm/inch）与字体嵌入情况，并在不满足期刊要求时打印警告。

### 已实现（细节说明）

- CLI 参数：新增 `--formats`（默认 `pdf,png`）、`--dpi`（默认 `600`）、`--line-style`（默认 `-`）、`--check`（执行简单检查）。
- 样式配置：新增 `configure_publication_style()`，默认使用 `Times New Roman`、字号 `10`、线宽 `1.5`（绘图默认）/rcParam `lines.linewidth` 可配置为 1.0，刻度方向向内（`xtick.direction`/`ytick.direction` = `in`），默认不显示网格，默认不绘制数据点（`--marker` 默认为空）。
- 导出行为：`plot_lines` 与 `plot_heatmaps` 支持多格式保存（PDF/EPS 为矢量保存，PNG/TIFF 等为位图保存时使用 `bbox_inches='tight'` 与 `pad_inches=0.05`）。
- 简单检查：实现 `_post_save_checks()`，对于 PNG 会读取 DPI 元数据并在低于预期时发出警告；对于 PDF/EPS 脚本会打印提示，建议手动或使用外部工具检查字体嵌入与矢量内容。


## 结论与下一步

### 坐标轴范围默认规则（需在脚本中实现）

默认行为下，坐标轴范围设定规则应该为：

- 图表中所有坐标轴的默认范围必须由该轴上数据的实际最小值与最大值自动且严格地确定；当使用刻度策略（例如“主要刻度覆盖”）时，可采用由刻度策略计算得到的主要刻度范围作为替代，但仍需以数据范围为基础。
- 坐标轴线条的视觉起点与终点必须精确对齐于第一个与最後一个主刻度线的位置；轴线不得在可视区域中超出这些主刻度线范围（即不允许在默认视图下向数据范围之外有任何多余延伸）。
- 若用户显式提供 `--xlim`/`--ylim`，则以用户指定为准；否则脚本应自动计算并严格应用上述规则。

该规则应在后续实现中作为默认行为加入 `plot_lines` 与 `plot_heatmaps` 的范围处理逻辑，并在文档中给出说明与示例。

## 文档与示例放置位置（约定）

- 脚本使用说明：所有脚本级的使用说明与示例（面向开发者的用户指南）应放在 `docs/guides/scripts/` 目录下。对此脚本的详细使用示例已在该目录中新增：`docs/guides/scripts/plot_scan_csv.md`。
- 示例数据与示例输出：用于展示、测试和视觉参考的示例 CSV、生成的 PDF/PNG 文件应分别放在 `data/examples/results/`（输入数据）和 `data/examples/figures/`（生成图像）目录下。当前有一个小型示例 CSV `data/tmp_test_scan.csv`，建议将其复制到 `data/examples/results/`，并把 `docs/dev/active/sample_output` 中的 PDF/PNG 复制到 `data/examples/figures/` 以便集中管理示例数据与输出。

这样可以使文档与示例资源结构清晰，便于 CI/审阅与新来开发者快速复现实验结果。
