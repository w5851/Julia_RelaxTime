## 1. 背景与目标

当前仓库在 `relaxtime / transport` 方向已经具备：

- [x] 单点平衡态求解与 phase-aware continuation
- [x] 单点 `tau` / `tau_inv`
- [x] `eta` / `sigma` / `zeta`
- [x] `kappa_*` 与部分输运组合量
- [x] `xi` 相关连续性与平滑性分析脚本
- [x] phase pipeline / crossover / CEP / spinodal 参考能力

但当前仍缺一条正式的“相图邻域 transport 结果产品化”主线：

- [ ] 缺少以相变线为参考的扫描模式
- [ ] 缺少固定温度、跨化学势的稀疏采样模式
- [ ] 缺少面向用户的 `data/` 层 canonical 结果目录
- [ ] 缺少与 `tests/regression/` 对应的正式治理口径
- [ ] 缺少 README / 项目简介层对新增能力的同步说明

本任务单的目标是：

1. 固化两类新的 transport 扫描模式；
2. 让这些模式与现有 `gap_transport_scan` / `xi_smoothness` / `phase pipeline` 共存；
3. 为用户提供稳定的 CSV + 图 + README 结果资产；
4. 为后续 regression / plot-review / data-layer canonical baseline 打通治理边界。

## 4. 需求收口

### 4.1 新增扫描模式

本期新增两类 phase-guided transport 扫描模式：

#### 模式 a：固定 `mu_B`，沿相变线温度做倍率带

- [x] 对给定 `mu_B`，先取该点相变线参考温度 `T_phase(mu_B, xi)`
- [x] 对温度倍率带 `alpha_T = 1.0, 1.1, 1.2, ...` 做扫描
- [x] 对每个 `alpha_T`，连续扫描 `xi`

当前固定口径：

- crossover 区：
  - base 线使用 `crossover line`
- 一阶相变区：
  - base 线使用**一阶相变线本身**
  - 不使用两条亚稳态相边界线作为 base

#### 模式 b：固定温度，离散 `mu_B`，连续 `xi`

- [x] 固定若干代表性温度点
- [x] 温度点覆盖：
  - crossover 区
  - CEP 附近
  - 一阶相变区
- [x] 每个固定温度下，选择少量离散 `mu_B` 点
- [x] 对每个 `(T, mu_B)` 点连续扫描 `xi`

### 4.2 图形组织规则

- [x] 按 `mu_B/T` 分图
- [x] 按 `T/mu_B` 分线
- [x] 线的横轴统一为 `xi`
- [x] 纵轴优先看 `tau`，再看输运组合量

### 4.3 `tau` 的输出与画图口径

- [x] CSV 中允许一并输出所有 flavor-resolved `tau`
- [x] 画图时按需要区分展示
- [x] 默认主输出保留：
  - `tau_u`
  - `tau_d`
  - `tau_s`
- [x] 在 `mu_B = 0` 时允许 `tau_u = tau_d` 合并展示
- [x] 在有限 `mu_B` 下保留 flavor 分辨，不提前合并

- [x] 现有 `run_gap_transport_scan.jl` 继续保留为基础规则网格入口
- [x] 现有 `xi_smoothness` 相关批处理继续保留为平滑性诊断工具
- [x] 新增模式不直接改写旧模式语义

### 5.2 新模式作为“上层计划模式”接入

当前建议：

- [x] 复用现有 `gap_transport_scan_orchestration.jl`
- [x] 将新增的 `a / b` 模式实现为更高层的 sampling plan / path generator
- [x] 下层逐点执行仍走现有 `execute_gap_transport_scan_point!`
- [ ] 仍未把 phase-guided 上层 plan 进一步并回 `gap_transport_scan_plan.jl`；当前以新增脚本和独立 plan 模块实现，优先保持旧规则网格语义稳定

推荐理解：

1. phase pipeline 负责提供参考线 / 关键点；
2. transport sampling plan 负责展开 `(T, mu_B, xi)` 点列；
3. transport orchestration 负责逐点求解与 CSV 落盘；
4. post-processing 负责分图与 README 汇总。

### 5.3 与介子质量扫描 / 等熵线能力的边界

- [x] 等熵线 / 化学冻结线求解能力不在本期 transport 扫描主轴中引入
- [x] 该能力若后续用于介子质量或介子数密度扫描，应单独设计路径入口
- [x] 本期 transport 只消费 phase line / CEP / 一阶相变线这类参考几何对象

## 10. 风险与回退

- [ ] 风险：新模式直接侵入旧入口，导致现有扫描语义漂移
  - 回退：新增上层 sampling plan，不覆盖旧网格模式

  - 回退：CSV 全量保留，图层只选第一批 canonical 字段
- [ ] 风险：`tau` flavor-resolved 与整体输运量混在同图，解释混乱
  - 回退：`tau` 单独成组，输运系数组合单独成组
- [ ] 风险：full regression 计算过重
  - 回退：先 core 轻量锁定，再逐步升 full canonical case
