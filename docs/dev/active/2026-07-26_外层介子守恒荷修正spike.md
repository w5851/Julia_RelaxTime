## 1. 目标

在固定 `(T,mu_B)` 下，以 `FixedMuBConservedCharges` 的 quark-only 解为初值，外层调整 `(mu_Q,mu_S)`。每个候选点重新求 PNJL 五平均场、计算 quark 净守恒荷与四个带电介子 BU 数密度，使

```text
rho_Q^q + rho_Q^M - r_QB * rho_B^q = 0
rho_S^q + rho_S^M - rho_S_target = 0
```

其中

```text
rho_Q^M = n_pi+ - n_pi- + n_K+ - n_K-
rho_S^M = n_K+ - n_K-
```

介子不携带重子数，因此分母仍由 `rho_B^q` 给出。首个代表点沿用 `T=170 MeV`、`mu_B=240 MeV`、`r_QB=0.4`、`rho_S_target=0`。

## 3. 物理与数值合同

- chemical equilibrium 映射：`mu_pi+=mu_Q`、`mu_pi-=-mu_Q`、`mu_K+=mu_Q+mu_S`、`mu_K-=-(mu_Q+mu_S)`；
- flavor 映射继续使用 `mu_u=mu_B/3+2mu_Q/3`、`mu_d=mu_B/3-mu_Q/3`、`mu_s=mu_B/3-mu_Q/3-mu_S`；
- quark density 必须使用净密度，不得把 `.quark` 粒子密度当作净密度；
- outer residual 使用 `rho0` 归一化的 affine form，不在 `rho_B≈0` 处分母除法；
- 每个候选点固定同一 `mu_B`，从 quark-only branch state warm start，并审计 gap residual；
- 第一版固定 `scheme=:current`，Bose-domain policy 必须显式记录。若使用 `:x_min_cut`，结果只能标为 diagnostic；
- 四个带电密度必须有限且非负，否则本 gate 直接降级为 blocked，不用调参掩盖。

## 5. verdict 规则

- `blocked`：出现非有限/负介子密度、Bose-domain unsafe 未显式处理、outer solve 不稳定，或节点变化与反馈信号同量级；
- `skip-full-feedback`：约束修正稳定收敛，且 chemical potentials 与双通道 ratio 的变化都小于可审计的数值/模型误差预算；
- `full-feedback-candidate`：修正稳定、显著超过节点变化，并满足 `max(|Delta mu_Q|,|Delta mu_S|) > 0.05 T` 或任一 ratio 相对变化超过 `10%`。这些阈值只用于决定是否拉起研究 spike，不是物理接受标准。

无论 verdict 如何，`0.3` 只承担 `O(10^-1)` 数量级锚点，不进入 outer solver objective。

### 7.3 数值与物理边界

- `q4*omega8 -> q8*omega16` 时 corrected `mu_Q/mu_S` 从 `-0.5286/1.7298 MeV` 变到 `-0.4621/1.4955 MeV`，corrected ratios 从 `1.0889/0.8929` 变到 `1.0500/0.8639`；修正解的节点变化相对反馈效应为次级。
- quark-only chemical point 的正 K 通道仍对节点敏感：`K+/pi+` 从 `4.3634` 变到 `5.3481`。该点 `mu_K+` 使请求窗口 `omega_min-mu_K+<0`，有限结果来自显式 `x_min_cut`，不能当成 strict Bose-domain 结果。
- partial-feedback ratios 仍为 `O(1)`，未达到实验常见 `O(10^-1)`；本 outer solve 没有、也不允许以 `0.3` 为拟合目标。
- 因正式 BU kernel 尚未把 finite-window boundary/strict support 纳入 production 认证，且本结果仅到 `q8*omega16`，Phase 5 的热力学反馈实现暂缓。先需要一个物理支撑域安全、节点收敛的 charged BU density baseline，再讨论 `Omega_M` 导数。
