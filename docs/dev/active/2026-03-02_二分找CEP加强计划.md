走“直接二分”（每个 \(T_\text{mid}\) 都重新跑一遍曲线 + S-shape + Maxwell）时，核心目标是把判定函数  
\(g(T)=\mathbf{1}[\text{S-shape 有效} \land \text{Maxwell 收敛}]\) 做到**尽量接近单调、且误判可控**。下面是我建议你重点抓的实现细节。

**1) 把二分判定做成“三态 + 置信度”，别只用 True/False**  
直接二分最怕的不是“网格不对齐”，而是数值噪声让 \(g(T)\) 在阈值附近抖动。建议把评估结果定义为：
- **valid**：S-shape 明确存在且 Maxwell 残差 \(\le \varepsilon_\text{good}\)
- **invalid**：S-shape 明确不存在，或 Maxwell 明确失败/残差 \(\ge \varepsilon_\text{bad}\)
- **unknown**：介于两者之间（例如残差在 \([\varepsilon_\text{good},\varepsilon_\text{bad}]\)，或 S-shape 特征“疑似但不稳”）

二分更新规则：
- valid → 视为低温侧，更新 \(T_\text{low}=T_\text{mid}\)
- invalid → 更新 \(T_\text{high}=T_\text{mid}\)
- unknown → **不移动 bracket**，而是触发“同一 \(T_\text{mid}\) 的加密重算”（见第 3 点）

这样能显著减少“偶发误判导致二分跑偏”。

**2) bracket 发现要稳：先用粗扫找到“最后 valid 的区间”，再二分细化**  
建议两阶段：
- **粗扫**：从低温到高温（或相反）用较便宜配置，找出最后一个 valid 的 \(T_a\) 和第一个 invalid 的 \(T_b\)，形成 \([T_a,T_b]\)
- **二分**：在该区间内用更严格配置（或自适应）细化

如果粗扫里出现 valid/invalid 交替，优先把它当成“数值不稳”，回到第 1 点三态机制处理，而不是硬二分。

**3) 每次评估 \(g(T)\) 都要带“自适应加密”策略（这是直接二分的灵魂）**  
你不对齐 \(\rho\) 网格没问题，但必须保证“在该 \(T\) 上网格足够好”。一个很实用的策略是“逐级加密直到判定稳定”：
- level 0：默认 \(\rho\) 点数 / 默认求解容差
- 若 S-shape 指标接近临界（例如导数符号变化只出现 1 次、极值很浅、回折段很窄）→ **局部加密 \(\rho\)**（在疑似转折区插点或缩步）
- 若 Maxwell 残差落在灰区（unknown）→ **提高积分精度/加密回折区间采样/收紧求解容差**再试
- 设最大 level，超过后仍 unknown：返回 unknown，并在总流程里计入“失败原因：判据不确定”

要点：**只在“接近边界”的温度点做贵的加密**，整体成本可控。

**4) S-shape 检测尽量做成“对离散不敏感”的版本**  
常见坑是用简单差分找极值，网格稍变就丢。建议：
- 用“符号变化 + 持续性”而不是“单点极值”：例如要求 \(\partial\mu/\partial\rho<0\) 的区间长度（或点数占比）超过阈值才算 S-shape
- 对疑似转折点区间做二次细化：在 \(\rho_i,\rho_{i+1}\) 之间补点验证，而不是直接下结论
- 记录一个连续指标（比如最小斜率、负斜率区宽度、极值深度），作为第 1 点置信度来源

**5) Maxwell 构造要“可重复”：固定口径、双阈值、失败可解释**  
建议把 Maxwell 评价拆成几类可诊断失败，而不是一个笼统的 false：
- **无可用区间**（S-shape 有但没有形成可构造的双相区间）
- **数值积分不稳定**（加密后残差变化大）
- **残差超阈值**（明确不满足等面积）
- **求解器未收敛/超迭代预算**

并采用双阈值：
- \(\varepsilon_\text{good}\)：判定 valid
- \(\varepsilon_\text{bad}\)：判定 invalid
- 中间灰区 → unknown → 触发加密

这样二分会更“单调友好”。

**6) 性能建议：continuation + cache，直接二分也能很快**  
每个 \(T_\text{mid}\) 都重新算确实贵，但可以用两类加速：
- **温度 continuation / warm-start**：用最近温度点的求解结果作为初值（同一 \(T\) 重算加密尤其有效）
- **缓存评估结果**：把已评估过的 \(T\)（以及其 level/网格参数/判据结果）缓存起来，避免重复

二分过程中会反复命中相同或相近的 \(T\)，缓存收益很高。

**7) 停止条件别只看 \(\Delta T\)，还要看“判据稳定性”**  
推荐停止条件组合：
- 温度区间宽度 \(T_\text{high}-T_\text{low} < \Delta T_\text{min}\)
- 且 \(T_\text{low}\) 的 valid 结果在最高允许 level 下仍稳定（例如加密不改变 valid/invalid 结论）
- 输出最好给一个“温度不确定度” \(\pm (T_\text{high}-T_\text{low})\)，这对后续解释很有帮助
