# K/pi 文献量级差异初判

更新日期：2026-05-03

目的：解释为什么本地论文库中常见的 `K/\pi ~ 0.2` 量级，与当前项目在 `Phase F` 阶段性结果中的 `K/\pi` 看起来差异很大，并明确下一步该如何做可比对照。

相关输入：

- 本地文献库：
  - `paper_lib/docs/papers/介子数密度(及其比值)/Blaschke 等 - 2017 - Mott dissociation of pions and kaons in hot, dense quark matter.txt`
  - `paper_lib/docs/papers/介子数密度(及其比值)/Blaschke 等 - 2020 - Using the Beth–Uhlenbeck Approach to Describe the Kaon to Pion Ratio in a 2 + 1 Flavor PNJL Model.txt`
  - `paper_lib/docs/papers/介子数密度(及其比值)/Blaschke 等 - 2021 - Mott dissociation and kaon to pion ratio in the EPNJL model.txt`
- 当前项目阶段性结果：
  - `docs/dev/active/2026-05-03_PhaseF最小结果说明.md`

## 1. 当前最关键的判断

当前“文献里常见 `K/\pi ~ 0.2`”与“项目当前阶段性结果更高”之间，**首先不是同一物理量的直接对比**。

至少有四层口径差异：

1. 文献中很多讨论的是 `K^+/\pi^+` 或 `K^-/\pi^-`
2. 当前项目阶段性结果默认是总 `K/\pi` 聚合数密度比
3. 文献中很多结果沿 `freeze-out line` 或 `critical line`
4. 当前 `Phase F` 阶段性图层固定的是 `\mu_B = 0`、`T = 208:2:220 MeV`

因此，当前两者不能直接用“数值不一致”判断实现对错。

## 2. 本地文献库里已经读到的直接证据

### 2.1 2017 文献不是简单 `\mu_B = 0` 温扫

`Blaschke 2017` 明确写到：

1. strange chemical potential 取 `\mu_s = 0.2 \mu`
2. 讨论沿 `\mu/T = const` 轨迹
3. 这些轨迹被解释为近似 freeze-out / 熵守恒演化路径

因此它不是当前项目默认的：

1. `\mu_B = 0`
2. `\mu_s = 0`
3. 纯温扫

### 2.2 2020/2021 文献的主目标是 `K^+/\pi^+` horn 现象

`Blaschke 2020` 与 `Blaschke 2021` 的本地文本都明确表明：

1. 讨论的是 `K^+/\pi^+` 与 `K^-/\pi^-`
2. 比较对象是重离子碰撞 yield ratio / horn
3. 使用 freeze-out 线或相变线映射
4. 会显式考虑 `\mu_\pi` 的现象学角色

所以这些文献更接近：

1. 带电粒子比值
2. 冻结线现象学
3. 非平衡 pion chemical potential

而不是当前仓库里最小主线的：

1. 总 `K/\pi`
2. `\mu_B = 0`
3. `\mu_\pi = 0`
4. 静态均匀介质温扫

## 3. 当前项目内部的定量证据

为了判断“量级差异是否主要来自口径不一致”，本轮做了一个最小数值检查。

在当前 stable 链、`\mu_B = 0`、`\xi = 0` 下：

1. `T = 150 MeV`：
   - 总 `K/\pi = 0.325`
2. `T = 160 MeV`：
   - 总 `K/\pi = 0.366`
3. `T = 170 MeV`：
   - 总 `K/\pi = 0.407`

这说明只要把温区从当前 `208:2:220 MeV` 下移到更接近 freeze-out 的 `150-170 MeV`，总 `K/\pi` 本身就会显著下降。

## 4. 带电比值与总比值的差别

当前项目默认总简并度是：

1. `d_\pi = 3`
2. `d_K = 4`

若文献讨论的是带电单通道 `K^+/\pi^+`，那么在最粗略的“只先换简并度口径”下，可把总比值乘一个：

```math
\frac{1/4}{1/3} = \frac{3}{4}.
```

于是上面的 stable 总比值会变成：

1. `T = 150 MeV`：
   - 带电口径代理约 `0.244`
2. `T = 160 MeV`：
   - 带电口径代理约 `0.275`
3. `T = 170 MeV`：
   - 带电口径代理约 `0.305`

这已经明显靠近“文献里常见 `~0.2`”的量级。

## 5. 还会进一步压低比值的因素

在文献主线里，除温区与带电口径外，还有几类因素会继续改变比值：

1. `\mu_\pi > 0`
   - 会增强 pion 数密度，从而压低 `K/\pi`
2. `\mu_s \neq 0` 或 baryon / strange chemical potential 组合
   - 会改变 kaon 与 antikaon 通道的非对称性
3. freeze-out line / critical line 扫描
   - 使 `(T,\mu_B)` 联动，而不是固定 `\mu_B = 0`
4. 文献比较的是 yield ratio，而不是简单的固定热平衡单点数密度比

因此，若文献给出的是 `K^+/\pi^+ ~ 0.2`，那么当前项目在 `\mu_B = 0`、`T = 208:2:220 MeV` 的总 `K/\pi` 阶段性结果更高，是完全可以预期的。

## 6. 当前对项目主线的含义

这一步的结论不是“当前项目结果已经对齐文献”，而是：

1. 当前差异**有强烈迹象主要来自口径差异**
2. 当前 `Phase F` 阶段性结果不应直接拿去对标 horn 文献里的 `K^+/\pi^+`
3. 若后续要把本地文献库结果变成验证目标，必须先按口径拆分

建议至少拆成三类：

1. 总 `K/\pi`、`\mu_B = 0`、纯温扫可比
2. 带电 `K^\pm/\pi^\pm`、freeze-out line 可比
3. 含 `\mu_\pi` / `\mu_s` / anomaly mode 的现象学口径，需单列

## 7. 下一步建议

更合理的后续顺序是：

1. 先完成正式 `meson_density/` 目录与 baseline/regression 契约固定；
2. 再从本地文献库中筛出与当前主线最可比的一组结果；
3. 若要进入 horn / `K^+/\pi^+` 文献对照，则应单独增加：
   - 带电通道口径
   - freeze-out 线扫描
   - `\mu_\pi` / `\mu_s` 设定

## 8. 本页结论

当前“文献常见 `K/\pi ~ 0.2`”与“项目当前阶段性结果更高”的主要矛盾，不像是实现错误，更像是：

**比较的对象本身不同：总比值 vs 带电比值、`\mu_B = 0` 高温温扫 vs freeze-out 线、平衡态 vs 含 `\mu_\pi` 的现象学口径。**
