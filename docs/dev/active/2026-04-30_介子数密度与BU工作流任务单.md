  - `src/relaxtime/MesonMass.jl`

- [x] 先确定总体工作流

`文献整理 -> 公式与记号统一 -> 最小问题定义 -> BW/稳定极限验证 -> BU 相移实现 -> 数值扫描与图 -> 再考虑 EOS`
