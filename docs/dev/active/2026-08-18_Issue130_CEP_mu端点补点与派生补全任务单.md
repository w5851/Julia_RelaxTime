三层都必须保留 calculation SHA、输入/派生 manifest hash 和生成脚本 hash。derived
reference 与 render 不得覆盖 strict 文件；图像视觉闭合也不能反向改变数据层的

## 为什么需要 μ 方向补点

C2 的细网格主要细化 rho，而 crossover CSV 每个 xi 切片只有有限的 μ 采样。
`crossover_cep_sampling_gap.csv` 显示最后一个物理侧 crossover 点与 CEP proxy
之间存在原生采样 gap；该 gap 不能使用 `mu_q>mu_CEP` 的被排除响应峰直接连接。

  候选 μ 区间；Maxwell boundary 只作为独立 route 的停止边界和 provenance。
