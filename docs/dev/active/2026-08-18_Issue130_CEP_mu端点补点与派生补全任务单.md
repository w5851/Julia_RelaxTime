## 为什么需要 μ 方向补点

C2 的细网格主要细化 rho，而 crossover CSV 每个 xi 切片只有有限的 μ 采样。
`crossover_cep_sampling_gap.csv` 显示最后一个物理侧 crossover 点与 CEP proxy
之间存在原生采样 gap；该 gap 不能使用 `mu_q>mu_CEP` 的被排除响应峰直接连接。

## 实施阶段

### A. Solver-free target-list 与成本预检

- 从 `crossover_cep_sampling_gap.csv`、CEP bracket overlay 和 Maxwell boundary
  生成每个 xi 的候选 μ 区间。
- 补点只位于最后保留 crossover 点与 CEP proxy 的物理侧区间内；不读取 oracle 标签，
  不使用被排除响应峰作为 route 锚点。
- 首轮 target policy 使用区间中点和靠近 CEP 的内部点；所有目标必须是严格低于
  CEP proxy 的 μ，不在 CEP 边界上硬插 crossover。
- 输出 target list、输入 hash、预期 slice 数、成本 envelope 和停止条件。

### B. Numerical pilot

- 先覆盖代表性 xi：`-0.5`、`0`、`0.2875`、`0.5`。
- 每个新 μ 点保存完整 response/rho 曲线、crossover 候选、CEP 相对位置、finite/
  converged、solver telemetry 和成本。
- 只要出现 solver failure、非有限、跨入 Maxwell 物理区或 endpoint classification
  不稳定，停止扩展，保留诊断 evidence。

### C. 全 xi 扩展与 derived completion

仅当 pilot 通过后，才扩展到全部 xi 切片。生成两层数据：

1. `certified_layer`：原始 C2 finite/converged boundary/crossover，完全不改；
2. `completed_layer`：仅在同一物理区、无跨 CEP、无外推的局部范围内插值，标记
   `interpolated_noncertified`，记录 source keys、方法、距离和误差估计。

Maxwell 的 `maxwell_area` 不因插值而伪造为证书；CEP bracket 内保持
`endpoint_ambiguous` 或显式 bracket 语义。completed artifact 只能作为下游显式选择的
派生输入，不能自动替代 strict phase-reference。

## 不变范围

- 不重跑完整 C0/C1/C2。
- 不修改 equilibrium solver、Maxwell、三态规则、endpoint policy 或既有容差。
- 不覆盖历史 C2、reference、transport 或 v5 evidence。
- 不把普通全局插值跨过 CEP，也不把 crossover 和 Maxwell 在同一 `(xi,mu_q)`
  赋予双重物理含义。

## 验收与停止

- preflight 必须证明 target μ 严格位于物理 crossover 侧，输入 key 唯一且 provenance
  完整；否则不运行 numerical。
- pilot 必须无 solver/finite/key/provenance failure，并保持 endpoint 状态与已接受
  T bracket 一致。
- 只有 pilot 通过，才可请求全 xi 扩展；任何失败都保持 diagnostic-only。
- 本任务完成后仍需作者审核 completed artifact，之后才讨论 phase-reference promotion
  和 RS transport 解锁。
