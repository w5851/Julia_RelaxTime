## 1. 背景与目标

现有 PNJL dense phase reference 使用固定 Gauss--Legendre 张量积网格：动量节点覆盖 `p in [0, 10] fm^-1`，角节点覆盖 `cos(theta) in [0, 1]`。`T=60 MeV` 已出现比更高温区明显的密度和 spinodal 收敛漂移；继续把温区向 `T=0` 延伸时，固定全区间节点不能自动解析费米面附近宽度约为 `O(T)` 的窄结构。

本任务的最终目标是建立不依赖旧稀疏相边界插值、覆盖明确全温区、带积分/相线/产物三级收敛证据的 PNJL phase reference，并让后续 transport production 显式绑定其 tag、manifest SHA 与热力学积分策略。

当前 PR 1 的目标是：

- 审计 phase thermodynamics 的全部角度依赖；
- 为 PNJL 热项引入显式、可审计的积分策略；
- 利用 RS 标量热核的角约化降低维数；
- 建立低温径向自适应与 `T=0` 数值语义；
- 保持现有统一 Models 入口、求解分支治理和默认固定网格兼容路径。

## 3. 当前能力与角度依赖审计

### 3.1 审计结论

对当前 `model_kind=:PNJL` phase 主路径，以下结论成立：

| 路径 | 角度/xi 进入位置 | 是否满足“角度只通过分布能量进入” | 处理 |
| --- | --- | --- | --- |
| `omega_components` 的 chi/poly/vac | 无 | 是 | 不变 |
| `PNJLIntegrals.calculate_log_sum` | 仅 `E_xi=sqrt(m^2+p^2(1+xi*cos(theta)^2))` | 是 | 可做 RS 角约化 |
| `model_rho`、`model_thermo` | 对上述标量压强做 AD | 是 | 继承同一积分策略 |
| `PNJLModel.number_densities` | 仅分布函数的 `E_xi` | 是 | 可做同一角约化 |
| phase scan / Maxwell / spinodal / CEP | 只消费标量状态和热力学量 | 是 | 不引入角核 |

因此对积分上限为无穷、且被积函数除 `E_xi` 外不含角度的标量热核，有

```math
\int_{-1}^{1} dc \int_0^\infty p^2 dp\,
F\!\left(\sqrt{m^2+p^2(1+\xi c^2)}\right)
=
\frac{2}{\sqrt{1+\xi}}
\int_0^\infty q^2 dq\,F\!\left(\sqrt{m^2+q^2}\right).
```

### 3.2 限定与缺口

- 现有球形有限截断 `p <= 10 fm^-1` 在变量替换后产生角度相关的 `q_max`，不能与固定 `q_max=10` 严格等同；新约化路径必须使用无穷区间或显式尾部误差控制。
- `T=0` 时现有热项、分布和 Polyakov 势含 `1/T`；不得把接近零温结果冒充严格零温结果。
- 通用逐调用自适应积分可能造成 AD 求解中的开销和数值路径跳变；必须用固定点 oracle、求解级收敛和 benchmark 判定是否可作为 production 内层算法。
- PNJL magnetic 与 transport kernel 含独立角结构，不适用本次标量约化。
