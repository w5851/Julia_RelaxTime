# 介子热力学扩展任务单

更新日期：2026-05-09

当前状态：实施中。第一版 `meson pressure` kernel、workflow、最小 CSV 合同与单测已落地；`QP / LD` 分区已在 phase-shift pressure 口径下显式化；后续继续沿 meson thermo 主线收敛，不并入 dense reference、meson mass path scan 或公共回归治理改造。

---

## 1. 任务目标

本任务单只处理一条主线：

- 把现有 `meson density / propagator / phase-shift` 能力提升为正式的介子热力学能力
- 明确文献对齐边界、输出合同、测试治理和后续扩张顺序
- 为后续 `Omega_total` 接线和 canonical EOS 结果资产打基础

本任务单不负责：

- dense reference / phase-guided transport 相关任务
- meson mass path scan 相关任务
- EPNJL 扩展
- README 主文档宣传口径更新
- regression baseline 更新

---

## 2. 关键物理结论

### 2.1 文献对齐边界

- [x] `Maslov & Blaschke 2023` 提供的是 `BU / off-shell / LD -> EOS` 的机制主线
- [x] 该文献中的 `sigma` 对当前项目更接近 `sigma_pi`
- [x] 因此当前项目的 `pi/K` 不能直接视作文献的近同构实现
- [x] `pi/K` 目前只应视为第一版原型 workflow
- [x] 若继续沿该文献方向推进，后续主通道应收敛到 `pi/sigma_pi`

### 2.2 系统热力学约束

- [x] `MesonThermodynamics` 层负责给出 `P_M`
- [x] `P_M` 并入总系综后，正式派生量应走 `Omega_total -> Models -> ForwardDiff`
- [x] workflow 层的局部差分热力学只能视为过渡实现，不是最终标准口径
- [x] 文献对齐时，`P_quark_meanfield / P_total` 应支持 vacuum-normalized pressure reference，而不只是保留原始绝对压强
