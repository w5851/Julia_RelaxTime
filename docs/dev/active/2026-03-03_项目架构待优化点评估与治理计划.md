### 5.1 `hbarc` 精度不一致

| 配置文件 | 值 | 备注 |
|---------|-----|------|
| `config/njl/default.toml` | `197.3269804` | 高精度 |
| `config/pnjl/default.toml` | `197.327` | 低精度，相对差异 ~1.5×10⁻⁵ |

- [x] **P2.1** 统一 `hbarc` 精度为 PDG 标准值 `197.3269804`
- [x] **P2.2** 评估当前是否因此导致 NJL/PNJL 跨模型对比时的数值偏差
  - 评估方法：在相同 MeV 物理点下，分别用 `hbarc=197.327` 与 `hbarc=197.3269804` 运行 NJL/PNJL（FixedMu，`p_num=8,t_num=4`），比较跨模型差值 `Δ = p_PNJL - p_NJL` 的漂移。
  - 结果：
    - 点 `(T,μ)=(110,20) MeV`：`|Δ_new-Δ_old|=2.506e-8`，相对漂移 `3.975e-7`
    - 点 `(T,μ)=(130,40) MeV`：`|Δ_new-Δ_old|=7.593e-8`，相对漂移 `3.974e-7`
  - 结论：`hbarc` 精度统一对 NJL/PNJL 跨模型对比影响可忽略（~`4e-7` 量级）。
  - 同步修复：`config/physics/default.toml` 仍残留旧值，已对齐为 `197.3269804`，避免默认运行路径继续使用旧常量。

- [x] **P2.5** 评估根级文件内收方案（需考虑对 relaxtime 全链路的影响）
  - 影响面评估：`src/` 内对四个根级文件与 `Main.*` 绑定存在高密度引用（`relaxtime`/`simulation`/`utils` 多模块）；`tests/` 与 `scripts/` 仍有大量 `include(".../src/Constants_PNJL.jl")` 与 `Main.ParameterTypes` 直接依赖。
