## 1. 当前检查口径

本轮保持下列约束不变：

- 正式相位仍取 `delta_M(omega, q) = arg D_M(omega + i eta, q)`
- 各向同性 `xi = 0`
- `d^3q` 通过球对称化约为径向一重积分
- `q` 与 `omega` 两个方向都先用 Gauss-Legendre + 有限硬截断

当前检查窗口：

- `T = 208, 210, 212 MeV`
- `meson = pi, K`
- `omega_max = 8, 10, 12`
- `qmax = 8, 10, 12`
- 主比较节点数：`q_nodes = 48`, `omega_nodes = 48`
- 附加分辨率检查：`qmax = 12` 下再做 `q_nodes = 64`

---

## 2. 最关键结果

### 2.1 `omega` 方向当前不是主要问题

在前一轮 `Phase E2` 与 `omega` 最小积分诊断里，已经看到：

- 高能相位在 `omega ≈ 10` 时自然趋近 `0`
- 固定 `q = 0` 时，`omega` 方向积分核尾部已衰减到 `1e-11` 量级

因此本轮主要关注外层 `q` 积分，而不是继续把问题归因到 `omega` 高能尾部。

### 2.2 `q` 末端壳贡献已经出现明显衰减

以 `omega_shell_at_qmax` 作为“最外层壳是否还很重”的最小代理，可见：

- `qmax = 8`：约 `2.4e-2 ~ 3.0e-2`
- `qmax = 10`：约 `5.6e-3 ~ 7.1e-3`
- `qmax = 12`：约 `1.2e-3 ~ 1.6e-3`

这说明：

- `qmax = 8` 虽然已经进入尾区，但壳贡献还不够小
- `qmax = 10` 明显更接近可接受范围
- `qmax = 12` 时已经把壳贡献进一步压低了约一个数量级

### 2.3 双积分总量开始变缓，但还不能直接说“完全收敛”

双积分估计 `double_integral_estimate` 的代表性变化为：

- `pi`：
  - `qmax = 8`：约 `2.75 ~ 2.77`
  - `qmax = 10`：约 `2.82 ~ 2.84`
  - `qmax = 12`：约 `2.81 ~ 2.82`
- `K`：
  - `qmax = 8`：约 `3.71`
  - `qmax = 10`：约 `3.81 ~ 3.82`
  - `qmax = 12`：约 `3.87 ~ 3.88`

当前含义应谨慎表述为：

- `pi` 通道在 `qmax = 10 -> 12` 之间已经出现平台迹象
- `K` 通道仍在继续上移，但变化速度比 `8 -> 10` 时更慢

因此当前更合理的说法是“**出现了初步收敛证据**”，而不是“已经严格收敛”。

### 2.4 在当前窗口内，`omega` 节点数已经基本稳定

固定 `qmax = 12`、`q_nodes = 64` 后，把 `omega_nodes` 从 `96` 提到 `128`，双积分估计与末端壳贡献都几乎不变。

这说明：

- 当前内层 `omega` 分辨率已经不是主要误差源
- 后续更值得投入的是 `qmax` 与外层 `q` 节点数的收敛表

### 2.5 `omega_max = 10` 是当前更合适的默认口径

固定 `qmax = 12`、`q_nodes = 48`、`omega_nodes = 48` 后，对 `omega_max = 8, 10, 12` 的比较显示：

- `omega_max = 8` 相对 `10` 仍有约 `0.1% ~ 0.2%` 的系统偏低
- `omega_max = 12` 相对 `10` 的差异已经压到 `10^-4 ~ 10^-3` 量级

这说明：

- `omega_max = 8` 已经接近可用，但略偏紧
- `omega_max = 12` 没有带来足够大的额外收益
- 因而 `omega_max = 10` 是当前默认值更好的平衡点

---

## 3. 节点数敏感性最小检查

在 `qmax = 12` 下，把 `q_nodes` 从 `48` 提到 `64` 后：

- `pi` 通道双积分估计改变量约 `+1%`
- `K` 通道双积分估计改变量约 `0% ~ -1%`

这说明两点：

1. 当前结果已经不再对 `q` 节点数极端敏感
2. 但节点误差还没有小到可以完全忽略，尤其在要形成正式数值产出前，仍值得补一个更系统的收敛表

---

## 4. 当前阶段结论

截至本轮，`Phase E3` 的最小判断可以收口为：

- 正式 BU 主线已经从“相位是否可读”推进到“二维积分是否开始收敛”
- `omega` 方向当前已经不像主要障碍
- 真正需要继续诊断的是 `q` 方向截断与分辨率
- 在用户偏好的 `GL + 硬截断` 路线下，当前更合理的默认诊断口径可先定为：
  - `qmax = 12`
  - `q_nodes = 48`
  - `omega_max = 10`
  - `omega_nodes = 48`

---

## 5. 下一步建议

当前更合理的下一步是：

1. 以 `qmax = 12, q_nodes = 48, omega_max = 10, omega_nodes = 48` 作为当前默认诊断口径
2. 开始把这套口径往正式 workflow / 模块实现推进
3. 同时补 benchmark，记录绝对耗时与在完整点求解中的相对占比
4. 在正式实现稳定后，再决定是否需要更系统的极端参数收敛表

## 6. 当前判断一句话版

- **Phase E3 当前已看到双积分的初步收敛证据；剩余主要问题是 `q` 方向的截断与节点收敛，而不是高能 `omega` 尾部。**
