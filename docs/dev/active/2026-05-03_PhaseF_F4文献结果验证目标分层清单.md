# Phase F F4 文献结果验证目标分层清单

更新日期：2026-05-03

目的：把本地参考文献库中与介子数密度 / `K/\pi` 比值相关的结果，按“当前主线可直接对比 / 需单独现象学链 / 暂不适合做回归目标”分层，作为后续验证目标治理清单。

相关输入：

- 本地文献库目录：
  - `paper_lib/docs/papers/介子数密度(及其比值)/`
- 当前主线口径：
  - `μ_B = 0`
  - `ξ = 0`
  - 总 `π/K` 数密度
  - `μ_π = 0`
  - `μ_K = 0`
  - 当前阶段性窗口 `T = 208:2:220 MeV`

## 1. 分层标准

### A 类：可直接提取并进入当前主线验证

要求至少满足：

1. 与当前主线是同一类物理量：
   - 总 `K/\pi` 或可直接换算到总 `K/\pi`
2. 不依赖 freeze-out 线 / critical line / collision-energy 映射
3. 不依赖 `μ_π`、`μ_s` 等额外现象学输入
4. 最好是 `μ_B = 0` 温扫，或至少可直接抽出对应极限

### B 类：需人工转录或需单独现象学链后才可比

典型特征：

1. 讨论的是 `K^+/\pi^+`、`K^-/\pi^-`
2. 依赖 freeze-out 线 / critical line / `T/μ_B`
3. 需要 `μ_π`、`μ_s`、anomalous mode 等额外设定
4. 当前主线若不扩展口径，不能直接做 regression 真值

### C 类：当前暂不适合作为验证目标

典型特征：

1. 主要提供公式来源或方法论支持
2. 不直接给当前链可比的 `n_π(T)` / `n_K(T)` / `K/\pi(T)`
3. 或口径与当前项目主线差得太远，短期内没有可执行对齐路径

## 2. 当前文献分层结果

### 2.1 A 类：当前未发现强候选

截至本轮盘点，当前本地文献库中**没有明显属于 A 类的强候选**。

原因不是文献无价值，而是当前库中与 `K/\pi` 直接相关的几篇核心文献，主目标几乎都偏向：

1. `K^+/\pi^+` horn
2. freeze-out / critical line
3. `μ_π` / `μ_s`
4. charged-yield phenomenology

而不是当前项目最小主线的：

1. 总 `K/\pi`
2. `μ_B = 0`
3. 平衡态温扫

### 2.2 B 类：可作为后续现象学验证目标的主力

#### `Blaschke:2016sqn` (2017)

角色：

1. 传播子 / BU / Mott 公式的重要来源
2. 含 freeze-out / horn 讨论

当前分层：`B`

原因：

1. 文中明确使用 `μ_s = 0.2 μ`
2. 沿 `μ/T = const` 轨迹讨论
3. 结果与 freeze-out / heavy-ion yield 语境绑定
4. 涉及 `K^+/\pi^+` 与 `K^-/\pi^-`

当前建议：

1. 不进入当前 `μ_B = 0` 主线 regression
2. 作为未来 charged / freeze-out 子链的重要验证目标

#### `Blaschke:2019col` (2020, Particles)

角色：

1. 当前最直接的 BU `K^+/\pi^+` 现象学文献之一
2. generalized BU 与 partial density/pressure 比较来源

当前分层：`B`

原因：

1. 明确比较 `K^+/\pi^+` 与 `K^-/\pi^-`
2. 使用 chemical freeze-out line / critical line
3. 结果对 `μ_π` 很敏感
4. generalized BU 也在 charged-ratio 场景下出现

当前建议：

1. 未来若开 `charged + freeze-out + μ_π` 子链，应优先提取此文的图/点
2. 当前先不把它当作总 `K/\pi` regression 目标

#### `Blaschke:2020bzh` (2020, EPNJL)

角色：

1. EPNJL 版本的 charged `K/\pi` 现象学链
2. 比较 BW 与 BU、freeze-out 与 critical proxy 的重要参考

当前分层：`B`

原因：

1. 目标是 `K^+/\pi^+` / `K^-/\pi^-`
2. 沿 `(pseudo-)critical line` 作为 freeze-out proxy
3. 引入 `x = T/μ_B`
4. 文中明确使用 `μ_s = 0.55 μ_u`、非平衡 pion chemical potential 等设定

当前建议：

1. 后续做 horn 子链时，优先作为 EPNJL 侧验证目标
2. 当前不直接进入主线 regression

#### `Blaschke:2021yml` (2021)

角色：

1. 2020 EPNJL horn 逻辑的延伸和总结
2. charged ratio、freeze-out、`μ_π` 的压缩版本参考

当前分层：`B`

原因：

1. 文中明确围绕 `K^+/\pi^+` horn
2. 沿 phase transition / freeze-out line
3. 强调 nonequilibrium pion chemical potential

当前建议：

1. 可作为后续 charged-horn 子链的补充验证文献
2. 不直接做当前总 `K/\pi` 主线 regression

#### `Friesen:2019ojk` (2019)

角色：

1. SU(3) PNJL 下 charged `K/\pi` 的前置现象学参考
2. 强调 freeze-out / chiral transition line

当前分层：`B`

原因：

1. 文章主目标就是 `K^+/\pi^+`
2. 使用 freeze-out line 语境
3. 不是当前 BU 主线的总比值口径

当前建议：

1. 未来可作为“非-BU charged 现象学对照”
2. 当前不进入主线 regression

## 4. 当前可执行结论

就 `F4` 当前阶段而言，可以明确写下：

1. 本地文献库中与 `K/\pi` 直接相关的核心文献，大多属于 `B` 类
2. 当前主线没有明显的 `A` 类强候选可直接拿来做 regression 真值
3. 因此当前更合理的做法是：
   - 先固定项目内 baseline/regression
   - 再单独规划 charged / freeze-out 文献对照子链
