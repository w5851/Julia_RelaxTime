# 技术债优先级清单与验收任务单（执行版，可勾选）

## 目标

将当前项目的技术债治理工作拆分为可执行、可验收、可追踪的任务单，按优先级分为 P0/P1/P2。

## 执行顺序

1. 先完成 P0（质量门禁与主链路正确性）
2. 再推进 P1（结构解耦与回归强度）
3. 最后处理 P2（治理运营与长期维护）

---

## P0（最高优先级：阻断回归风险）

### P0-1：DEFAULT_SKIP 清零计划（分项转正）

- [ ] 为以下 4 个 skip 用例建立逐项转正任务：
  - [ ] `test_core_integrals.jl`
  - [ ] `test_implicit_jacobian.jl`
  - [ ] `test_scans.jl`
  - [ ] `test_differential_cross_section.jl`
- [ ] 每个用例补齐“失败根因 + 修复策略 + 回归点”记录。

**可执行脚本**

```powershell
julia --project=. scripts/dev/check_unit_skip_policy.jl
julia --project=. tests/unit/runtests.jl
```

**验收标准**

- [ ] `scripts/dev/check_unit_skip_policy.jl` 通过。
- [ ] `config/ci/unit_skip_policy.toml` 与 `tests/unit/runtests.jl` 一致。
- [ ] `DEFAULT_SKIP` 条目数相较当前基线不增加（理想为下降）。

---

### P0-2：主链路固定点回归（PNJL + Transport）

- [ ] 固化最小固定点回归集合（T/μ/ξ 若干代表点）。
- [ ] 将固定点结果写入统一结果目录并纳入比对。
- [ ] 对超阈值偏差给出失败退出与定位提示。

**可执行脚本**

```powershell
julia --project=. scripts/relaxtime/run_gap_transport_scan.jl --help
julia --project=. tests/unit/runtests.jl
```

**验收标准**

- [ ] 固定点回归在 CI 中可重复。
- [ ] 结果落盘路径统一为 `data/outputs/`。
- [ ] 偏差超阈值时任务失败并输出可定位信息。

---

### P0-3：单元测试语义收敛（unit 与 smoke 边界）

- [ ] 清点 `tests/unit/` 中偏 workflow/integration 的条目。
- [ ] 将非纯 unit 用例迁移到 `tests/analysis/` 或 `tests/perf/`（按性质）。
- [ ] 保持 `UNIT_PROFILE=smoke` 的稳定绿色基线。

**可执行脚本**

```powershell
$env:UNIT_PROFILE='smoke'; julia --project=. tests/unit/runtests.jl
$env:UNIT_PROFILE='full';  julia --project=. tests/unit/runtests.jl
```

**验收标准**

- [ ] `smoke` 通过且时长稳定（无明显回归）。
- [ ] `full` 可运行并反映真实测试面，不混入脚本型检查。
- [ ] 迁移后的目录职责与 `docs/dev/README.md` 约定一致。

---

**可执行脚本**

```powershell

```

**验收标准**

## P2（低优先级：治理优化与运营降噪）

### P2-1：active 文档池持续归档

- [ ] 按周检查 active 文档是否超 60 天。
- [ ] 对完成项执行归档并补齐 metadata。

**可执行脚本**

```powershell
julia --project=. scripts/dev/check_active_docs_governance.jl
julia --project=. scripts/dev/archive_docs.jl <filename.md>
```

**验收标准**

- [ ] active 文档命名全部符合 `YYYY-MM-DD_*.md`。
- [ ] 超期文档为 0 或有明确豁免说明。
- [ ] archived 文档 frontmatter 完整可追溯。

---

### P2-2：输出目录口径彻底统一

**可执行脚本**

```powershell
julia --project=. scripts/relaxtime/run_gap_transport_scan.jl --help
```

**验收标准**

- [ ] 新输出不再写入根级 `outputs/`。
- [ ] 文档中仅保留 `data/outputs/` 作为默认口径。
- [ ] 历史兼容路径有迁移说明。
