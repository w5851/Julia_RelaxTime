目的：记录 `Phase E2` 首轮检查结果，回答当前 `delta_M(omega,q)` 是否已经具备直接接入正式 BU 数密度积分的条件。

## 1. 当前检查范围

本轮在 `Phase E1` 的基础上，进一步做了：

- `T = 208, 210, 212 MeV`
- `q = 0.0, 0.2`
- `omega_max = 6.0`
- 更细的 `omega` 步长

目标是补看两件事：

1. 相位分支是否仍保持可读
2. 高能端相位是否已经接近回零

## 2. 当前可确认的结论

### 2.1 峰位与参考质量/阈值关系仍然正常

传播子 `|D_M|` 的峰位继续与 `mass_ref`、`threshold_ref` 保持可解释关系。

例如：

- `T = 210 MeV, q = 0`
  - `pi`
    - `peak_omega ≈ 0.885`
    - `mass_ref ≈ 0.910`
    - `threshold_ref ≈ 0.698`
  - `K`
    - `peak_omega ≈ 2.505`
    - `mass_ref ≈ 2.572`
    - `threshold_ref ≈ 2.377`

这说明当前相位诊断链在局部峰结构上没有新出现的明显漂移。

### 2.2 相位分支仍可读

当前 `phase_unwrapped` 没有出现失控跳变，`phase_span` 在补扫后仍保持较大且连续：

- `pi`：约 `2.40 ~ 2.58`
- `K`：约 `2.25 ~ 2.58`

这表明：

- 当前解包策略还能维持一条连续相位曲线
- 至少在当前窗口内，还没有出现彻底不可解释的分支灾难

## 3. 当前最关键的否定性结论

### 3.1 `omega_max = 6` 时原始相位仍非零，但继续外推后已自然接近 0

本轮检查后，需要把两个阶段区分开：

1. 当扫描只到 `omega_max = 6`
2. 当扫描外推到更高能端（当前已检查到约 `omega = 10`）

如果只看 `omega_max = 6`，原始 `phase_unwrapped` 在尾端仍明显非零。  
但把扫描外推后，可以直接看到传播子已经进入：

- `Re D_M` 为有限小正值
- `Im D_M` 为 `1e-8` 量级小值

例如 `T = 212 MeV, q = 0, K` 在 `omega ≈ 9.99` 时：

- `D_re ≈ 0.2957`
- `D_im ≈ 4.88e-8`
- `phase_unwrapped ≈ 1.65e-7`

对应分母也已经接近正实数：

- `denom_re ≈ 1.3785`
- `denom_im ≈ -2.27e-7`
- `denom_phase ≈ -1.65e-7`

这说明：

- 在更高能端，传播子本身确实自然趋向正实数
- 因而 `delta_M = arg D_M` 也自然趋近 `0`

因此，上一轮“高能端不回零”的判断，更准确地说是：

- **`omega_max = 6` 不足以看到自然渐近回零；**
- **继续外推后，原始相位已经表现出接近 0 的高能渐近行为。**

## 4. 这意味着什么

当前 `Phase E2` 的首轮判断应是：

- **相位结构在峰区和阈值附近已经可读**
- **高能端在足够大的 `omega` 下表现出自然回零趋势**

所以当前主线还需要继续完成：

1. 更大的 `omega_max` 检查已经证明是必要的
2. 当前优先保留原始相位主线，不必急着把“减尾部基线”当作正式定义
3. 是否需要 generalized BU 修正项，仍待后续判断

## 5. 当前不该做的事

基于这一轮结果，当前仍不建议直接做：

- 大范围温度扫描
- `K/pi` 正式图
- EOS 扩展

但相位高能端问题已经从“是否回零”推进到了“需要多大的 `omega_max` 才能看到回零”，这比前一轮更接近正式积分条件。

## 6. 下一步建议

当前更合理的下一步是：

1. 先固定 `q = 0`
2. 在正式 BU 积分试探中保留足够大的 `omega_max`
3. 继续用原始 `delta_M = arg D_M` 主线做最小积分试探
4. 再根据积分稳定性判断是否需要额外规范

## 7. 当前判断一句话版

- **Phase E2 首轮结果表明：在足够大的 `omega` 下，原始相位已经自然趋近 0；下一步可以开始做正式 BU 积分的最小试探。**
