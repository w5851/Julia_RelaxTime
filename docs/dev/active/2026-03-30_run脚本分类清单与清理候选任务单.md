## 2. 分类口径

- 核心入口：建议优先固化到前端/CI 的主链路脚本。
- 专题入口：稳定但偏专题研究或后处理。
- 回归门禁：主要用于回归校验、门禁或分析，不建议做前端按钮。
- 过时候选：历史一次性脚本或与主入口明显重叠，建议后续迁移/归档。
- 内部模块候选：文件名是 `run_`，但实质被其他脚本 include/调用，建议改名去 `run_`。
