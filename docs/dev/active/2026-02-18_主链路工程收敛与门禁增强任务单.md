# 主链路工程收敛与门禁增强任务单（执行版，可勾选）

## 背景

本任务单承接一次结构审视后的结论，目标是把“问题识别”转为“可执行门禁与里程碑”。

## 当前问题与不足（结论沉淀）

1. 主价值链未形成强门禁闭环：虽已升级为“已验证可用”，但缺少长期自动回归矩阵与阈值化验收。
2. 测试语义有分层但仍混杂：`smoke` 已筛选，`DEFAULT_SKIP`/deprecated 仍显示完整正确性与历史负债并存。
3. 服务入口耦合偏高：`scripts/server/server_full.jl` 同时承载路由、计算、静态资源与实验接口。
4. CI 覆盖偏向 smoke：已有 unit/docs/dependency 与 benchmark 工作流，但阈值告警与 full 回归门禁不足。
5. 文档治理成熟但有运营负担：active/archived 机制完善，历史命名与长期文件并存增加检索噪声。
