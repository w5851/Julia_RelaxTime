## 3. 公式到代码映射任务（按 `PNJL_magnetic_core.md`）

### 3.1 热力学势主式

- [x] 实现总势
	$\Omega = \sum_f(\Omega_f^0+\Omega_f^T)+2G(\phi_u^2+\phi_d^2+\phi_s^2)-4K\phi_u\phi_d\phi_s+U(\Phi,\bar\Phi,T)$
- [x] 确认与现有 `calculate_omega` / `calculate_pressure` 接口兼容。

### 3.2 真空项与温度项

- [x] 实现 Landau 求和真空项 $\Omega_f^0$。
- [x] 实现 Landau 求和热项 $\Omega_f^T$（含 $Z_f^+,Z_f^-$）。
- [x] 接入平滑截断函数 $f_\Lambda(p)$，支持可配置指数 $N$（默认建议 $N=10$）。

### 3.3 能谱与简并度

- [x] 实现 $E_{f,n}$ 计算函数。
- [x] 实现简并度因子 $\alpha_n$（$n=0$ 为 1，其余为 2）。
- [x] 加入 Landau 级数截断策略（固定 `n_max` / 自适应收敛）。

### 3.4 数密度与派生量

- [x] 实现 $\rho_f=\partial\Omega/\partial\mu_f$ 的数值接口。
- [x] 实现分层输出：总密度、分味密度、按 Landau 层密度。
- [x] 提供低温近似式（文档中式(5-13)）的可切换验证路径。

### 3.5 IMC 耦合

- [x] 实现 $G(B)=G_0\frac{1+a\zeta^2+b\zeta^3}{1+c\zeta^2+d\zeta^4}$。
- [x] 参数化配置（`a,b,c,d,\Lambda_{QCD}`）落地到配置文件。
- [x] 提供 `G(B)` 数值健康检查（$B\to0$ 回归到 $G_0$）。
