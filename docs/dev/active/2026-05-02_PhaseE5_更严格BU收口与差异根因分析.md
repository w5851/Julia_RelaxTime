## 3. generalized BU 候选的来源

更严格的 generalized Beth-Uhlenbeck 口径不是简单的 `d\delta/d\omega`，而是带有 `2\sin^2\delta` 因子的相移导数：

```math
2\sin^2\delta\,\frac{d\delta}{d\omega}
= \frac{d}{d\omega}\left(\delta-\frac{1}{2}\sin 2\delta\right).
```

本轮采用它作为候选，主要依据是：

- Blaschke 等在 generalized BU / MHRG 推导中给出

```math
n \propto \int d\omega\; f(\omega)\,2\sin^2\delta\,\partial_\omega\delta
```

并在分部积分后得到

```math
\delta-\frac{1}{2}\sin 2\delta
```

的结构。

本仓库当前直接相关的一个可核对来源是：

- V. Vovchenko et al., *Thermodynamics of quark matter with multiquark clusters in an effective Beth-Uhlenbeck type approach*, EPJA (2024)
  - generalized BU 密度：Eq. (38)
  - 分部积分后的相位函数：Eq. (48)

注意：

- 该文献讨论的是更一般的 cluster / MHRG 场景，不是“直接等于我们当前 `pi/K` 实现”。
- 但它足以说明：若从更严格的 generalized BU 推导出发，`F(\delta)=\delta` 往往不是最终完整口径。

## 5. 对“尾部平移”的判断

把每个 `q` 壳上的相位替换为

```math
\delta(\omega,q)-\delta(\omega_{\max},q)
```

后，结果会出现巨大负值，说明：

- 当前 `\delta(\omega_{\max},q)` 的尾部残量虽然不大，但若在整个 `\omega` 区间内被玻色核放大并整体平移，会严重过补偿；
- 因此“简单尾部平移”不能作为正式物理修正；
- 真正起决定作用的更像是 generalized BU 的 `2\sin^2\delta` / `\delta-\frac{1}{2}\sin 2\delta` 结构，而不是纯粹的常数尾部减法。

- generalized BU 候选虽已显著修正数量级，但 `K/pi` 仍高于 stable，说明还需要继续判断：
  - 当前 `\delta = arg D` 是否还需进一步拆成 bound-state / scattering 部分；
  - Levinson / continuum subtraction 是否还需在当前 `pi/K` 简单介子道里更明确地实现；
  - 是否需要补做“导数形式 vs 分部积分形式”的离散一致性检查。

当前这一步里的 `d\delta/d\omega` 不是解析公式导数，也不是自动微分，而是：

1. 先在离散 `\omega` 网格上计算 `\delta(\omega,q)=\arg D(\omega+i\eta,q)`；
2. 对相位做 unwrap；
3. 再对 unwrap 后的离散相位做数值微分：
   - 端点：前/后差分
   - 内点：中心差分

因此，本节结果的用途是“离散一致性诊断”，而不是把导数形式本身视为已收敛的正式生产实现。

### current 口径：`F(\delta)=\delta`

首轮结果显示：

- `pi` 通道相对偏差约 `19.9%`
- `K` 通道相对偏差约 `22.5% - 22.7%`

即：

- `density_current_byparts` 明显高于 `density_current_derivative`
- 该差异量级已经不宜简单视为离散舍入误差

### generalized BU 候选：`F(\delta)=\delta-\frac{1}{2}\sin 2\delta`

首轮结果显示：

- `pi` 通道相对偏差约 `5.3% - 9.4%`
- `K` 通道相对偏差约 `1.5% - 2.8%`

即：

- generalized BU 候选在同一有限 `\omega` 窗口和同一 GL 网格下，导数形式与分部积分形式的一致性明显优于 current 口径；
- 尤其 `K` 通道已经压到几个百分点量级。

### 当前判断

这轮一致性检查给出的信号是：

1. `current` 口径的巨大数密度并不只是“结果大”，它在当前离散实现下的内部一致性也更弱；
2. generalized BU 候选不仅把数量级压回到更合理范围，而且在“导数形式 vs 分部积分形式”这一门上表现更稳；
3. 因此，generalized BU 候选继续保留为 stricter reference 是有实证支持的，下一步值得继续检查 scattering / Levinson 部分，而不是回头继续纠缠 strict BW 层。

### 为什么导数形式与分部积分形式在当前数值实现下不完全等价

理论上，如果同时满足以下条件，两种写法应当等价：

1. `\omega` 积分是连续且足够光滑的；
2. 积分区间是理想的全区间，而不是有限窗口；
3. 相位基线与边界项处理完全正确；
4. `\partial_\omega \delta` 使用解析导数，或数值上已充分收敛到解析极限。

但当前仓库中的 E5 诊断并不满足这些理想前提，而是采用了：

1. 有限窗口 `\omega \in [0.05, 10]`；
2. 有限 `48` 点 GL 网格；
3. `\delta(\omega,q)=\arg D(\omega+i\eta,q)` 的离散 unwrap；
4. 在离散 `\omega` 网格上对 unwrap 相位做数值微分，而不是解析导数。

因此当前看到的差异，不宜简单归因于“积分节点可能还不够”，更准确地说是以下几项共同作用：

- 数值微分会放大局部 phase-baseline / unwrap 误差；
- 有限窗口下的分部积分边界项不会像理想全区间那样自动完全抵消；
- 中等 `q` 壳上已观察到明显 baseline / normalization 偏移，`current` 口径对这类偏移更敏感；
- `gbu` 的非线性相位函数对大相位区和基线偏移更不敏感，因此两种写法在 `gbu` 下表现出更好的离散一致性。

所以，当前 `current` 的 `20%~23%` 偏差并不支持“仅靠继续加密节点就会自然消失”这一更强结论。更合理的解释是：

- 这首先是**有限窗口 + 离散微分 + 相位基线偏移**共同造成的离散不等价；
- generalized BU 在当前数值口径下内部一致性更好，因此更适合作为 stricter reference workflow。

1. generalized BU 的关键作用，不是统一地压低所有 threshold-neighborhood 贡献；

   - 在若干 `q` 壳上，`arg D` 总相位在 pole-like / near-resonance 区域给出了过强权重；
   - generalized BU 的 `2\sin^2\delta` 因子正是在这些“大相位局部峰区”上重写了有效权重。

这也解释了为什么前面的“threshold above 总量拆分”不足以说明问题：

- generalized BU 的主要修正未必表现为“整段高能尾部都被削掉”；
- 它更像是对 **特定局部峰区** 做非线性重权，而这些峰区既可能靠近阈值，也可能更接近 pole-neighborhood。

### 对下一步的含义

因此，接下来若继续沿任务单主线推进，更合理的重点应是：

1. 进入 Levinson / phase normalization 检查；
2. 继续判断这些中等 `q` 壳上的 pole-neighborhood 大相位，是否应被完整视为 scattering phase shift；
3. 再决定 generalized BU 是否应升格为更正式的 workflow 分支，而不是仅停留在 stricter reference。

## 8.5 Levinson / phase normalization：首轮诊断

本轮已补充诊断脚本：

- [check_bu_levinson_e5.jl](/C:/Users/Wmzx/.codex/worktrees/346c/Julia_RelaxTime/scripts/analysis/relaxtime/check_bu_levinson_e5.jl)

输出结果：

- [meson_density_phase_e5_levinson_check.csv](/C:/Users/Wmzx/.codex/worktrees/346c/Julia_RelaxTime/data/outputs/results/relaxtime/analysis/meson_density_phase_e5_levinson_check.csv)

该脚本对少量 `T,q` 取样点直接检查：

1. `delta_low`
2. `delta_high`
3. `delta_span = delta_high - delta_low`
4. 它们各自离最近整数倍 `\pi` 的距离

### 当前读到的主要信号

1. `q = 0`
   - `delta_low`
   - `delta_high`
   - `delta_span`
   都非常接近 `0 * pi`，偏差量级约 `1e-7`；
   - 说明在 `q=0` 上，当前 `arg D` 总相位的基线是相当干净的。
2. `q = 2,4 fm^-1`
   - `delta_low` 明显偏离 `0`，约 `0.013 - 0.020`
   - `delta_high` 在 `q=4` 时可到 `0.07 - 0.27`
   - `delta_span` 也不再接近整数倍 `\pi`

### 当前判断

这一步的结论非常关键：

1. 当前问题不只是“高能尾部有贡献”；
2. 更关键的是：在中等 `q` 壳上，`arg D` 总相位本身就带着明显的 baseline / normalization 偏移；
3. 因而 `F(\delta)=\delta` 偏大，不只是因为某一段 tail 太大，而是因为这些未完全规范化的大相位结构被直接积分进去了；
4. generalized BU 之所以表现更稳，除了物理口径更严格，也因为 `2\sin^2\delta` 对这类大相位区间天然有非线性抑制。

### 对下一步的含义

因此，更合理的下一步应是：

1. 在分析层尝试最小 phase normalization / baseline correction 诊断；
2. 比较 normalization 前后 current 口径是否明显靠近 generalized BU；
3. 再决定 generalized BU 的优势究竟来自：
   - 更严格的物理相位函数；
   - 还是在部分程度上补偿了当前 `arg D` 总相位的 normalization 问题。

## 8.6 最小 phase normalization / baseline correction：当前不能单独解释差异

本轮已补充诊断脚本：

- [diagnose_bu_phase_normalization_e5.jl](/C:/Users/Wmzx/.codex/worktrees/346c/Julia_RelaxTime/scripts/analysis/relaxtime/diagnose_bu_phase_normalization_e5.jl)

输出结果：

当前比较了三种最小处理：

1. `raw`：直接使用当前 unwrap 后总相位
2. `tailnorm`：`delta -> delta - delta(omega_max)`
3. `lownorm`：`delta -> delta - delta(omega_min)`

### 当前读到的主要信号

1. `tailnorm` 会把 `current` 和 `gbu` 都推到巨大负值：
   - `current_tailnorm_over_raw ~ -95` 到 `-99`
   - `gbu_tailnorm_over_raw ~ -605` 到 `-667`
2. `lownorm` 的影响要温和得多，但仍不足以单独解释 `current` 与 `gbu` 的巨大差异：
   - `current_lownorm_over_raw ~ 0.74 - 0.77`
   - `gbu_lownorm_over_raw ~ 0.92 - 0.95`

### 当前判断

这一步进一步说明：

1. 当前问题不能靠“给每个 `q` 壳做一个常数 baseline 平移”直接解决；
2. `delta(omega_min)` 基线偏移确实在推高 `current`，但它只能解释一部分放大；
3. generalized BU 的优势不只是“比 current 少吃了一点 baseline 偏移”，而更像是：
   - 同时包含更严格的相位函数口径；
   - 也包含对大相位区和基线偏移的低敏感性。

因此，Phase E5 的 scattering / normalization 收口方向应继续优先放在：

1. `arg D` 总相位中哪些局部结构应视为 scattering phase shift；
2. 中等 `q` 壳上的 pole-neighborhood 大相位是否应整体进入近似 BU 主产出；
3. generalized BU 的非线性重权究竟在多大程度上是在“物理纠正”，而不是“数值补偿”。
