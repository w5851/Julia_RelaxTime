## 5. 四层图像语义

| `figure_mode` | 允许内容 | 视觉/文字要求 | 论文资格 |
| --- | --- | --- | --- |
| `audit` | 原始点、失败点、unresolved、support gap、residual、bracket、mask | 图内或 caption 明确 `audit`；状态和排除原因可见；允许诊断 connector，但必须标注；可以显示 raw support marker | 不可直接进入论文正文 |
| `estimated_midpoint` | 在存在明确 bracket/上下界时显示 midpoint 候选 | 必须写 `estimated` 或 `bracket midpoint`；优先使用辅助线/开放 marker；不得命名为 confirmed CEP | 只能作为 supplement/内部讨论 |
| `strict` | 已确认、有限、无重复键且 support 连续的物理点 | 默认 `line-first / landmark-only`：不显示普通 support marker；confirmed CEP 只用稀疏粗点；不显示 unresolved 或未确认 CEP；禁止隐式 connector、外推和未声明插值 | 可申请论文定稿，仍需人工视觉审核 |
| `legacy` | 原历史数据和原历史绘图语义 | 不自动换 style、不自动修正单位、不自动重生成；manifest 记录“保留历史语义” | 只能作为历史兼容或追溯证据 |

模式不是数值质量的替代品。`strict` 只表示图像渲染满足严格 gate，不改变 source CSV/JSON 的物理结论；`legacy` 也不表示历史产物无效。

## 6. 三个 style profile

### 6.1 公共规则

- 采用当前 `scripts/plot_scan_csv.py` 的 APS 尺寸作为初始基线：single-column `3.375 x 2.5 in`，double-column `6.75 x 4.6 in`。
- 字体请求为 serif/Times 系列，数学字体使用 STIX；实际解析到的字体名称写入 manifest，不能因机器缺字体而静默产生不可追踪变化。
- 轴线、刻度、legend、bbox、PDF 字体嵌入沿用现有 publication helper 的可验证规则。
- 颜色只表达图族或 series 角色；物理状态优先用线型和 marker 表达，避免仅靠颜色区分 first-order、crossover、spinodal。
- 线型、landmark marker、support 显示策略和状态语义是公共合同；普通 support 默认采用 line-first，audit 可覆盖为 support-visible；热图、3D surface、literature comparison 可以有图族覆盖项，但覆盖项必须写进 profile/manifest。

### 6.2 profile 表

| profile | 目标 | 建议尺寸/字体 | 线宽/marker | 输出建议 | 允许内容 |
| --- | --- | --- | --- | --- | --- |
| `audit_v1` | 审计、support、residual、失败点和 3D mask | 默认 double-column；9--10 pt | 0.8--1.2 pt；raw support marker 可见，诊断 marker 可稍大 | PNG 300 dpi；SVG 可选；必须有 audit manifest | 可见 unresolved、bracket、排除行和审计文字 |
| `candidate_origin_like_v1` | 论文候选的内部评审/补充材料预览 | single/double-column 按图族选择；10 pt 起 | 1.0--1.2 pt；普通 support 不画 marker；estimated/bracket 以辅助线或开放 landmark 表达 | PNG 600 dpi + SVG；PDF 可选 | `estimated_midpoint` 只允许 supplement/内部 review，不得进入正文草稿或 strict |
| `strict_origin_like_v1` | 定稿候选 | 当前 APS-like single/double-column 基线；8--10 pt | 0.8--1.2 pt；普通 support 不画 marker；confirmed CEP 采用稀疏实心圆点 | SVG + PNG 600 dpi；PDF 按投稿场景可选；输出 hash 必须写入 manifest | 只含确认、有限、support 合格的 series |

公共 palette 采用现有 APS-like cycle：`#4477AA`、`#EE6677`、`#228833`、`#CCBB44`、`#66CCEE`、`#AA3377`、`#BBBBBB`。论文模板可以覆盖颜色，但不能改变状态的线型/landmark 语义，也不能让颜色成为区分物理状态的唯一依据。

作者已通过 line-first pilot，因此 `first_order`、`crossover`、`spinodal`、`cep_confirmed` 等状态的线型/landmark 语义和默认 palette 作为 v1 baseline 生效；颜色仍允许论文模板做显式覆盖，但必须在 manifest/provenance 中记录。

## 7. 单位与状态语义

### 7.1 坐标单位

| 物理量 | source 字段示例 | strict 显示约定 | 约束 |
| --- | --- | --- | --- |
| 温度 | `T_MeV`, `T_fm` | 优先 `T [MeV]` | MeV/fm^-1 转换必须显式记录 |
| 夸克化学势 | `mu_MeV`, `muq_MeV` | `mu_q [MeV]` | 不得未经 manifest 变成 `mu_B` |
| 重子化学势 | `muB_MeV` | `mu_B [MeV]` | 若由 `mu_q` 转换，记录 `mu_B = 3 mu_q` |
| 密度 | `rho`, `rho_over_rho0` | `rho/rho_0` 或明确 `rho [fm^-3]` | 禁止仅凭列名猜单位 |
| 反应能 | `sqrt_s_MeV`, `sqrt_s_GeV` | 一张图只用一个 display unit | MeV/GeV 转换写入 axes transform |
| transport | `eta`, `sigma`, `zeta`, `tau_*`, `eta_over_s`, `zeta_over_s`, `sigma_over_T` | 显式标注 dimensionless、fm 或约定单位 | 不从 y 名称推断单位 |

### 7.2 物理状态与视觉映射

| semantic state | 默认线型 | 默认 marker | 说明 |
| --- | --- | --- | --- |
| `first_order` / `coexistence` | solid | 可不设 | 表示已确认的一阶共存线/分支 |
| `crossover` | short dashed | audit 可用 support circle；candidate/strict 默认无普通 marker | 表示 crossover/pseudocritical line，不当作一阶线 |
| `spinodal` | dotted，较低 alpha | 可选 | 默认作为可选 overlay，不并入主线 |
| `cep_confirmed` | 不单独连线 | 稀疏实心圆点 | 只有满足 strict CEP gate 才能用 confirmed 语义；不使用密集 support marker |
| `cep_bracket` | bracket/辅助线 | open diamond 或 interval marker | 只能出现在 audit 或标明 estimated 的候选图 |
| `estimated_midpoint` | dashed auxiliary | open marker | 必须在 legend/caption 中写 estimated |
| `unresolved` / `nonconverged` | 不连接 | cross/open marker | 断线、mask 或单独审计层，不得生成连续物理曲线 |
| `literature_reference` | 不承担模型状态 | open square/point | 记录来源与 digitization provenance |
| `plotting_connector` | 禁止在 strict | 仅 legacy/audit | 必须列出 connector row 及其非物理性质 |

## 8. 输出和 provenance 合同

新生成的 case 必须写入正式根目录下的新 sibling 目录，例如：

```text
data/outputs/figures/<domain>/<figure_family>/<case_slug>__plotv1__audit/
data/outputs/figures/<domain>/<figure_family>/<case_slug>__plotv1__estimated_midpoint/
data/outputs/figures/<domain>/<figure_family>/<case_slug>__plotv1__strict/
```

默认禁止覆盖；旧 case 即使目标图名相同，也只能新建 sibling case。历史图只读引用，不批量重绘。

严格模式必须满足：

1. 所有输入 CSV/JSON 都有路径、角色、大小和 SHA-256。
2. generator 路径、脚本 SHA、Git commit、calculation SHA、postprocess SHA 和 source run id 可追溯；未知值写 `null` 并在 validation 中解释。
3. axes 显示字段、source 字段、单位和转换公式齐全；`mu_q -> mu_B`、MeV/GeV 等不能隐藏在绘图代码中。
4. 输入行有限、无重复 key；`converged=false`、unresolved、缺失 support 和非法物理值不进入 strict series。
5. strict 不使用隐式插值、外推或视觉 connector；任何 gap 以断线、mask 或排除记录表达。
6. strict 默认同时提供 SVG 和 600 dpi PNG，并为每个输出写 bytes、hash、format、dpi/vector 信息；PDF 不作为所有图族的硬性要求，只有投稿系统或版式流程需要时才启用并记录。
7. 如果使用 Origin，只导入通过 validator 的 CSV 和矢量图；Origin 不得改数值、重采样、插值或补点。外部排版工具、版本、输入 hash、导出 hash 和 operator 写入外部排版 provenance。

## 9. 已确认决策与待冻结项

以下决策已用于 pilot，并已由作者确认；正式执行细节见 figure production SOP：

- `strict_origin_like_v1` 固定采用当前 APS-like single-column `3.375 x 2.5 in` 和 double-column `6.75 x 4.6 in` 基线；宽度参照 APS-like 版式，高度是项目当前版式选择，不宣称为 APS 的普遍硬性值。
- strict 默认只交付 SVG 和 600 dpi PNG；PDF 改为按投稿系统或外部版式流程启用的可选格式，历史图不追溯补齐。
- `estimated_midpoint` 只允许 supplement/内部 review，不进入论文正文草稿或 strict。
- Figure 4 旧 connector 只保留在 `legacy`/`audit`；新 strict 合同一律 `connector=forbidden`。
- literature comparison 的模型插值只保留在 `audit`/`legacy`；strict 只画原始模型 support 点。
- phase 状态的线型和 landmark 语义采用 line-first v1 规则；默认 palette 已通过视觉审核，论文模板可以覆盖颜色，但不能改变物理状态含义，也不能只靠颜色区分状态。

本文件当前作为已审核的 registry/contract 依据；正式 SOP 已固化，后续活跃图族迁移必须逐 case 通过 strict layout gate。
