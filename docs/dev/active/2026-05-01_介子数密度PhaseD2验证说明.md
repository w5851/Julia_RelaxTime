# 介子数密度 Phase D2 验证说明

更新日期：2026-05-01

目的：把稳定粒子极限 meson density 的最小验证结论收成一页可审计说明，并明确是否进入 `Phase D3` 的判断口径。

---

## 1. 验证对象

- workflow 入口：`Models.solve_gap_and_meson_density_point`
- 扫描脚本：`scripts/analysis/relaxtime/validate_meson_density_stable_baseline.jl`
- 当前物理窗口：
  - `muB = 0`
  - `xi = 0`
  - `T = 150:10:190 MeV`
- 当前方法口径：
  - 只使用稳定粒子极限
  - 介子质量来自 meson workflow
  - 数密度后处理不单独重算介子极点

## 2. 当前验证结论

- `n_pi(T)` 随温度单调上升
- `n_K(T)` 随温度单调上升
- `K/pi(T)` 随温度单调上升
- 全部检查点满足 `n_pi > n_K > 0`

这说明在当前温区内：

- 单位与量级没有出现明显异常
- `pi/K` 两道的热激发顺序合理
- 稳定粒子极限可作为 BU 之前的最低台阶基线

## 3. 与介子质量 workflow 的一致性护栏

当前已具备两层护栏：

- 点内一致性：
  - `meson_density.m_pi/m_K` 必须等于同点 `meson_results[:pi/:K].mass`
- continuation 一致性：
  - 沿 `T=150:10:190 MeV` 扫描时，必须继承 `continuation_state`
  - `T=190 MeV, xi=0` 的结果应与 `mott_phase` 参考数据对齐

因此，数密度 workflow 当前不是独立质量求解链，而是显式依附于 meson workflow 的后处理层。

## 4. 是否进入 Phase D3

当前判断：**需要保留 D3，但应控制为最小桥接层，而不是先扩成完整模块族。**

原因：

- 稳定粒子极限在接近或越过 Mott 区域后会失效
- BU 正式实现前，需要一个能体现“宽度进入后会怎样”的中间诊断层
- BW 可用于区分：
  - 稳定极限失效带来的问题
  - 真正需要相移 / Levinson 定理修正的问题

## 5. D3 最小交付建议

建议把 D3 限定为以下最小目标：

- 先做 `pi/K` 的 BW 诊断计算
- 仅比较：
  - 稳定极限 vs BW
  - 质量进入 vs 质量+宽度进入
- 只输出少量固定温点或窄温区结果
- 明确标注“D3 是 BU 前的诊断桥梁，不是最终热力学结果”

不建议在 D3 立即做的事：

- 不先扩成完整 `src/` 下 BU 公共接口
- 不先并入 EOS 或更大范围 `T-muB` 扫描
- 不把 BW 结果表述成最终物理解读
