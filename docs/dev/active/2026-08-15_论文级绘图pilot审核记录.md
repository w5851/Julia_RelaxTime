## 已采用的 pilot 规则

- 当前 APS-like baseline 固定为 single-column `3.375 x 2.5 in`、double-column `6.75 x 4.6 in`。宽度作为 APS-like 基线；高度是项目当前版式选择，不宣称为 APS 的普遍硬性值。
- strict 默认输出 `600 dpi PNG + SVG`。PDF 降为按投稿系统或外部版式需要启用的可选兼容输出。
- `estimated_midpoint` 只能进入 supplement 或内部 review，不能进入论文正文草稿或 strict。
- Figure 4 connector 仅保留在 `legacy`/`audit`；本次新 strict 合同使用 `connector=forbidden`。
- literature comparison 的模型插值不进入 strict；strict 只允许原始模型 support 点。
- 正式候选/strict 默认采用 `line-first / landmark-only`：不绘制普通 support marker；confirmed CEP 只保留稀疏实心圆点；C1 三维 bracket 优先用加粗线表达。
- audit 可以显示 raw support、失败点和 unresolved；manifest 必须同时记录完整 support 行数和视觉筛选策略。
- phase 状态的线型/landmark 语义是 provisional contract；颜色 palette 暂为 provisional，论文模板可以调整颜色，但不能改变状态含义或只靠颜色区分状态。

## 请审核的视觉问题

- phase 图中 solid/dashed/dotted/confirmed-CEP 粗点是否足够容易区分，颜色对比度是否需要调整；
- single-column 图的字号、legend、line-only 曲线和 x 轴对数刻度是否适合论文正文；
- SVG 在当前查看器中是否出现字体替换、文字错位、裁切或线型变化；
- C1 3D estimated 图的淡 support 线和加粗 bracket 线的信息密度是否可接受，是否需要改为双图或 2D supplement 版；
- 是否需要图内保留 audit/estimated 提示，还是只在 caption 和 manifest 中保留；
- 是否要将某些图族默认尺寸切换为 double-column；
- palette 是否可以冻结，还是需要按论文模板另行指定。

## 历史图清理门禁

当前不清理 `data/outputs/figures` 中的 PNG/PDF/SVG。原因是：文件可能仍被论文、README、报告、manifest 或外部排版工程引用；格式重复也不等于内容重复，删除会损失历史证据和 provenance。

清理应在 pilot 视觉规则通过后单独进行：先生成引用/重复 registry，确认每个候选文件的引用状态、输入 hash、输出 hash 和历史语义；然后优先移动到明确的 archive/quarantine 位置，保留原路径映射和可恢复记录。只有获得精确路径授权后才删除，且不处理正式 CSV/JSON、reference、Maxwell、C2、transport 或当前未提交 C1 文件。

作者已通过 line-first pilot。strict 图族后续仍必须逐 case 检查 legend 空间、数据遮挡、single/double-column 选择和必要的外置 legend；正式流程已固化为 `docs/guides/sop/workflows/figure_production.md`。
