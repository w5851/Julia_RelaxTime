## 1. 当前已基本确认的结论

### 1.1 generalized BU 候选确实显著压低了 current 口径的数量级

当前 `F(\delta)=\delta` 会给出明显偏大的 `n_pi / n_K / K/pi`。

而 generalized BU 候选

```math
F(\delta)=\delta-\frac{1}{2}\sin 2\delta
```

能够把：

1. `n_pi`
2. `n_K`
3. `K/pi`

整体压回到与 stable / strict BW 更接近的量级。

这说明 E4 中看到的巨大差异，不太像是单纯的积分窗口问题，而更像是当前相位函数口径偏松。

### 1.2 generalized BU 候选在离散一致性上更稳

当前已做的“导数形式 vs 分部积分形式”检查表明：

1. current 口径相对偏差约 `20% - 23%`
2. generalized BU 候选相对偏差约 `1.5% - 9.4%`

因此，generalized BU 候选不只是“结果更小”，它在当前有限 `\omega` 窗口和 GL 离散实现下，也表现出更好的内部一致性。

### 1.3 问题不能简化成“只是一段高能 tail 太大”

当前已做的：

1. threshold split
2. `q` 壳剖面
3. local window 剖面

共同给出的结论是：

1. current 偏大的面积并不只是来自 threshold above 高能尾部；
2. generalized BU 的压制也不只是“削尾巴”；
3. 更强的修正信号出现在若干中等 `q` 壳上的 pole-neighborhood / near-threshold 大相位局部峰区。

### 1.4 中等 `q` 壳上的相位归一问题是真实存在的

Levinson / phase normalization 诊断表明：

1. `q=0` 上相位基线基本干净；
2. 但 `q=2,4 fm^-1` 上，
   - `delta_low`
   - `delta_high`
   - `delta_span`
   都明显偏离更理想的整数倍 `\pi` 归一。

这说明当前 `arg D` 总相位在中等 `q` 壳上确实带有 baseline / normalization 偏移，而 current 口径会对这些偏移更敏感。

## 2. 当前已经证伪或不宜直接采用的方向

### 2.1 简单 tail subtraction 不能作为正式修正

把每个 `q` 壳上的相位直接改成

```math
\delta(\omega,q)-\delta(\omega_{\max},q)
```

会导致结果出现巨大负值。

这说明：

1. 尾部残量虽然小；
2. 但在整个玻色核积分中会被严重放大；
3. 因而简单 tail subtraction 会过补偿。

所以这条路目前可以视为已被证伪的简化修正方案。

### 2.2 不能把 generalized BU 的作用解释成“只是补 tail”

当前证据已经不支持这种更强说法。

更合理的说法是：

1. generalized BU 在大相位区间上进行了非线性重权；
2. 这种作用同时影响 pole-neighborhood、near-threshold 以及部分 threshold-above 结构；
3. 因而它的效果既包含“更严格的物理公式”，也包含“对总相位归一偏移更不敏感”这层数值/结构优势。

## 3. 当前 generalized BU 的项目定位

基于现有证据，更合理的治理定位是：

1. 正式生产默认口径：
   - 仍保留当前近似 BU / 文献主流 `pi/K` 口径
   - 即 `F(\delta)=\delta`
2. 更严格参考口径：
   - generalized BU 候选
   - 即 `F(\delta)=\delta-\frac{1}{2}\sin 2\delta`
3. stable / strict BW：
   - 继续保留为降阶对照层

这意味着：

- generalized BU 现在已经不只是“随便试的候选”；
- 它已经具备作为 **stricter reference branch** 的充分证据；
- 但还未到“应立即替代默认 workflow 主线”的程度。

## 4. 何时可以考虑正式升格 generalized BU

若要从 stricter reference 升格到更正式的 workflow 分支，建议至少满足下面三条：

1. **相位归一门禁更清楚**
   - 对中等 `q` 壳上的 baseline / normalization 偏移，已有更明确解释；
   - 至少知道 generalized BU 的优势有多少来自物理公式本身，有多少来自对 normalization 的低敏感性。
2. **Levinson / scattering-part 解释更清楚**
   - 当前 `arg D` 总相位里，哪些部分应视为真正 scattering phase shift，有更清楚的边界；
   - 不再只停留在“数值上更合理”。
3. **workflow 契约明确**
   - 若升格为 workflow/helper 分支，应明确：
     - 它是替代 current 主线，还是并列一个 `gbu_reference` 分支；
     - 输出字段、单位、结果解释边界如何标注。

## 5. 当前最合理的下一步

在当前阶段，不建议立刻改正式默认口径。

更合理的顺序是：

1. 先把 E5 的分析证据作为阶段性结论固定；
2. 在需要时，可增加一个分析型或参考型 generalized BU workflow 分支；
3. 只有当 scattering / Levinson / normalization 三个问题再进一步收口后，才考虑是否调整默认生产口径。

## 6. 本页结论

当前 E5 的阶段性判断可以概括成一句话：

**generalized BU 现在已经足够强，可以作为更严格参考口径；但它是否应升格为正式 workflow 主线，仍取决于当前 `arg D` 总相位的 scattering / normalization 解释能否进一步收口。**
