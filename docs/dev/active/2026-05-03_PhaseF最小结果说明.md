## 1. 当前图层范围

本轮只整理两类最小图层：

1. `n_pi(T)` / `n_K(T)` 双面板
2. `K/pi(T)` 单图

比较对象固定为四条链：

1. `stable`
2. `strict BW Stage2`
3. `current BU`
4. `gbu_reference`

- `T = 208:2:220 MeV`

## 2. 当前最直接读到的结果

### 2.1 stable

`stable` 继续作为最低复杂度基线：

1. `n_pi` 约 `0.345 -> 0.358`
2. `n_K` 约 `0.196 -> 0.229`
3. `K/pi` 约 `0.567 -> 0.638`

### 2.2 strict BW Stage2

当前 `strict BW Stage2` 明显不能再与旧的 reduced BW 混写：

1. `n_pi` 约 `0.210 -> 0.604`
2. `n_K` 约 `0.583 -> 1.035`
3. `K/pi` 约 `2.78 -> 1.71`

这说明：

1. 当前 `strict BW Stage2` 是一个独立对照层；
2. 它不接近 `stable`；
3. 后续若图表或文字引用 BW，必须显式写清是 `Stage1 reduced` 还是 `Stage2 q-pole strict BW`。

### 2.3 current BU

`current BU` 仍然保持当前主线里最显著的放大特征：

1. `n_pi` 约 `2.82 -> 2.80`
2. `n_K` 约 `3.87 -> 3.91`
3. `K/pi` 约 `1.369 -> 1.399`

因此本轮图层继续支持此前 `Phase E5` 的阶段判断：

1. `current BU` 不只是 `stable` 或 `BW` 的小修正；
2. 它对应的是一个明显不同的相位积分结果层级。

### 2.4 generalized BU reference

`gbu_reference` 继续扮演 stricter reference：

1. `n_pi` 约 `0.262 -> 0.208`
2. `n_K` 约 `0.203 -> 0.185`
3. `K/pi` 约 `0.775 -> 0.888`

在当前窗口下，它：

1. 明显低于 `current BU`
2. 更接近 `stable` 的数量级
3. 与 `strict BW Stage2` 也保持清楚分离

1. `stable`：
   - 基线
