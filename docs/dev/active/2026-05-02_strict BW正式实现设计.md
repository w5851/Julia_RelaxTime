## 1. 文献口径分工

strict BW 这一层的引用口径需要明确拆开：

1. `Hatsuda:1994pi`
   - 角色：NJL/RPA 介子传播子与极化函数结构的综述性背景。
   - 在 strict BW 中负责解释“为什么可以从传播子极点谈介子共振”。
2. `Rehberg:1996da`
   - 角色：当前项目简单介子道传播子/极点方程的直接上游背书。
   - 在 strict BW 中负责支撑
     ```math
     \mathcal{D}_M=\frac{2K_M}{1-4K_M\Pi_M},
     \qquad
     \mathcal{G}_M(z,q)=1-4K_M\Pi_M(z,q)=0
     ```
     这一极点定义。
3. `Maslov:2023wul`
   - 角色：phase-shift / off-shell 热力学主线背书。
   - 在 strict BW 中负责说明：strict BW 不是新的热力学理论，而是完整 BU / phase-shift 热力学链上的受控极点近似层。

因此，strict BW 的项目定位应是：

- **传播子与极点定义**对齐 `Hatsuda:1994pi` + `Rehberg:1996da`；
- **热力学归宿**对齐 `Maslov:2023wul` 的 BU / off-shell 主线；
- **实现层级**位于 `stable` 与 `full BU` 之间，替换当前仅作诊断的 `BW-proxy` 作为正式对照层。

## 2. 目标与非目标

本轮 strict BW 正式实现的目标：

1. 在不改动 meson 主求解链的前提下，给出可复用的 strict BW 数密度 helper；
2. 将 strict BW 挂到现有 workflow，保持 workflow 作为唯一计算入口；
3. 让 strict BW 与 stable / Phase-E3 形成统一输出契约与统一测试入口；
4. 明确 reduced strict BW 与 full strict BW 的阶段边界。

本轮非目标：

1. 不在 strict BW 阶段引入 generalized BU 的 scattering part；
2. 不重写当前 Phase-E3 full phase-shift 链；
3. 不在第一阶段就实现 `q` 依赖复极点求解；
4. 不把当前 `BW-proxy` 继续扩张成正式实现。

## 3. 目标公式与分阶段实现

公式目标已经在 reference/formula 中固定：

```math
n_M^{BW}(T)
= d_M \int_0^\infty \frac{dq\,q^2}{2\pi^2}
\int_0^\infty \frac{d\omega}{2\pi}
g_M(\omega)
\frac{\Gamma_M(q)/2}
{\left[\omega-E_M(q)\right]^2+\Gamma_M^2(q)/4}.
```

但从代码落地角度，应拆成两个阶段：

### 3.1 Stage 1：reduced strict BW

第一阶段只实现：

```math
E_M(q)\approx \sqrt{q^2+M_M^2},
\qquad
\Gamma_M(q)\approx \Gamma_M.
```

其中 `M_M`、`\Gamma_M` 直接消费 meson workflow 当前点的输出。

这一步的意义是：

1. 保持“传播子上游定义”不变；
2. 用正式双积分取代 `BW-proxy` 的质量展宽代理；
3. 不要求当前 meson workflow 立即提供 `q` 依赖复极点。

### 3.2 Stage 2：full strict BW

第二阶段再扩展到：

1. 固定 `q` 网格；
2. 在每个 `q` 上求 `z_p(q)=E_M(q)-i\Gamma_M(q)/2`；
3. 将 `E_M(q)`、`\Gamma_M(q)` 回填 strict BW 双积分。

这一步才是完全对齐当前传播子口径的 full strict BW。

当前状态更新：

- `Stage 1` 已实现并接入 workflow；
- `Stage 2` 已进入首轮实现：当前已支持在 `q` 网格上逐点重解复极点并回填 strict BW 双积分；
- `Stage 2` 首轮 workflow / scan / test / docs 已打通；
- `Stage 2` 的内层 `\omega` 积分现已切到严格 `\omega \in [0,\omega_{\max}]` 口径；
- 因而 strict BW 这一层已达到“阶段性闭环完成”的状态；
- 但 `Stage 2` 仍不等于 generalized BU，也不是最终 BU 主线收口结论。

## 4. 建议的模块与入口设计

### 4.1 `src/relaxtime/MesonDensity.jl`

新增正式 helper：

1. `strict_bw_meson_number_density(mass, gamma, T; ...)`
   - 单通道 reduced strict BW 双积分；
   - 只依赖 `(mass, gamma, T, degeneracy, q/omega quadrature config)`。
2. `strict_bw_kpi_ratio(m_pi, gamma_pi, m_K, gamma_K, T; ...)`
   - 稳定计算聚合通道 `K/pi`。
3. `strict_bw_meson_density_summary(meson_results, thermo_params; ...)`
   - 将 meson workflow 的 `pi/K` 输出整理成统一 summary。

第一阶段不建议把复极点求解塞进 `MesonDensity`。
`MesonDensity` 只做 strict BW 数密度积分与摘要层。

### 4.2 `src/models/workflow_apps/MesonDensityWorkflow.jl`

新增 workflow 后处理入口：

1. `solve_strict_bw_meson_density_from_meson_point(meson_point; density_kwargs...)`
2. `solve_gap_and_strict_bw_meson_density_point(T_fm, mu_fm; density_kwargs=(;), kwargs...)`

这与现有：

1. `solve_meson_density_from_meson_point`
2. `solve_phase_shift_meson_density_from_meson_point`

形成三条并列链：

- `stable`
- `strict_bw`
- `phase_shift`

这样可以把“同一 meson workflow 结果上叠加不同数密度口径”的契约固定下来。

## 5. 参数与默认口径

Stage 1 reduced strict BW 建议默认参数：

1. `qmax = 12.0`
2. `q_nodes = 48`
3. `omega_max = 10.0`
4. `omega_nodes = 48`
5. `omega_min = 0.0`

但实现上要额外处理 `omega = E(q)` 附近 Lorentzian 峰形与 `omega -> 0` 下玻色分布增长：

1. 使用 GL 积分时，不让节点恰好落在解析峰点不是问题本身；
2. 数值上真正关键的是 `omega_max` 与 `qmax` 的稳定性回归；
3. 对 `gamma -> 0` 退化，需用单元/回归测试显式守住。

## 6. 输出契约

strict BW workflow 输出建议至少包含：

1. `n_pi`
2. `n_K`
3. `kpi_ratio`
4. `m_pi`, `gamma_pi`
5. `m_K`, `gamma_K`
6. `qmax`, `q_nodes`
7. `omega_max`, `omega_nodes`
8. 诊断量：
   - `pi_q_integral_estimate`
   - `k_q_integral_estimate`
   - `pi_omega_shell_at_qmax`
   - `k_omega_shell_at_qmax`

这样 strict BW 的输出风格可尽量与当前 Phase-E3 helper 对齐，方便比较脚本与 workflow 扫描统一处理。

## 7. 测试与验证层

这部分应至少覆盖两个层级：

### 7.1 单元测试

位置建议：

- `tests/unit/relaxtime/test_meson_density.jl`
- `tests/unit/models/test_meson_density_workflow.jl`

最小断言：

1. `gamma = 0` 或足够小极限下，strict BW 退回 stable；
2. `gamma > 0` 时结果有限且为正；
3. `solve_strict_bw_meson_density_from_meson_point` 与直接 helper 一致；
4. strict BW workflow 不改变 meson workflow 自身的 `pi/K` 质量结果。

### 7.2 分析 / benchmark

位置建议：

- `scripts/analysis/relaxtime/validate_meson_density_strict_bw_minimal.jl`
- `benchmark/relaxtime/bench_bu_double_integral_phase_e3.jl` 的并列 strict BW benchmark

最小检查：

1. `208:2:220 MeV` 窗口下数值稳定；
2. strict BW 与 `BW-proxy` 的差异可解释；
3. strict BW 与 stable 的差异为有限宽度修正，而非数量级跳变。

## 8. 与现有链路的关系

当前建议的正式分工：

1. `stable`
   - 基线、回退极限、快速扫描。
2. `strict BW`
   - 正式的有限宽度极点近似对照层。
3. `phase_shift`（当前默认近似 BU）
   - 正式生产主线。
4. `generalized BU`
   - 更严格参考口径。
5. `BW-proxy`
   - 保留旧分析脚本用途，不再视为正式 workflow 层。

## 9. 当前建议的直接下一步

当前更合理的直接下一步应切到 strict BW 收口后的后续工作：

1. 保留 `Stage 1 reduced` 与 `Stage 2 q-pole` 两条 strict BW 对照链；
2. 默认扫描口径优先使用 `pole_require_converged = true`；
3. 将 strict BW 继续定位为 stable 与 BU 主线之间的极点近似对照层；
4. 主精力转回 generalized BU / Levinson 收口，而不是继续返工 strict BW 同一层积分定义。
