# P1 论文图后端能力任务单

## 背景与目标

面向贴近组内 PRC 风格的 paper 写作，本任务把两类 P1 图件收束为可复用后端能力：

1. `T-muB` Mott 相图：不同 `xi` 下的 `pion/kaon` Mott 线，并在同图叠加可用的手征 crossover、一阶相变线、CEP 与 spinodal。
2. 等熵线扫描图：在 `T-muB` 平面画 `s/nB` 路径，标出路径穿过 `pion/kaon` Mott 条件的位置；伴随面板展示沿等熵线的 `M_pi`、`M_K`、`Gamma_pi`、`Gamma_K`。

本任务的核心不是重写求解器，而是把已有主计算结果稳定转成论文图可消费的数据资产与草图级图像。

## 范围 / 非范围

范围：

- 消费现有主计算产物：
  - `scripts/relaxtime/run_gap_meson_mass_scan.jl` 产出的 `(T, muB, xi)` meson mass / Mott gap 网格。
  - `scripts/pnjl/calculate_phase_structure.jl` 产出的 `first_order_boundary.csv`、`spinodal.csv`、`crossover_line.csv`、`phase_summary.json`。
  - `scripts/relaxtime/run_isentropic_meson_mass_scan.jl` 产出的 fixed-`sigma=s/nB` 路径 CSV。
- 生成固定后处理资产：
  - `mott_lines.csv`
  - `isentropic_trajectories.csv`
  - `isentropic_mott_crossings.csv`
  - `phase_overlay.csv`
  - `figure_manifest.json`
  - 可选草图级 `p1_mott_phase_diagram` 与 `p1_isentropic_mott_paths` 图。

非范围：

- 不改变 PNJL / meson mass / mixed-meson 求解语义。
- 不在本任务中保证真实生产网格已经覆盖所有 Mott 线；主计算覆盖不足时只如实输出可抽取的线段。
- 不把图像最终审美样式固定为论文终版；终版排版可在 paper 目录再做微调。

  - `spinodal_quark` 的低温回折在 finer rho 下保持：`xi=-0.3` 在 `T=60 MeV` 附近取最大，`xi=0` 与 `xi=0.3` 在 `T=70 MeV` 附近取最大。
- 判断：
  - 当前证据不支持“低温 quark spinodal 回折是 rho 粗网格精度误差”，但后续与正式 PNJL 相图 reference 对比显示它也不应直接视为物理曲线特征。

## 2026-05-31 spinodal low-T 正式 reference 对齐诊断

- 对比对象：`data/reference/pnjl/spinodals.csv` 与 `data/reference/pnjl/trho_scan_xi0.0.csv`，对应正式相图 `data/outputs/figures/pnjl/phase_diagrams/phase_diagram_combined.png`。
- 现象：
  - 正式 reference 在 `T=50 MeV, xi=0` 的 quark-side spinodal 约为 `mu≈346.94 MeV, rho≈2.0`，低温段随 `T` 升高单调下降。
  - 本轮 `paper_p1_xi3` reference 使用 `p_num=12,t_num=4` 时，同点 quark-side 极小值提前到 `mu≈339.07 MeV, rho≈1.35`，随后 `mu(rho)` 在 `rho≈1.5` 附近明显偏离正式曲线，造成低温回折。
- 归因 probe：
  - 仅对 `T=50 MeV, xi=0, rho=0:0.05:4` 重跑当前 `Models.run_trho_scan`，把积分节点提高到 `p_num=24,t_num=8` 后，曲线回到正式 reference：quark-side 极小值约 `mu≈346.94 MeV, rho≈2.0`。
  - 因此该回折主要是 `build_dense_phase_reference.jl` 低积分节点默认 `12/4` 引入的数值伪极值，不是 `T-rho` 物理多分支，也不是需要用 pressure 在多个分支中切换。
- 处理：
  - `build_dense_phase_reference.jl` phase 默认改为 `p_num=24,t_num=8`，并新增 `--p-num/--t-num/--iterations` CLI 与 manifest 字段。
  - `run_paper_p1_pipeline.jl` 的 phase stage 默认显式传入 `--p-num 24 --t-num 8 --iterations 80`。
  - 已有 `paper_p1_xi3` reference 需要按新默认重跑后才能作为正式固化产物。

## 暴露的设计问题

1. `phase` 与 `Mott` 生产路径原本缺少单一的 P1 编排入口；已新增 `run_paper_p1_pipeline.jl` 并在 `scripts/relaxtime/README.md` 补充 stage 与 slice plan 用法。若要作为稳定 CLI 入口，仍需要进入稳定脚本清单。
2. phase reference 已有 `build_dense_phase_reference.jl`；P1 后处理现已支持 `--phase-reference-root/--phase-reference-tag`，并在 README 中明确 reference tag 复用方式。
3. `build_paper_p1_figure_assets.py` 原先读取了 `xi` 但绘图按 `kind` 连接 phase 线，可能把不同 `xi` 的 phase 段串线；已修为按 `(kind, xi)` 分组。
4. phase 曲线原先缺少显式 `plot_order_key`，导致 spinodal 这类以 `T` 为参数的曲线容易被下游按 `mu_B` 重排；现已在 phase artifact、dense reference 和 P1 overlay 合同中固定。
5. 高密区 Mott root governance 暴露两类问题：`K` 通道负号等价 pole，以及旧 pion Mott bracket 沿亚稳 continuation 跨 spinodal 跳变。稳定相 equilibrium 模式已修正，合并 Mott 网格旁新增 `mott_grid_combined_manifest.json` 记录 selector policy；`K` 问题经单点复核不是正质量连续穿零，而是 workflow 在 `xi=-0.3, muB=1000 MeV` 从最低温点即选到负号等价根。已在 `MesonMassWorkflow` 输出层统一 `M >= 0` 符号约定，并用 `root_sign_flipped_*` 标记。
6. 等熵路径入口本身使用了项目已有 `FixedSigma` 模式，但调用链需要由 `run_isentropic_meson_mass_scan.jl` 间接触发；建议增加一个 P1 workflow manifest，把 `sigma_target`、`T_grid`、`xi`、`seed` 和失败点统一记录。
7. `select_pressure_max_candidate` 的实现曾与名称/语义不一致，先比较 residual 再比较 pressure，导致 stable 分支仍可能选到亚稳候选；已修复并补单元测试。随后复核发现 `SolverAPI._select_pressure_max_local` 也保留了 residual 优先的重复实现，已同步为 pressure 优先。后续类似 selector 应把 selector policy 写入测试和产物 manifest。
8. 长生产脚本原先不逐行 flush CSV，中途难以判断进度或失败位置；`run_mott_phase_scan.jl` 已补 `flush(io)`，`build_dense_phase_reference.jl` 已补 per-`xi` 进度输出。若后续 phase 单个 `xi` 仍耗时过长，再补 per-`T` 进度。
9. P1 Mott 生产需要按不同 `mu_B` 使用不同 `T` 覆盖；统一编排入口已支持 `--mott-slice-plan`，并把每个 slice 写入合并 manifest。
10. phase reference 原默认 `T_min=50 MeV`，但 stable Mott 高密低温点可能落在 `T<50 MeV`；P1 pipeline 的 phase 默认已改为 `T_min=30 MeV`。已有正式 reference 若仍从 50 MeV 起，需要按新默认或显式 `--phase-tmin 30` 重跑后才能覆盖低温 bracket。
