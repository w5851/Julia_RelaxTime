## 2. 背景判断

当前本地已整理的一批 `Friesen / Blaschke 2020 / Blaschke 2021` 等文献，虽然可作为：

1. charged-ratio phenomenology 的结果层对照；
2. workflow reproduction 的外部样本；

但对“当前仓库主实现链的 formal validation / 强背书”而言，并不是最优第一选择。

因此需要单独立项，重新做一轮更贴近当前实现主线的文献检索与分层。

## 3. 任务范围

### 3.1 检索目标

- NJL / PNJL 中的介子极点方程与极化函数
- `π/K` Mott dissociation
- Beth-Uhlenbeck / generalized Beth-Uhlenbeck
- phase shift thermodynamics
- bound-state / resonance / scattering continuum 统一处理
- 若能找到与当前项目传播子形式、极点方程形式一致或高度等价的文献，优先级最高

### 3.2 明确排除

- 只提供最终 `K/\pi` 曲线、但缺乏上游公式口径闭合的信息源
- 主要价值只是 freeze-out phenomenology 拟合，而不是方法链条本体的文献
- 与当前实现路线差异过大、只能作为远端对照的模型
