# 六费米子同构候选第二轮检索清单

更新日期：2026-05-06

状态：第二轮定向检索已完成；目标是补足“显式包含六费米子相互作用”的更同构候选。

---

## 1. 检索硬约束

本轮新增硬约束为：

- `SU(3)` / `2+1 flavor`
- `Kobayashi-Maskawa-'t Hooft` / `KMT`
- `U_A(1) anomaly`
- `six-fermion` / determinant interaction
- `kaon / pion`
- 尽量靠近 `mesonic correlations / pressure / BU / phase shift`

---

## 2. 结果概览

第二轮的核心结论是：

1. 已经找到**比 A1/A2/A3 更贴近当前主拉氏量**的候选；
2. 但这些新候选大多偏向：
   - meson masses
   - mesonic correlations / pressure
   - crossover / phase-transition thermodynamics
3. 仍然**没有找到一篇同时满足**：
   - `three-flavor or 2+1 flavor PNJL`
   - `explicit KMT / six-fermion interaction`
   - `pi/K`
   - `Beth-Uhlenbeck / phase-shift continuum`
   - `可直接作为当前 formal-validation 主背书`

换句话说：

- “六费米子同构性”这一维度补上了一部分；
- 但“六费米子同构 + BU/phase-shift 完整闭环”这一组合，目前仍未找到强单篇候选。

## 3. A 类：当前最值得继续跟进的新同构候选

### A1. Yamazaki and Matsui, 2013

- 标题：`Quark-hadron phase transition in a three flavor PNJL model for interacting quarks`
- 来源：[arXiv:1310.4960](https://arxiv.org/abs/1310.4960)

为什么它重要：

1. 明确是 `three flavor PNJL`；
2. 明确讨论 `pions and kaons`；
3. 明确讨论 mesonic correlations 对 pressure 的贡献；
4. 摘要直接点明：
   - flavor nonet pseudo-scalar / scalar correlations；
   - axial `U(1)` breaking `Kobayashi-Maskawa-'t Hooft` interaction；
   - pions / kaons 随温度升高熔化进入 quark-antiquark continuum。

当前角色判断：

- 这是目前最接近“当前主拉氏量含六费米子项”这一要求的**新第一候选**；
- 它非常适合作为：
  - `three-flavor + KMT + pion/kaon + mesonic pressure`
    的同构参考；
- 但它看起来更偏 mesonic correlations / pressure，而不是 BU phase-shift 口径。

当前限制：

- 从在线摘要看，它没有直接宣称 Beth-Uhlenbeck / phase-shift 表达；
- 因此它更像“六费米子同构的 mesonic-correlation 文献”，而不是“六费米子同构的 BU 文献”。

正文级新增确认（2026-05-06）：

- 已获取 arXiv PDF 并核对前几页；
- 在模型设定部分，文中显式写出
  - `L4` 四费米子项
  - `L6 = -K [det ... + det ...]`
    的 Kobayashi-Maskawa-'t Hooft 六费米子相互作用；
- 同时正文引言明确声明：
  - 三味 `PNJL`
  - `pions and kaons`
  - mesonic correlations / pressure
  - `KMT` 对低能热激发的作用

因此，`1310.4960` 现在可以从“摘要层第一候选”升格为：

- **已完成最小正文核对的六费米子同构层第一候选**

进一步正文级判断（2026-05-06）：

- 文中热力学势写法是：
  - mean-field 项
  - 加上 scalar / pseudoscalar mesonic correlation 的 Gaussian fluctuation 项
- 文中明确把 mesonic contribution 写成 thermodynamic potential / pressure 的一部分；
- 同时明说：
  - pions / kaons 在升温后熔化进入 quark-antiquark continuum；
  - 关注的是 mesonic correlations / pressure 与 melting temperature。

但目前也可以明确它**还不是什么**：

- 不是 Beth-Uhlenbeck 形式文献；
- 没有 phase-shift 表述；
- 没有当前 `current BU / generalized BU` 那类 continuum 公式治理。

因此对当前项目的最准确定义是：

- **六费米子同构层最强候选**
- **但仍不替代 BU / phase-shift 机制层文献**

### A2. Hell et al., 2009

- 标题：`Thermodynamics of a three-flavor nonlocal Polyakov--Nambu--Jona-Lasinio model`
- 来源：[arXiv:0911.3510](https://arxiv.org/abs/0911.3510)

为什么它重要：

1. 明确是 `three-flavor PNJL`；
2. 明确包含 axial `U(1)` anomaly；
3. 明确写到 additional pionic and kaonic contributions to pressure in RPA。

当前角色判断：

- 它不是 local PNJL，也不是当前仓库的同一技术路线；
- 但它提供了一个：
  - `three-flavor + anomaly + pion/kaon pressure`
    的上游 thermodynamics 参考。

当前限制：

- nonlocal 模型；
- 不是 BU / phase-shift 主线；
- 更适合作为 pressure / thermodynamics 侧辅助文献。

## 4. B 类：局部更同构，但不足以接住当前 F4.6 主目标

### B1. Matsumoto et al., 2010

- 标题：`Investigation of meson masses for real and imaginary chemical potential`
- 来源：[arXiv:1004.0592](https://arxiv.org/abs/1004.0592)

价值：

1. 明确是 `three-flavor PNJL`；
2. 明确写到 six-quark `KMT` determinant interaction；
3. 直接研究 meson masses 与 anomaly coupling。

局限：

- 它更偏 meson-mass / phase-diagram / anomaly-coupling sensitivity；
- 对 `BU / phase-shift / continuum thermodynamics` 的帮助有限。

当前角色：

- 更适合作为 `KMT -> meson spectrum` 的上游背景参考；
- 不足以单独支撑 `F4.6`。

### B2. Friesen et al., 2018

- 标题：`Strange matter and kaon to pion ratio in SU(3) PNJL model`
- 来源：[arXiv:1808.04179](https://arxiv.org/abs/1808.04179)

价值：

1. 明确是 `SU(3) PNJL`；
2. 明确包含 `U_A(1)` anomaly；
3. 直接讨论 `K^+/\pi^+`, `K^-/\pi^-`。

局限：

- 仍偏 phenomenology / horn / CEP；
- 没有把 BU / phase-shift continuum 主线作为核心。

当前角色：

- 它在“六费米子同构”上比 A1/A2/A3 更好；
- 但在 `F4.6` 的 lower-layer validation 目标上仍然偏下游。

## 5. 与第一轮 A1/A2/A3 的关系

当前最稳妥的分工应该改为：

1. **A1/A2/A3（第一轮）**
   - 负责 `BU / phase shift / continuum / off-shell / pressure` 的机制层解释
2. **Yamazaki–Matsui 2013 / Hell et al. 2009 / Matsumoto et al. 2010 / Friesen 2018（第二轮）**
   - 负责 `three-flavor / KMT / anomaly / pion-kaon thermodynamics or spectrum` 的同构层补充

也就是说，现在没有单篇文献同时把这两组要求都满足得很好。
