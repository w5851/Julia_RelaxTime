# 固定 MuB 守恒荷化学势联合求解任务单

更新日期：2026-07-26

当前状态：completed。前置 gate `2026-07-26_带电KPi_BU_kernel门禁与同点消融.md` verdict 为 `diagnostic-only`；本阶段只完成 quark-only 守恒荷联合求解，未修改正式 BU kernel。

## 1. 目标

在统一 `Models` / `ProblemSpec` 主链新增固定 `(T,mu_B)` 的夸克级守恒荷平衡模式，同时求解平均场与 flavor chemical potentials，使

```text
mu_u = mu_B/3 + 2 mu_Q/3
mu_d = mu_B/3 - mu_Q/3
mu_s = mu_B/3 - mu_Q/3 - mu_S
```

并满足

```text
rho_Q - r_QB * rho_B = 0
rho_S - rho_S_target = 0
```

首个使用场景固定 `r_QB=0.4`、`rho_S_target=0`。本任务只计入夸克/平均场热力学中的守恒荷；介子守恒荷修正属于下一阶段外层反馈。

## 3. 物理与数值合同

- `rho_B=(rho_u+rho_d+rho_s)/3`；
- `rho_Q=(2rho_u-rho_d-rho_s)/3`；
- `rho_S=-rho_s`；
- 固定 `mu_B` 通过 `mu_u+2mu_d-mu_B=0` 约束实现；
- charge constraint 使用 affine form `(rho_Q-r_QB*rho_B)/rho0`，不在 `rho_B≈0` 处分母除法；
- strangeness constraint 使用 `(rho_S-rho_S_target)/rho0`；
- 解仍返回完整 `mu_vec=(mu_u,mu_d,mu_s)`，`mu_Q=mu_u-mu_d`、`mu_S=mu_d-mu_s` 由可逆映射读取；
- mode 继续使用 5 个平均场未知量 + 3 个 flavor chemical potentials 的 8 维 unified joint solve。
