## 2. A 类：最接近当前实现主线的机制层参考

### A1. Dubinin et al., 2016 / 2017

- 标题：`Mott dissociation of pions and kaons in hot, dense quark matter`
- 来源：[arXiv:1608.05383](https://arxiv.org/abs/1608.05383)
- 当前定位：**A 类第一优先级（机制层）**

接近点：

1. 明确是 `2+1 flavor PNJL`；
2. 明确围绕 `pi/K`；
3. 明确以 Beth-Uhlenbeck 相移口径处理 bound / resonant / scattering states；
4. 摘要直接点明：
   - Mott transition；
   - threshold phase-shift jump；
   - Levinson theorem；
   - scattering continuum 必须保留，否则高能端相关贡献不会自然消失。

可用于本项目的角色：

- 当前最贴近仓库 `MesonPropagator + Polarization + phase shift` 主链的**机制层主参考文献**；
- 可直接支撑 `phase_shift_current / phase_shift_gbu` 的物理解释边界；
- 也是后续选择 formal validation kernel target 时最值得先回读的原始文献之一。

当前限制：

- 摘要层已经足够证明它高度相关，但若要进一步对齐到代码级公式，需要后续精读正文中的传播子、极点条件与热力学表达式。
- 更关键的是：它没有纳入当前项目已考虑的六费米子相互作用，因此不能视为当前主拉氏量的同构背书。

### A2. Blaschke et al., 2013

- 标题：`Generalized Beth--Uhlenbeck approach to mesons and diquarks in hot, dense quark matter`
- 来源：[arXiv:1305.3907](https://arxiv.org/abs/1305.3907)
- 当前定位：**A 类第二优先级（机制层）**

接近点：

1. 直接讨论 generalized Beth-Uhlenbeck；
2. 明确把热力学势写成 BU 形式；
3. 明确讨论：
   - phase shift 的 resonance / continuum 分解；
   - Mott effect；
   - Levinson theorem；
   - pionic correlation 对 pressure 的贡献。

可用于本项目的角色：

- 当前 `generalized BU` 参考 workflow 的**上游公式文献**；
- 比 `K/pi` 结果层文献更适合给 `delta - 1/2 sin(2delta)` 一类 stricter reference 提供概念与公式背景；
- 可作为 `F4.6` 中“先下沉到 lower-layer target”的理论支撑。

当前限制：

- 该文以 `SU(2) NJL` 为主，不是当前仓库的 `2+1 flavor PNJL` 全等实现；
- 它同样没有当前项目中的六费米子相互作用；
- 更适合作为 generalized-BU 理论口径背书，而不是 `pi/K` 数值 target 本身。

### A3. Maslov and Blaschke, 2023

- 标题：`Effect of mesonic off-shell correlations in the PNJL equation of state`
- 来源：[arXiv:2301.09882](https://arxiv.org/abs/2301.09882)
- 当前定位：**A 类第三优先级（机制层）**

接近点：

1. 直接研究 `PNJL` 下的 mesonic equation of state；
2. 明确写到 meson polarization loop 的完整动量依赖；
3. 明确写到 Beth-Uhlenbeck 下 spacelike continuum / Landau damping 对 pressure 的贡献。

可用于本项目的角色：

- 若后续 formal validation 从 `K/pi` 下沉到 mesonic partial pressure / EOS kernel，这篇比 charged-ratio 文献更贴近目标；
- 很适合作为 `Blaschke:2016sqn Figure 8` 之外的**pressure-kernel 补充文献**；
- 对当前代码里 `q` 依赖与 off-shell / continuum 解释边界有直接帮助。

当前限制：

- 该文是 `2-flavor PNJL`，与当前 `pi/K, 2+1 flavor` 主线不完全同构；
- 它同样没有当前项目中的六费米子相互作用；
- 更适合 pressure / off-shell kernel，而不是直接作为 `K/pi` reproduction target。

## 3. B 类：局部帮助大，但不足以做第一主背书

### B1. Blaschke et al., 2020

- 标题：`Chiral phase transition and kaon-to-pion ratios in the entanglement SU(3) PNJL model`
- 来源：[arXiv:2009.03284](https://arxiv.org/abs/2009.03284)
- 当前定位：**B 类上游-下游过渡文献**

接近点：

1. 仍然围绕 `SU(3) PNJL / EPNJL`；
2. 仍然显式比较 meson pole (`Breit-Wigner`) 与 `Beth-Uhlenbeck`；
3. 仍然讨论 `pi/K` partial densities 与 critical-line proxy path。

可用于本项目的角色：

- 可作为当前 stable / BW / BU 三条 workflow 并排解释时的下游对照文献；
- 也适合作为 `meson mass at mu_B = 0` 一类上游 spectrum target 的来源之一。

不足以做 A 类主背书的原因：

1. 文献目标已明显掺入 `K/pi` 现象学与 critical-line proxy path；
2. 它更接近“下游应用 + path strategy”，不是最纯粹的公式链闭环文献。
