## 待改条目

### 1. 相邻刻度标签间距检查（`scripts/plotting/plot_quality.py`）

现状：`text_overlap_pairs` 能抓到轴标题与刻度标签重叠，但抓不到相邻刻度标签
互相接近。本次 `−0.3` 与 `−0.15` 几乎相碰，靠人工目视才发现。

期望：在 `measure_figure()` 中遍历每个坐标轴的可见主刻度 `Text` 渲染 bbox，
计算相邻标签的水平／垂直净距；水平净距低于约 2.0 pt（或垂直净距低于约 1.5 pt）
时计入布局缺陷并阻断导出。

### 2. `SeriesStyle` 支持 `markerfacecolor`（`scripts/plotting/plot_series.py`）

现状：单色 + 空心/实心编码（灰度可辨、符合无障碍要求）无法作为单一
`SeriesStyle` 注册——填充不参与样式身份，只能把连线与标记拆成两个 ID，再在
`accessibility` 里补说明。

期望：给 `SeriesStyle` 增加可选字段 `markerfacecolor: str | None = None`
（`None` 沿用 `color`，`"white"`／`"none"` 透传到 `plot_kwargs()`），使
「颜色 + 填充」二元编码成为完整样式身份。

### 3. `png_review` 阶段强制 SOP 快照（新脚本模板与需重出的旧脚本）

现状：漏传 `--review-results-dir` 时 PNG 阶段照常出图，直到
`--deliver-vector` 才报 `PNG/vector frozen input contents or roles changed`。

期望：把该参数设为 `required=True`（或自动定位同级 `results/<case_slug>`），
并在写出 PNG 前先调用 `write_sop_snapshot()`；缺失或冲突立即 raise。
