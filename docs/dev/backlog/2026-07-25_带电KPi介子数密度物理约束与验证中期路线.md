# 带电 K/π 介子数密度物理约束与验证中期路线

更新日期：2026-07-25

当前状态：active 中期路线。带电 K/π 主线 Phase 0-4 已形成任务与验证证据；Phase 4 显示介子守恒荷修正显著，但 Phase 5 因 charged BU 支撑域/节点收敛尚未达到 production 认证而暂缓。完整 KMT 相互作用核并行路线的 Phase 0/1 已完成纯公式合同与后端骨架，详见 `docs/dev/active/2026-08-29_full-kmt-interaction-phase0-phase1.md`；完整 RPA 接入尚未开始。

## 1. 决策结论

1. 本路线与输运系数开发按两个任务分支治理。路线文档可以先在当前工作区落盘；后续源码、数值扫描与正式产物应从最新 `origin/main` 建立独立 worktree 和独立 feature branch，避免与长时间运行的 transport 支线互相切换或污染结果目录。
2. 目标观测量同时覆盖 `K^+/π^+` 与 `K^-/π^-`。两个比值必须来自同一个上游平衡态、同一条物理路径和同一套数值策略，并同时保留 `n_{π^+}`、`n_{K^+}`、`n_{π^-}`、`n_{K^-}`，不能只输出单个 ratio。
3. `trho_asymmetric_kplus_piplus_scan_v1` 保留为现有 `FixedAsymmetricRho` 诊断基线，不直接视为实验预测。其 `production-grade` verdict 只说明既定分支、积分窗口和 `x_min_cut` 策略下通过了数值生产门禁，不说明物理口径已被外部数据验证。
4. 主物理路线不优先新增“手工指定 `μ_I`”的独立求解链。优先在固定 `(T, μ_B)` 下，以 `n_Q/n_B=0.4` 和总 `n_S=0` 求解 `μ_Q、μ_S`，再由守恒荷基底推导 `μ_u、μ_d、μ_s`。如需报告 `μ_I`，必须同时声明采用的定义约定。
5. `μ_s=0.55 μ_u`、`μ_s=0.2 μ_q` 等关系只作为文献复现或单变量敏感性情景，不能直接替代守恒荷约束，也不能在没有比较证据时升级为默认平衡条件。
6. 在改平衡态求解前，先完成 BU 数密度 kernel 门禁。必须查清分部积分形式、`dδ/dω` 参考形式、边界项、相移分支与 Levinson 归一化之间的差异；否则改变 `μ_u、μ_d、μ_s` 可能只会掩盖现有 kernel 偏差。
7. 实验比较只承担趋势和数量级验证：目标是结果处于 `O(10^-1)`、以约 `0.3` 为数量级锚点，并能讨论正负电荷通道的宽趋势；不以逐点拟合或精确复现实验误差棒作为中期验收标准。
8. 介子对守恒荷的反馈分阶段接入：先做 quark-only 守恒荷解，再做外层介子修正以测量反馈大小，只有在 kernel 已通过门禁且外层修正不可忽略时，才考虑完整 BU 热力学反馈。

本文件治理的是介子数密度支线的物理口径、阶段顺序、验证层级和实施边界，不替代后续 `docs/dev/active/` 任务单。

## 3. 已知证据与解释边界

### 3.1 当前仓库证据

- `data/outputs/results/relaxtime/meson_density/trho_asymmetric_kplus_piplus_scan_v1/README.md` 记录了当前正式产物：`T=120:10:220 MeV`、`ρ/ρ_0=0.05:0.05:1.00`、`ρ_u/ρ_d=0.876`、夸克层 `ρ_s=0`，BU/GBU 使用 `density_policy=x_min_cut`、`bose_x_min=0.01`。
- 同目录 `PRODUCTION_AUDIT.md` 记录的有限 `kpi_ratio` 最大值约为 `260.5`。这说明异常不是“略高于 0.3”，而是跨越了多个数量级。
- 既有历史 fixed-point 审计显示，current BU 相对 stable 的抬升在 K 通道更强；charged chemical-potential 诊断也显示切换 signed `μ_K` 时主要变化的是 `n_K`。因此后续必须逐通道输出密度，不能只看 ratio。
- 历史审计还发现 current by-parts 与 derivative reference 在相同窗口下存在系统差异，并且简单平移相移尾部不能恢复一致性。该结论支持“先做 kernel 门禁”，但尚不足以指定唯一修复公式。
- 现有 `K^+` 正化学势下出现 `μ_K` 接近或超过低能支撑域的问题；`x_min_cut` 给出了有限诊断结果，但它是项目策略，不是由文献唯一决定的物理处方。

### 3.2 文献口径

- Blaschke 等 2020 的 BU PNJL 工作采用 `μ_u=μ_d=μ_q`、`μ_s=0.2 μ_q` 的 flavor 情景，并引入 `μ_π=100 MeV` 或 `134.5 MeV` 的非平衡 pion-number 准化学势。这里的 `μ_π` 不是同位旋化学势。
- EPNJL 相关工作中的 `μ_s=0.55 μ_u` 是一个基准情景；后续现象学处理中还使用了随路径变量变化的 `μ_s(x)`、`μ_π(x)`。因此 `0.55` 适合进入敏感性矩阵，不适合作为普适平衡关系。
- 文献 Figure 4 中的拼接等温线可以作为 literature-reproduction proxy，但不能替代本项目的主物理冻结线。

### 3.3 当前只能作为假设的内容

- “同位旋不对称条件是超大 ratio 的主要根因”仍是假设。它需要在同一个 meson point 上只改变 chemical-potential prescription 的消融实验来验证。
- “介子奇异度反馈能够把 ratio 拉回实验量级”仍是假设。反馈可能改变 `μ_S`，也可能因 BU kernel 不稳定而放大计算成本或数值噪声。
- “当前随温度下降的趋势是错误趋势”也不能脱离路径判断。固定 `ρ`、固定 `μ_B`、冻结线和临界线不是同一个温度导数。

## 4. 化学势基底与命名约定

主路线使用守恒荷基底：

```text
μ_u = μ_B/3 + 2μ_Q/3
μ_d = μ_B/3 - μ_Q/3
μ_s = μ_B/3 - μ_Q/3 - μ_S
```

相应的化学平衡部分满足：

```text
μ_{π+}^{eq} = μ_u - μ_d
μ_{π-}^{eq} = μ_d - μ_u
μ_{K+}^{eq} = μ_u - μ_s
μ_{K-}^{eq} = μ_s - μ_u
```

中期实现必须区分三类量：

1. `μ_Q、μ_S`：由总守恒荷约束求出的热力学化学势。
2. `μ_I`：同位旋化学势的报告别名。若定义为 `μ_u-μ_d`，则等于 `μ_Q`；若采用 half-splitting 定义，则为 `(μ_u-μ_d)/2`。任何 API、配置和图注都必须声明约定。
3. `μ_π^neq`：描述化学非平衡 pion-number fugacity 的准化学势，可作为独立现象学参数；不得与 `μ_I` 或 `μ_Q` 混写。

这一路由能在不新增手工 `μ_I` 主链的前提下自然产生 `μ_u != μ_d`，也能让正负 charged channel 的符号关系由守恒荷基底统一给出。

## 5. 中期目标与完成信号

本路线的目标不是把某条曲线调到 `0.3`，而是建立一条可解释的双通道计算链。完成信号如下：

1. 同一个平衡态能稳定输出 `K^+/π^+` 和 `K^-/π^-` 及四个组成密度，并记录所有 flavor、conserved-charge 和 meson chemical potentials。
2. BU 主口径与 derivative reference 的差异已被边界项、相移分支、离散化误差或明确的物理近似解释；正式口径不依赖未标注的相移平移或静默 Bose 截断。
3. quark-only 守恒荷求解在代表点满足 `n_Q/n_B=0.4` 与 `n_S=0`，并输出可审计残差和分支选择信息。
4. 介子反馈的影响被定量拆成“无反馈、外层修正、完整反馈候选”三层；是否进入完整反馈由结果大小和稳定性决定，而不是预先承诺。
5. 沿经验化学冻结线的双通道结果在合理参数窗口内保持有限、数值收敛，并处于 `O(10^-1)` 而非 `O(10^1-10^2)`。约 `0.3` 只作数量级锚点，不设成逐点硬 target。
6. 当横轴映射到 `sqrt(s_NN)` 时，结果资产可以分别讨论 `K^+/π^+` 的宽峰或 horn-like 结构以及 `K^-/π^-` 的更平滑能量依赖；现阶段只要求方向和量级可比较，不要求精确拟合峰位与峰高。
7. 经验冻结线承担物理预测，pseudo-critical line 承担模型诊断，拼接等温线只承担明确标注的文献复现。

## 6. 分阶段路线

### Phase 0：证据冻结与同点诊断合同

目的：把“现有图看起来不对”转成可重复的最小问题。

近期 active 任务应固定少量代表点，并在同一个 upstream meson point 上输出：

- 四个 charged densities 与两个 ratio；
- `μ_u、μ_d、μ_s、μ_Q、μ_S、μ_{π±}、μ_{K±}`；
- `m_M-μ_M`、Bose-domain status、积分边界与相移端点；
- stable、strict BW、current BU、GBU 和 derivative reference；
- `n_K` 与 `n_π` 对 ratio 变化的独立贡献。

退出条件：同点诊断资产可复现组会图中的代表异常，并能区分 upstream state、chemical prescription、density kernel 和 scan path 四类变化。

### Phase 1：BU kernel 与边界项门禁

目的：在不改变平衡态的前提下确认数密度公式的有效数值语义。

门禁至少覆盖：

- derivative form 与 by-parts form 在相同有限积分域上的完整恒等式，包括上下边界项；
- 相移 unwrap、显示折叠与实际积分相移的职责分离；
- 高能端、阈值端和 Levinson 约束；
- `phase_shift_current` 与 GBU weight 的差异是否来自预期的 phase weighting；
- `μ_M` 接近低能支撑域时的 Bose-domain 判定，禁止把 `x_min_cut` 自动解释成物理延拓；
- `qmax、ωmax`、节点数和 cutoff policy 的联合收敛。

退出条件：选定一个有公式和边界证据支撑的主 kernel；其余口径保留为 reference 或 diagnostic，并明确不能承担的结论。

### Phase 2：化学势单变量消融与双通道闭合

目的：回答 chemical-potential prescription 能解释多少偏差，而不把 solver 与 kernel 同时改动。

至少比较：

- 当前 `FixedAsymmetricRho` quark-only state；
- BU2020 的 `μ_s=0.2 μ_q` 文献复现情景；
- EPNJL 基准 `μ_s=0.55 μ_u` 敏感性情景；
- signed `μ_{π±}`、`μ_{K±}` 的 chemical-equilibrium mapping；
- 可选 `μ_π^neq` 情景，但与 `μ_Q/μ_I` 分栏输出。

退出条件：能回答超大 ratio 主要由 `μ_K`、`n_K` kernel、Bose-domain policy 还是上游质量/相移变化驱动，并据此决定下一阶段需要改 solver 还是只需修 kernel。

### Phase 3：quark-only 守恒荷化学势求解

目的：用物理上可解释的守恒荷约束替代 `ρ_u/ρ_d=0.876` 的历史近似，同时控制第一版计算成本。

在固定 `(T, μ_B)` 下联合求解 PNJL 平衡态与 `μ_Q、μ_S`，约束为：

```text
n_Q^q / n_B^q = 0.4
n_S^q = 0
```

该阶段仍不把介子写回约束，但必须把它标为 quark-only baseline。实现应复用 `Models` 统一入口，保持 mixed-meson governance 和 non-fixedmu unified joint-solve 语义不变，并保留多根/压力最大分支治理。

退出条件：代表性 `(T, μ_B)` 点和一条稀疏冻结线路径稳定收敛，约束残差、分支选择、flavor chemical potentials 和双通道输出完整可审计。

### Phase 4：外层介子守恒荷修正

目的：以可控成本测量介子对 `n_Q、n_S` 的反馈大小。

对每个候选 `μ_Q、μ_S` 重新求 quark mean-field state，再计算 charged meson densities，并在外层求解：

```text
(n_Q^q + n_Q^M) / n_B^q = 0.4
n_S^q + n_S^M = 0
```

第一版只在少量固定点运行，使用 warm start、缓存和明确的最大迭代预算。该结果属于 partial-feedback diagnostic，因为 meson contribution 尚未进入 mean-field stationarity。若修正很小且稳定，可以用误差预算论证后续仍采用 quark-only baseline；若修正显著或改变 charged splitting，则进入 Phase 5 评估。

退出条件：给出 `μ_Q、μ_S`、四个 meson densities 和两个 ratio 相对 Phase 3 的变化，并对忽略完整反馈的误差作出量化判断。

2026-07-26 状态：已完成单点 partial-feedback spike。`T=170 MeV, mu_B=240 MeV` 的 `q8*omega16` 诊断把 `mu_S` 从约 `80.27 MeV` 修正到 `1.50 MeV`，`K+/pi+` 从 `5.35` 变为 `1.05`、`K-/pi-` 从 `0.094` 变为 `0.864`。反馈效应显著，属于 `full-feedback-candidate`；但输入使用 `x_min_cut` 且 quark-only 正 K 通道仍有明显节点漂移，因此不立即拉起 Phase 5 实现。

### Phase 5：完整 BU 热力学反馈，条件性阶段

当前状态：deferred。Phase 4 的影响大小满足“值得评估”的条件，但 kernel physicality/convergence 前置条件尚未满足。

只有同时满足以下条件才拉起：

1. Phase 1 kernel 与边界项门禁已通过；
2. Phase 4 表明介子反馈不可忽略；
3. `Ω_M` 对 fields 和 conserved chemical potentials 的导数能以可验证、可收敛的方式计算；
4. 代表点运行成本可接受。

目标形式是从同一个 `Ω_total=Ω_PNJL+Ω_M` 导出 stationarity 与 `n_X=-∂Ω_total/∂μ_X`，避免把后处理密度与热力学导数混成伪自洽解。该阶段允许因成本或数值不稳定停留在研究 spike，不预先承诺主线化。

### Phase 6：冻结线验证与正式生产

主输出至少包含：

- 经验化学冻结线上的 `K^+/π^+`、`K^-/π^-` 及组成密度；
- pseudo-critical line 的同口径诊断对照；
- 结果对 kernel、chemical scenario 和 feedback level 的敏感性带；
- convergence manifest、constraint residual、branch policy 和 Bose-domain status；
- 以趋势和数量级为主的实验比较说明。

拼接等温线若保留，只能放在 literature-reproduction panel，不得替代冻结线主结论。

## 7. 验证分层

| 层级 | 责任 |
| --- | --- |
| unit | 守恒荷到 flavor chemical potentials 的代数映射、charged channel 符号、`μ_I` 约定、边界项公式、非法物理域与残差校验 |
| integration | 同一 equilibrium state 的正负双通道工作流；代表点 `μ_Q、μ_S` 联合求解；scan contract 与 metadata |
| regression | kernel 固定点、约束解固定点、稀疏冻结线路径和现有 `FixedAsymmetricRho` 诊断语义不意外漂移 |
| validation | BU 文献 fixed-point/curve 的机制对照；实验只检查数量级、charged splitting 和宽趋势，不做逐点拟合 gate |
| production | 数值收敛、分支稳定、完整 manifest、正式 result/figure 布局；只有通过前述物理门禁后才允许使用 `production-grade` |

任何数值语义变化都必须先解释误差来源和物理含义，不允许为了接近 `0.3` 或通过 baseline 而放宽容差。

## 8. 非目标与不变约束

- 不以调参方式强制 ratio 等于 `0.3`。
- 不把 `μ_s=0.55 μ_u` 或 `μ_s=0.2 μ_q` 宣称为重离子体系的唯一平衡条件。
- 不把非平衡 `μ_π^neq` 当成 `μ_I`。
- 不把拼接等温线当作主物理冻结线。
- 不在 kernel 未收口前直接投入完整 meson-feedback joint solve。
- 不在本路线中改变 mixed-meson governance、现有 non-fixedmu unified joint-solve 语义或 transport 数值口径。
- 不因建立新路线而废弃现有 `FixedAsymmetricRho` 产物；它继续承担诊断和回归比较职责。

## 9. 风险与应对

1. **把 kernel 偏差误判为平衡态偏差**
   - 应对：Phase 1、2 均复用同一个 upstream state，只改变一个公式或 chemical scenario。
2. **Bose pole 邻域由截断策略主导结果**
   - 应对：输出 `m_M-μ_M`、实际积分下界与 cutoff sensitivity；物理结论不得只依赖单个 `bose_x_min`。
3. **`μ_I、μ_Q、μ_π^neq` 记号混淆**
   - 应对：API、配置、CSV 和图注使用不同字段，并把同位旋约定写入 manifest。
4. **partial feedback 被误称为热力学自洽**
   - 应对：Phase 4 固定标注 `partial-feedback diagnostic`；只有 Phase 5 可使用 full thermodynamic feedback 表述。
5. **多根与路径延拓改变上游 state**
   - 应对：复用 pressure-max、多 seed 与连续路径治理，记录所有候选和选择理由。
6. **与 transport 支线产生工作区和结果冲突**
   - 应对：代码实施使用独立 worktree、独立 branch 和独立 case slug；共享源码改动只通过已审核提交或 PR 同步。

推荐做法：

1. 当前工作区只承载本路线文档或短小审阅改动。
2. 在开始 Phase 0/1 的代码工作前先同步远端信息，以最新 `origin/main` 为基线创建新的 worktree。
3. transport 支线与本支线分别维护 active 任务单、验证命令和产物目录。
4. 若两条支线都需要修改 `src/relaxtime/MesonDensity.jl` 或共享 solver，应先收敛最小提交，再通过 cherry-pick/rebase 或 PR 顺序解决依赖，不在同一工作区来回切 branch。

选择独立 worktree 的原因不是 Git 形式偏好，而是本路线会同时触及 `src/models/`、`src/relaxtime/`、配置、跨层测试和长时数值产物，生命周期与 transport 开发重叠，冲突面和运行状态都明显大于 docs-only 任务。

## 11. 滚动复审与 active 任务拆分

每完成一个 Phase 或出现下列事件时复审本路线：

- kernel 主公式或边界条件发生变化；
- 外层介子修正显著改变 `μ_Q、μ_S` 或 charged ratios；
- 新文献提供更明确的 flavor chemical-potential 或 freezeout 处方；
- 实验比较目标从趋势/数量级升级为定量拟合；
- transport 或 PNJL 主线修改共享 equilibrium / phase-shift 语义。

复审时更新：当前事实、下一阶段入口条件、保留/淘汰的方案、验证资产和成本估计。

后续建议拆为四类 active 任务单，而不是把本页变成执行日志：

1. BU kernel、边界项与双通道同点诊断。
2. 守恒荷化学势基底与 quark-only `μ_Q、μ_S` 联合求解。
3. 外层介子 `n_Q、n_S` 修正 spike 及是否进入完整反馈的决策。
4. 冻结线双通道正式生产、趋势验证与分析产物。

物理口径最终确认由项目作者负责；每个 active 任务的实现、验证和文档同步由该任务负责人负责。
