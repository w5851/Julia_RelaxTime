## 冻结公式

通道为 pi+=(u,d)、pi-=(d,u)、K+=(u,s)、K-=(s,u)。耦合分别取 full KMT 的
K12_P、K45_P；K03/K38 不进入 charged scalar 分母。退化度每个电荷态为 1。

```math
z=k_0+\mu_1-\mu_2+i0^+,\qquad
\Delta^{-1}=1-4K_a\Pi_a(z,q),\qquad
\delta=-\arg\Delta^{-1},\quad F(\delta)=\delta-\tfrac12\sin(2\delta).
```

Pi 使用 [完整谱泡](ChargedRPA_BU_ProductionRoute.md#521-同一-regulator-的完整谱泡研究候选2026-09-05)
及其配套 Cauchy/PV 重建，实虚部不可来自不同 regulator。真空两线均限制在模型
Lambda 内，热两线使用显式 L_th 并检验热尾极限。接触项为同域 C(q)，不是把
q=0 的 A1+A2 强制用于有限 q。

```math
n_a^{\rm GBU}=\int_0^\infty\frac{q^2dq}{2\pi^2}
\left[\sum_{b\in\mathrm{certified\ gap}}g_B(k_{0b};0)
 +\sum_{c\in\mathrm{cuts}}\int_c\frac{g_B(k_0;0)}{\pi}\,dF(\delta_c)\right].
```

独立根贡献一个 pi 跳变，因此普通 BU 与 GBU 的离散权重相同。连续谱保持有符号，
包含 Landau 和 unitary；禁止 fold、全局翻号、负值裁零或删除 anomalous。
主值角只在无未处理跳变的连续区间求导，不承担束缚态计数。
所有频率/动量内部单位 fm^-1，密度 fm^-3；k0 已含化学势平移，Bose 核不再减一次
mu_M。阈值为 sqrt(q^2+(m1+m2)^2)-(mu1-mu2)。

下端为正常相的 k0->0+ 极限。有限 eta 比较先在固定正下端做 eta->0+，再移动
PV 下端；不交换极限。分部积分形式必须保留两端边界项。

1. temp7 原始函数与新核使用同一给定质量、T、mu、Polyakov、耦合及 q=0。
   先统一 Pi/分母归一化，分别记录实部、虚部及相位，不以 fold 后外观作为一致性。
   temp7 的历史 B0 依赖和源文件须一并记哈希；不修改外部 temp7。
2. 分开比较同截断和真空截断/热项延伸，避免把 thermal 处方差异误报为代码 bug。
3. 在**相同新 q=0 核**上定义 timelike 参考
   delta_ref(k0,q)=delta_0(sqrt((k0+mu1-mu2)^2-q^2)-(mu1-mu2))。
   这是文献外推思想在当前 KMS 坐标下的项目版本，不是原 temp7 外频率公式的逐字
   复用。spacelike 谱不在这一近似模型内；它的零值不能移植到直接有限 q 路线。
4. 该参考和直接有限 q 使用同一 Bose 核、离散计数、参数及外层求积；分别报告
   bound、unitary、Landau 差异。参考的低端、跨零点或非正常域失败必须保留。

## 验收与停止条件

- 根必须位于由运动学认证的开解析 gap，满足实虚部残差；加密扫描并用复平面
  围道零点计数检查遗漏的偶重或近邻根。围道绕数仅计数，不定义密度相位。
- 围道证据只覆盖明确给出的解析域与离散谱精度，不宣称全模型无遗漏。
  额外 cutoff gap、cut 内零点和凝聚/不稳定模仍须单独检查。
- Mott 必须定位根到 unitary 阈值的接触，而不是只看某次扫描根数减少；同时检查
  阈值相位补偿。热 Mott 与固定 T 下的有限 q 消失分别命名。
  密度壳层的阈值相位采用上方偏移 1e-7/1e-8/1e-9/1e-10 fm^-1 的趋近序列，
  末两点相位/pi 变化须小于既有 phase_tolerance/10，且不允许未分辨阈值零点。
  这不是降低残差要求：根数与末点相位仍使用原 phase_tolerance 检查，同时保留
  首末探针及变化。极接近或恰在 Mott 的零点需要专门处理，不强制四舍五入计数。
- 数值误差逐轴比较谱节点、根节点、omega/q 节点、下端和尾部。参考目标密度
  相对变化 <1%，Mott 温度 bracket <=0.25 MeV；这些不是证明绝对误差的上限。
  谱 `energy_nodes` 是解析角向 cut 后的一维求积节点；它与直接二维泡的
  `momentum_nodes/angle_nodes` 分开记录和加密。只改后两者不构成密度谱收敛检查。
- 正则化对照单独标记为模型差异。固定真空 Lambda；全热硬截断仅作敏感性模型，
  不冒充与 thermal-extended 上游严格一致。改变 Lambda 需要参数重新拟合，当前不做。
- 稀疏冻结线使用仓库既有 baseline 参数化，先取 sqrt(sNN)=3、7.7、200 GeV。
  任何背景、谱、计数、正常相或收敛失败均保存原因并阻止完整曲线扩展。
- 不用实验数据选择切支、cutoff 或容差。实验口径对齐和论文图表冻结在上述检查后。

## 首轮正则化风险

2026-09-05 同背景比较发现 direct finite-q 与 q=0 外推的密度有数量级差异，
不能把这种差异归为数值误差或声称 direct finite-q 已经优于文献近似。
相对动量中心截断探针最初只比较解析 gap 极点；后续已扩展到同谱实虚部、
contact与有限窗口解析gap检查，仍不提供替代实轴密度。

在真空小 q 极限，双线球交集丢失的边界帽产生

```math
C(q)-C(0)=\Lambda^2\left(\frac{1}{E_1(\Lambda)}+
\frac{1}{E_2(\Lambda)}\right)|q|+O(q^2).
```

这是从积分域得到的数学推导，不是文献给出的经验修正；同一中心球截断的
接触项变化以 q^2 起始。测试检查这两个标度。当前 thermal-extended 设置下，
L_th 处占据很小，真空边界项仍显著。由此导致的极点色散和密度依赖是 v1 的
模型系统项，不得通过改相移或调容差消除。方法冻结只固定可复查的候选定义，
不表示正则化选择已经适合实验预测；完整冻结线与论文物理结论暂不能据此授权。

### 文献支持的后续对照，不自动改写 v1

上界的显著依赖；它不等同于内部夸克真空 cutoff，也不提供本项目 charged-BQS

保持同一真空谱和参数，在有限 q 检验真空洛伦兹色散及热 Landau 谱，并将相同
谱截断同时施加于 Cauchy 实部和虚部。不能仅读 A.4 就混用截断实部与未截断
虚部。推广到不等质量/有序化学势、匹配 contact、必要的减法及高能行为，都必须
