## 1. 引用口径与文献分工

本文需要同时引用“传播子/极点来源”和“BU 热力学来源”，二者职责必须分开：

1. `Hatsuda:1994pi`
   - 角色：NJL/RPA 介子传播子与极化函数的一般综述背景；
   - 作用：说明 BU 相移完全可以建立在介子传播子的相位结构上；
   - 不是本文 BU 热力学公式的直接来源。
2. `Rehberg:1996da`
   - 角色：当前项目简单介子道传播子与极点方程的直接 SU(3) NJL 背书；
   - 作用：支撑本文采用
     ```math
     \mathcal{D}_M=\frac{2K_M}{1-4K_M\Pi_M},
     \qquad
     \delta_M=\arg\mathcal{D}_M
     ```
     这一项目口径；
   - 它负责“相移从哪一个传播子来”，不是负责 BU 热力学权重本身。
3. `Maslov:2023wul`
   - 角色：phase-shift / off-shell 热力学主线背书；
   - 作用：支撑“用相移积分构造介子热力学量”这条方法结构；
   - 它负责本文 BU 主线的热力学方法归宿。

因此，本文的引用口径应理解为：

- **传播子底座**：`Hatsuda:1994pi` + `Rehberg:1996da`
- **BU 热力学结构**：`Maslov:2023wul`
- **当前 `pi/K` 最小实现的直接参考写法**：`Blaschke:2020bzh`、`Blaschke:2021yml`

## 2. BU 主公式

广义 Beth-Uhlenbeck 形式写为：

```math
n_M(T)
= d_M \int \frac{d^3q}{(2\pi)^3}
\int \frac{d\omega}{2\pi}
g_M(\omega)\frac{d\delta_M(\omega,q)}{d\omega}.
```

### 来源

- `Blaschke:2020bzh` Eq. (24)
- `Blaschke:2021yml` Eq. (8)

## 3. 分部积分后的等价形式

对上式分部积分后，得到：

```math
n_M(T)
= \frac{d_M}{T}
\int \frac{dq\,q^2}{2\pi^2}
\int_0^\infty \frac{d\omega}{2\pi}
g_M(\omega)\bigl[1+g_M(\omega)\bigr]\delta_M(\omega).
```

### 来源

- `Blaschke:2020bzh` Eq. (25)

## 4. 当前优先实现口径

当前主线优先采用**分部积分后的 `\delta_M` 本体形式**，原因是：

1. 当前项目后续相移将由传播子数值相位提取；
2. 直接对 `\delta_M` 求 `\omega` 导数更容易放大数值噪声；
3. 相移本体形式更利于先检查 Levinson 约束和相位分支选择。

导数形式保留为理论原式和交叉验证口径。

## 5. 当前项目中的相移定义

文献常通过传播子的极坐标形式定义相移：

```math
S^M_{ij}(\omega,q)=|S^M_{ij}(\omega,q)|e^{i\delta_M(\omega,q)}.
```

对当前项目简单介子道，优先采用项目化解释：

```math
\delta_M(\omega,q;\xi)=\arg \mathcal{D}_M(\omega+i\eta,q;\xi).
```

其中当前项目主传播子为：

```math
\mathcal{D}_M(\omega,q;\xi)
= \frac{2K_M}{1-4K_M\Pi_M(\omega,q;\xi)}.
```

这意味着 BU 相移主线必须服从当前项目的传播子与极点条件口径，而不是直接切换成文献里另一套归一化记号。

### 5.1 为什么不直接改成文献里的传播子写法

当前 `pi/K` 文献中，常见写法是

```math
S_M \sim \frac{1}{1-2P_M\Pi_M}
```

而当前项目简单介子道采用的是

```math
\mathcal{D}_M = \frac{2K_M}{1-4K_M\Pi_M}.
```

这两者的**归一化与耦合记号**不同，但它们服务的物理任务相同：都是通过传播子分母零点或相位结构来描述介子相关。

对本项目而言，更合理的原则是：

1. 对齐文献的**方法结构**：
   - 用传播子相位定义 BU 相移
   - 用 BU 原式或分部积分形式计算相关热力学量
   - 检查阈值、高能端与 Levinson 约束
2. 保持本项目的**传播子/极点方程口径不变**：
   - `1-4K_M\Pi_M=0`
   - `\delta_M=\arg \mathcal{D}_M`

原因是：

- 当前项目的介子质量计算、Mott 阈值与宽度主线已经围绕该传播子口径建立；
- 若仅为对齐文献外形而把传播子分母改写成另一套记号，反而会让介子质量链、BW 链和 BU 链之间失去一致性；
- 文献中的 BU/BW 推导依赖的是“传播子极点与相位”的一般结构，而不是某个特定的 `2` 或 `4` 系数本身。

因此，在这条链路中应对齐的是**物理/数学结构**，而不是机械改写成文献的符号外形。

## 6. Levinson 约束与物理检查

在 BU 实现中，应满足下列物理检查：

1. 束缚态对应相移 `+\pi` 跳变；
2. 高能端相移应回到 `0`；
3. Mott 解离后，原束缚态跳变应转为连续谱/共振结构。

这些检查先于数值积分结果本身，是相移实现是否可信的基本门禁。

## 7. 当前边界

本文只固定：

1. BU 数密度表达；
2. 相移与当前项目传播子之间的关系；
3. 分部积分形式作为当前优先实现口径。

它不负责：

1. BW 近似；
2. 稳定粒子极限；
3. 冻结线现象学拟合；
4. 各向异性下的完整角向积分实现细节。
