## 1. 引用口径与文献分工

当前介子数密度主线中，本文只固定**稳定粒子极限**这一层；与它相邻的“传播子/极点”和“BU 热力学”文献角色分工如下：

1. `Hatsuda:1994pi`：
   - 作为 NJL/RPA 介子传播子与极化函数结构的综述性上游背景；
   - 用来解释为什么项目里可以沿“传播子 -> 极点 -> 介子质量”这条链定义介子输入；
   - 不是本文稳定粒子玻色积分公式的直接来源。
2. `Rehberg:1996da`：
   - 作为 thesis 第 5 章 `(5.34)-(5.36)` 所追溯的直接 SU(3) NJL 介子传播子/极点方程来源；
   - 支撑当前项目 `1-4K_M\Pi_M=0` 这一介子质量上游口径；
   - 但它不负责本文的稳定粒子数密度积分公式本身。
3. `Maslov:2023wul`：
   - 作为后续 BU / off-shell 热力学主线的文献背书；
   - 用来约束“稳定粒子极限只是后续 BU 链的降阶基线”这一角色；
   - 不是本文公式的直接推导来源。

因此，本文中的稳定粒子公式应理解为：

- **直接公式来源**：`Blaschke:2020bzh`、`Blaschke:2021yml` 给出的稳定粒子密度写法；
- **上游输入来源**：`Hatsuda:1994pi` + `Rehberg:1996da` 支撑项目中介子质量/极点的定义；
- **下游比较来源**：`Maslov:2023wul` 支撑后续与 BU / off-shell 结果的比较框架。

## 3. 稳定粒子极限数密度

对稳定、无宽度的介子，采用玻色分布积分：

```math
n_M
= d_M \int \frac{d^3 q}{(2\pi)^3} g_M(E_M),
\quad
g_M(E_M)=\frac{1}{e^{(E_M-\mu_M)/T}-1},
\quad
E_M=\sqrt{q^2+m_M^2}.
```

利用角积分后，可写为：

```math
n_M
= d_M \int_0^\infty \frac{dq\,q^2}{2\pi^2}
\frac{1}{e^{(E_M-\mu_M)/T}-1}.
```

### 来源

- `Blaschke:2020bzh` Eq. (23)
- `Blaschke:2021yml` Eq. (7)

## 4. `K/\pi` 比值定义

当前主线的 `K/\pi` 比值定义为：

```math
\frac{K}{\pi} = \frac{n_K}{n_\pi}.
```

若后续进入电荷分辨现象学，可进一步写为：

```math
\frac{K^\pm}{\pi^\pm} = \frac{n_{K^\pm}}{n_{\pi^\pm}},
```

但这不属于当前最小平衡态主线。

## 5. 当前默认化学势口径

在 `\mu_B = 0` 的最小平衡态实现中，默认采用：

```math
\mu_u=\mu_d=\mu_s=0,
\qquad
\mu_\pi=0,
\qquad
\mu_K=0.
```

这一定义只用于当前 MVP，不否定后续现象学阶段引入 `\mu_\pi(x)`、`\mu_s(x)` 的做法。

## 6. 当前默认简并因子口径

当前主线默认输出聚合通道总数密度，因此采用：

```math
d_\pi = 3,
\qquad
d_K = 4.
```

对应：

- `\pi` 三重态：`(\pi^+, \pi^0, \pi^-)`
- `K` 四重态：`(K^+, K^0, K^-, \bar K^0)`

若后续进入电荷分辨通道，则每个单态默认使用 `d_M = 1`。

## 7. 当前实现边界

当前稳定粒子极限文档只负责：

1. 给出最小数密度基线公式；
2. 固定 `K/\pi` 比值定义；
3. 固定 `\mu_B = 0` 下的最小化学势和简并因子口径。
