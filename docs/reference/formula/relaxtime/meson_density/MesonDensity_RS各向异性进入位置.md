## 1. 当前项目中 RS 各向异性的作用位置

当前项目里 RS 各向异性已经进入：

1. 夸克分布函数
2. 单圈积分修正
3. 极化函数 `\Pi_M(\omega,q;\xi)`
4. 介子传播子 `\mathcal{D}_M(\omega,q;\xi)`

因此，当前最自然的主线是：

```math
\Pi_M(\omega,q;\xi)
\rightarrow
\mathcal{D}_M(\omega,q;\xi)
\rightarrow
\delta_M(\omega,q;\xi)
\rightarrow
n_M(T;\xi).
```

## 2. 当前不直接修改稳定粒子 `E_M`

在当前 `Phase D` 的稳定粒子极限中，不直接把

```math
E_M=\sqrt{q^2+m_M^2}
```

改写成经验型 `E_M(\xi)`。

### 原因

1. 当前项目已有的 RS 修正首先作用在夸克侧与极化函数侧；
2. 若直接手写 `E_M(\xi)`，容易把“项目自洽传播子修正”和“额外现象学假设”混在一起；
3. 对当前主线而言，更可信的方式是让各向异性通过 `\Pi \to \mathcal{D} \to \delta_M` 进入。

## 3. 若后续需要各向异性的介子色散关系

若未来要做各向异性的稳定 / BW 准粒子近似，应遵循：

1. 从当前项目极点条件
   ```math
   1-4K_M\Pi_M(p_0,q;\xi)=0
   ```
   出发
2. 在给定 `\xi` 下重新导出介子色散关系
3. 必要时显式允许方向依赖 `E_M(q,\theta;\xi)`

而不是先人为规定某个经验型 `E_M(\xi)` 再回填。

## 4. 当前 MVP 的范围约束

在当前 MVP 中，不要求：

1. 完成各向异性下的介子数密度链路；
2. 完成 `E_M(q,\theta;\xi)` 的导出；
3. 完成各向异性 BU 数值积分。

当前阶段只要求后续 BU 相移主线在结构上允许 RS 自然接入。

## 5. 当前结论

当前介子数密度主线对 RS 各向异性的固定规则是：

1. 稳定粒子极限不直接修改 `E_M`；
2. RS 主效应后续通过 `\Pi`、`\mathcal{D}` 与 `\delta_M` 进入；
3. 若需要各向异性准粒子近似，必须从项目主极点条件重新导出色散关系。
