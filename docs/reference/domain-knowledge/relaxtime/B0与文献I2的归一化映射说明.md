# B0 与文献 I2 的归一化映射说明

## 1. 目的与边界

本文专门说明当前项目中 `B0` 积分与文献常用双传播子圈积分 `I_2` 的对应关系，并把这个对应关系同：

- 极化函数 `\Pi`
- 有效耦合 `K_a` / `P_{ij}`
- 极点方程

一起闭合起来。

这页文档的目标不是重复 [OneLoopIntegral_B0.md](../../formula/relaxtime/integrals/OneLoopIntegral_B0.md) 的积分推导，而是回答一个更窄的问题：

```math
\boxed{\text{项目中的 } B_0 \text{ 到底对应文献中的哪个 } I_2\text{，差几个因子、差什么号？}}
```

讨论范围限定在当前项目实际使用的赝标量介子极化函数口径，重点是 `\pi/K` 通道与 `k=0` 的极点问题；但归一化结论本身同样适用于对应的 `k\neq 0` 结构。

## 2. 结论先行

对当前项目主线口径，若把单线积分写成**与文献三维 cutoff 完全同口径**的
```math
A_\Lambda
```
（即真空项与热分布项都只积分到同一个 `\Lambda`），则文献中常见的
```math
I_2^{ij}
```
与项目里的
```math
B_0^{ij}
```
满足
```math
\boxed{
I_2^{ij}
= -\frac{N_c}{16\pi^2}\, B_0^{ij}
}
```

同时，文献里的极化函数若写成
```math
\Pi_{ij,\mathrm{lit}}^P
= 4\left[
I_1^i + I_1^j
-\bigl(P_0^2-(M_i-M_j)^2\bigr) I_2^{ij}
\right],
```
而项目里的极化函数写成
```math
\Pi_{ij,\mathrm{proj}}^P
= -\frac{N_c}{8\pi^2}
\left[
A_{\Lambda,i} + A_{\Lambda,j}
-\bigl(\lambda^2-(m_i-m_j)^2\bigr) B_0^{ij}
\right],
```
则两者之间满足
```math
\boxed{
\Pi_{ij,\mathrm{lit}}^P = 2\,\Pi_{ij,\mathrm{proj}}^P
\qquad(\text{同 cutoff 口径})
}
```

这个因子 2 不是矛盾，而是被有效耦合的定义吸收掉了。对 `\pi/K` 通道有
```math
\boxed{
P_\pi = 2K_{123}^+,\qquad
P_K = 2K_{4567}^+
}
```
因此文献极点方程
```math
1-P_{ij}\Pi_{ij,\mathrm{lit}}^P=0
```
与项目极点方程
```math
1-4K_a\Pi_{ij,\mathrm{proj}}^P=0
```
严格等价。

## 3. 比对所用的三类来源

这里把文献分成三类角色：

1. 基础 RPA/NJL 锚点  
   用来确认 `1-2G\Pi` 这一基础写法是标准口径。代表：
   - Buballa 2004
   - Hansen et al. 2007

2. 三味 KMT/介子谱锚点  
   用来确认三味模型里 `1-4K_a\Pi_a` 也是标准写法。代表：
   - Aguirre and Lourenço 2024

3. 当前项目 lineage 直接祖先  
   用来确认 `B_0` 本体、三维 cutoff 处理、以及 `\Pi^P` 的工程写法。代表：
   - Rehberg and Klevansky 1995 hadronization
   - Rehberg and Klevansky 1995 BMP 技术文
   - Rehberg 1996 transport
   - Friesen et al. 2019
   - Blaschke et al. 2020

其中 Blaschke 2020 可用于 `I_1/I_2` 与 BU/BW 后续链路，但其传播子公式与后文 BW 极点条件存在内部因子不一致，因此**不应单独作为极点方程归一化的唯一锚点**。

## 4. 第一步：外部能量变量不是自由假设

这一步先把之前容易悬空的点钉死：这里并不存在“只要把外部能量变量约定对齐即可”的额外假设。

### 4.1 项目代码的定义

项目的 `B0` 组合函数在 [src/relaxtime/OneLoopIntegrals.jl](/C:/Users/Wmzx/.codex/worktrees/346c/Julia_RelaxTime/src/relaxtime/OneLoopIntegrals.jl:493) 明确写道：

```julia
"""
    B0(λ, k, m1, μ1, m2, μ2, T; Φ=0.0, Φbar=0.0)
根据文档公式组合四个 ̃B0 项得到完整的 B₀ 积分。
λ = k0 + μ1 - μ2, 其中k0是传播子能量
"""
```

因此项目中进入 `B0` 的外部能量组合不是模糊符号，而是**定义**
```math
\boxed{\lambda = k_0+\mu_1-\mu_2.}
```

### 4.2 文献里的写法

Friesen 2019 / Blaschke 2020 在静止系写赝标量极化函数时，动量相关部分都采用
```math
(\omega+\mu_{ij})^2-(m_i-m_j)^2
```
或 `P_0^2-(m_i-m_j)^2` 的形式；这里
```math
\mu_{ij}=\mu_i-\mu_j.
```

因此在当前项目的符号里，只需作**直接代入**
```math
P_0 \;\widehat{=}\; \lambda
=k_0+\mu_1-\mu_2,
```
这一步来自代码定义本身，不是额外归一化假设。

## 5. 第二步：A_\Lambda 与 I1 已经闭合

这一步是已闭合部分，但它对 `B0 ↔ I2` 的结论很关键。

若把项目中的单线积分按**与文献相同的 cutoff 口径**书写，则
```math
A_{\Lambda,i}
= -4\int_0^\Lambda dp\,\frac{p^2}{E_i}
\left[1-n_q(E_i)-n_{\bar q}(E_i)\right].
```

Blaschke 2020 给出的三味 PNJL 记号可写成
```math
I_1^i
= \frac{N_c}{4\pi^2}\int_0^\Lambda dp\,\frac{p^2}{E_i}
\left[1-f_\Phi^-(E_i)-f_\Phi^+(E_i)\right].
```

把 `f_\Phi^+=n_q`、`f_\Phi^-=n_{\bar q}` 代回，可直接得到
```math
\boxed{
I_1^i = -\frac{N_c}{16\pi^2}A_{\Lambda,i}
}.
```

这个关系同样与 Friesen 2019、Blaschke 2012、Aguirre and Lourenço 2024 所采用的 `I_1` / 凝聚写法兼容。

需要特别强调的是：当前项目代码里的 [`A(m, μ, T, Φ, Φbar, nodes_p, weights_p)`](</D:/Desktop/Julia_RelaxTime/src/relaxtime/OneLoopIntegrals.jl:527>) 并**不**强制把热分布部分截到 `\Lambda`；而默认的 `A` 自动构建路径 [`build_A_triplet(...; p_max=20.0)`](</D:/Desktop/Julia_RelaxTime/src/relaxtime/AFieldBuilder.jl:64>) / [`ensure_quark_params_has_A(...; p_max=20.0)`](</D:/Desktop/Julia_RelaxTime/src/relaxtime/AFieldBuilder.jl:83>) 也确实把热尾积分延伸到 `20\,\mathrm{fm}^{-1}`。

因此：

```math
I_1^i = -\frac{N_c}{16\pi^2}A_i
```

只有在 `A_i` 的数值实现也采用 `0\le p\le\Lambda` 的同 cutoff 节点时才是逐字严格的。若项目运行时使用了更长的热尾积分区间，则这里应理解为：

```math
I_1^i = -\frac{N_c}{16\pi^2}A_{\Lambda,i},
```

而不是对任意运行时 `A_i` 数值对象都无条件成立。

## 6. 第三步：从原始双传播子积分直接锁定 B0 与 I2

上一版说明里，`I_2 ↔ B_0` 是通过 `A/I_1` 与极化函数整体结构闭合出来的。那种推法可以作为一致性检查，但还不够“源头级严格”。这一节改用项目实际采用的技术祖先文献，把 `B_0` 和 `I_2` 都追到原始双传播子 Matsubara 积分。

### 6.1 项目所用 B0 的技术祖先

当前项目的 `B0` 不是后写出来的经验公式，而是直接承自 Rehberg/Klevansky 1995 的一圈积分技术路线：

- Rehberg and Klevansky, *Hadronization in the SU(3) Nambu–Jona-Lasinio model* (1995)
- Rehberg and Klevansky, *One Loop Integrals at Finite Temperature and Density* (BMP 技术文, 1995)

其中：

1. Rehberg 1995 hadronization 文中 Appendix A 把 `B_0` 定义为
```math
B_0(\vec k,m_1,\mu_1,m_2,\mu_2,i\nu_m)
=
\frac{16\pi^2}{\beta}\sum_n e^{i\omega_n\eta}
\int_{|\vec p|<\Lambda}\frac{d^3p}{(2\pi)^3}
\frac{1}{((i\omega_n+\mu_1)^2-E_1^2)}
\frac{1}{((i\omega_n-i\nu_m+\mu_2)^2-E_2^2)}.
```

2. BMP 技术文把同一个对象系统化地分解为四个 `\tilde B_0^\pm`，并显式定义
```math
\lambda = i\nu_m+\mu_1-\mu_2,
```
在解析延拓后成为实能量变量。

3. 当前项目代码 [src/relaxtime/OneLoopIntegrals.jl](/C:/Users/Wmzx/.codex/worktrees/346c/Julia_RelaxTime/src/relaxtime/OneLoopIntegrals.jl:498) 的 `B0` 与 `tilde_B0` 正是按 BMP 的 Eq. (4.7), (4.8) 逐项实现的。

因此，对当前项目而言：
```math
\boxed{
\text{项目中的 }B_0
\equiv
\text{BMP / Rehberg 1995 技术路线中的 }B_0
}
```
这件事已经不是“相似”或“可类比”，而是同一个原始对象。

### 6.2 I2 的原始定义

Blaschke 2012、Friesen 2019、Blaschke 2020 这一路文献把两线泡图更常写成
```math
I_2^{ij}(P_0)
= iN_c \int \frac{d^4p}{(2\pi)^4}
\frac{1}{(p^2-M_i^2)\bigl((p+P)^2-M_j^2\bigr)}.
```

也就是说，`I_2` 的本体就是**同一个双传播子圈图**，只不过：

- 文献侧保留了四维积分记号与整体 `iN_c`
- 项目/BMP 侧先转到 imaginary-time Matsubara 和三维 cutoff，再额外抽出了 `16\pi^2`

### 6.3 从原始定义直接得到归一化

把 `I_2` 转到 Matsubara 形式后，其积分核正是
```math
\frac{1}{((i\omega_n+\mu_1)^2-E_1^2)}
\frac{1}{((i\omega_n-i\nu_m+\mu_2)^2-E_2^2)}.
```

这与 BMP Eq. (2.2) / 项目 `B0` 的原始核逐字一致；差异只剩三部分：

1. 文献 `I_2` 带整体 `N_c`
2. BMP / 项目 `B_0` 额外定义了整体 `16\pi^2`
3. 从 Minkowski 四维积分到 imaginary-time Matsubara 再做 retarded continuation 时，当前项目口径对应一个整体负号

因此直接得到
```math
\boxed{
I_2^{ij}
= -\frac{N_c}{16\pi^2} B_0^{ij}
}.
```

这一步不再通过“极化函数要闭合，所以猜 `c` 应该是多少”的方式完成，而是由**原始双传播子积分定义**直接给出。

### 6.4 文献祖先链对“最后两条缺失信息”的补充

此前剩下的两条顾虑是：

1. 对方文献的 `I_2` 在有限 cutoff 下，是否和 BMP 一样使用三维 cutoff 与变量替换处理？
2. 对方文献的 retarded 解析延拓号约定，是否和 BMP 的 `-i\epsilon\,\mathrm{sgn}(\lambda)` 完全同向？

沿技术祖先链追溯后，可得到更强判断：

- **对当前项目这条 lineage，本质上已经补齐。**  
  Rehberg 1995 hadronization 文与 BMP 技术文使用的是同一个 `B_0` 定义；Rehberg 1996 输运论文又直接把这个 `B_0` 放进与当前项目同型的 `\Pi^P` 表达式。  
  因而对“当前项目推导口径”而言，不再缺失。

- **但对任一后续论文的“逐字完全同构”仍要保留限定。**  
  因为有些后续文献会直接写 `I_2` 的最终表达式，而不把：
  - cutoff 的变量替换细节，
  - retarded continuation 的 `i\epsilon` 指向，

  再完整重写一遍。  
  在这种情况下，我们只能说它们**沿用了这一技术传统**，而不能说每一篇都逐页重推并重新声明了所有中间约定。

### 6.5 极化函数闭合现在只作为交叉验证

有了上面的原始定义映射，再代回文献与项目的 `\Pi^P` 结构，就会自动得到
```math
\Pi_{ij,\mathrm{lit}}^P = 2\,\Pi_{ij,\mathrm{proj}}^P,
```
而这再与
```math
P_\pi = 2K_{123}^+,\qquad
P_K = 2K_{4567}^+
```
一起，重新给出相同的极点方程。

此时“极化函数整体闭合”只是一道反查，而不是主证明。

## 7. 第四步：为什么极点方程仍然完全一致

### 7.1 文献侧的赝标量极化函数

Friesen 2019 / Blaschke 2020 的 `\pi/K` 通道都写成
```math
\Pi_{ij,\mathrm{lit}}^P
= 4\left[
I_1^i + I_1^j
-\bigl(P_0^2-(M_i-M_j)^2\bigr) I_2^{ij}(P_0)
\right].
```

### 7.2 项目侧的赝标量极化函数

项目实现在 [src/relaxtime/PolarizationAniso.jl](/C:/Users/Wmzx/.codex/worktrees/346c/Julia_RelaxTime/src/relaxtime/PolarizationAniso.jl:19) 给出
```math
\Pi_{ij,\mathrm{proj}}^P
= -\frac{N_c}{8\pi^2}
\left[
A_i + A_j
-\bigl(\lambda^2-(m_i-m_j)^2\bigr) B_0^{ij}(\lambda,k)
\right].
```
其中在 `k=0` 极点问题里，`m_i` 与 `M_i` 只是同一条主线里的 constituent mass 记号差异，这里不再单独区分。

### 7.3 先比较 A/I1 部分

把
```math
I_1^i = -\frac{N_c}{16\pi^2}A_i
```
代入文献极化函数，其前两项变成
```math
4(I_1^i+I_1^j)
= -\frac{N_c}{4\pi^2}(A_i+A_j).
```

而项目中的对应部分是
```math
-\frac{N_c}{8\pi^2}(A_i+A_j).
```

因此，**仅看 A/I1 部分，文献极化函数就已经正好是项目极化函数的 2 倍**。

### 7.4 用原始定义映射代回 I2

把
```math
I_2^{ij}= -\frac{N_c}{16\pi^2}B_0^{ij}
```
直接代回文献侧动量项，得到
```math
\Pi_{ij,\mathrm{lit}}^P
= -\frac{N_c}{4\pi^2}
\left[
A_i+A_j
-\bigl(\lambda^2-(m_i-m_j)^2\bigr)B_0^{ij}
\right]
=2\,\Pi_{ij,\mathrm{proj}}^P.
```

因此这里的因子 2 已经是原始定义直接推出来的，不再依赖猜测。

### 7.5 文献中的有效耦合

Friesen 2019 对 `\pi/K` 通道使用
```math
P_\pi = g_S + g_D\langle\bar s s\rangle,\qquad
P_K = g_S + g_D\langle\bar u u\rangle.
```

### 7.6 项目中的有效耦合

项目当前实现中
```math
K_{123}^+ = G + \frac12 K G_s^{\text{helper}},
\qquad
K_{4567}^+ = G + \frac12 K G_u^{\text{helper}},
```
并且
```math
G = \frac{g_S}{2},\qquad
K = -g_D,\qquad
G_f^{\text{helper}}=-\phi_f=-\langle\bar q_f q_f\rangle.
```

因此直接代数化简可得
```math
\boxed{
K_{123}^+ = \frac{P_\pi}{2},\qquad
K_{4567}^+ = \frac{P_K}{2}.
}
```

### 7.7 极点方程闭合

文献写法：
```math
1-P_{ij}\Pi_{ij,\mathrm{lit}}^P=0.
```

把
```math
P_{ij}=2K_a,\qquad
\Pi_{ij,\mathrm{lit}}^P=2\Pi_{ij,\mathrm{proj}}^P
```
代入：
```math
1-(2K_a)(2\Pi_{ij,\mathrm{proj}}^P)=0
\quad\Longleftrightarrow\quad
1-4K_a\Pi_{ij,\mathrm{proj}}^P=0,
```
这正是项目当前的极点方程。

因此，当前项目与 Friesen 2019 的 `\pi/K` 极点条件在当前映射下是**严格一致**的。

## 8. 严格成立的前提条件

上面的 `B_0 \leftrightarrow I_2` 映射在以下前提下严格成立：

1. 使用 BMP / Rehberg 这条技术路线的双传播子 Matsubara 定义；
2. 使用三维动量 cutoff 正则化；
3. 使用和 BMP 一致的变量替换与 `\lambda=i\nu_m+\mu_1-\mu_2` 记号；
4. 使用同向的 retarded 解析延拓约定。

需要特别提醒的一点是，BMP 在对 Eq. (4.2) 的第三、四项做变量替换后，明确说明默认
```math
\Lambda \gg k,
```
因此没有同步移动 cutoff 边界。  
这属于当前技术口径的一部分。对当前项目和同 lineage 文献，这不是问题；但若切换到另一种 UV 正则化或显式移动 cutoff 边界的方案，就需要重新核对 `B_0` 的有限 cutoff 细节。

## 9. 家族 A 中的 G_M 与当前项目 K_a 的物理角色

这里还需要补一个容易混淆、但很关键的解释：

本文**不主张**
```math
G_M = K_a
```
是一个文献级恒等式；但从物理角色上看，二者确实属于同一类对象。

### 9.1 当前项目中的 K_a 是什么

在当前项目里，`K_a`（如 `K_{123}^+`, `K_{4567}^+`）不是裸的 `'t Hooft` 六费米耦合 `K`，而是**某个介子通道进入 RPA 分母的有效四费米耦合**。

例如对 `\pi` 通道，
```math
K_{123}^+ = G + \frac12 K G_s^{\text{helper}},
```
其中：

- `G` 是原始 NJL 四费米耦合；
- `K` 是裸的 `'t Hooft` 六费米耦合；
- `G_s^{\text{helper}} = -\phi_s = -\langle\bar s s\rangle`。

因此可改写为
```math
K_{123}^+ = G - \frac12 K \phi_s.
```

这说明 `K_a` 的物理含义是：

> 原始四费米耦合 `G`  
> 加上  
> KMT 六费米项在平均场/凝聚缩并后，为该介子通道诱导出的附加四费米修正。

也就是说，`K_a` 本身仍然应被理解为
```math
\boxed{\text{该介子通道的有效四费米耦合}.}
```

### 9.2 家族 A 中的 G_M 是什么

家族 A 的写法
```math
D_M \sim \frac{2G_M}{1-2G_M\Pi_M}
```
里的 `G_M`，其物理角色同样是：

```math
\boxed{\text{该介子通道直接进入 RPA 分母的有效四费米耦合}.}
```

所以从物理意义上看，家族 A 中的 `G_M` 与当前项目中的 `K_a` 是**同类对象**。

### 9.3 为什么仍不把它写成严格等式

虽然 `G_M` 与 `K_a` 在物理角色上同类，但本文不把它写成
```math
G_M = K_a
```
这样的严格文献映射，原因是：

- 家族 A 里的 `G_M` 依赖该文献对
  - flavor 因子、
  - bosonization / RPA 规范、
  - `\Pi_M` 归一化、
  - 可能的 `1/2` 或 Fierz 因子
  
  的具体吸收方式；
- 当前项目的 `K_a` 则是当前这套三味 + KMT 缩并口径下定义出来的通道有效耦合。

因此，稳妥的说法是：

```math
\boxed{
G_M \text{ 与 } K_a \text{ 具有相同的物理角色，但本文不主张单独的 } G_M=K_a \text{ 恒等式。}
}
```

真正进入传播子极点条件、且跨口径可比较的是分母组合项：
```math
2G_M\Pi_M^{(A)}
\quad\text{vs}\quad
4K_a\Pi_M^{\text{proj}}.
```

### 9.4 一个直观极限

若关掉 `'t Hooft` 六费米作用，
```math
K \to 0,
```
则当前项目中的通道有效耦合退化为
```math
K_a \to G.
```

这说明当前项目 `K_a` 与基础 NJL 通道耦合图像之间存在连续的物理联系；也正因如此，家族 A 的 `G_M` 可以从物理角色上被理解为与当前项目 `K_a` 同类的“通道有效耦合”。

## 10. 这能解释什么，不能解释什么

### 10.1 已经解释清楚的

1. 为什么项目的 `\Pi` 看上去比 Friesen/Blaschke 文献少一个 2。  
   答：`I_1/I_2` 到 `A/B_0` 的归一化和有效耦合 `P_{ij}` 到 `K_a` 的归一化一起重排了，最终极点方程不变。

2. 为什么 `K_{123}^+=P_\pi/2`、`K_{4567}^+=P_K/2` 不是拍脑袋约定。  
   答：这是由 `G=g_S/2`、`K=-g_D` 与 helper 变量 `G_f^{\text{helper}}=-\phi_f` 共同决定的代数结果。

3. 为什么这里不再需要“外部变量约定大致差不多”这种模糊说法。  
   答：因为 `\lambda=k_0+\mu_1-\mu_2` 在代码中是显式定义，而 `B_0` 本体可直接追溯到 BMP 的原始双传播子 Matsubara 积分。

4. 此前“还差的信息”是否已经补齐。  
   答：对当前项目 lineage，已经补齐；对某些不重述中间约定的后续论文，则仍应保留“沿用同一技术传统”的表述，而不是宣称其每一步都逐字完全同构。

5. 家族 A 中的 `G_M` 与当前项目 `K_a` 如何理解。  
   答：它们应视作同类的“通道有效四费米耦合”；但本文不把它们写成单独的严格文献恒等式。

### 10.2 仍需和本文分开处理的

1. Blaschke 2020 文内 `S_{ij}^M = 2P_{ij}/(1-4P_{ij}\Pi_{ij})` 与后文 BW 极点条件 `1-2P_{ij}\Pi_{ij}=0` 的内部不一致。  
   这不是 `B_0 ↔ I_2` 映射能解决的问题，而是该文自身的因子漂移。

2. 严格复能量 continuation 下，`B_0(\lambda+i\Gamma/2)` 与文献 `I_2(z_M)` 的分支选择、主值路径和宽度实现。  
   这属于 strict BW / full BU 口径，不属于本文的实数路径归一化说明。

## 11. 对当前仓库文档层的建议
