# Issue #130 phase-surface render v8

This is a display-only successor to the v1 phase-reference render. The strict and derived tables are immutable inputs. Crossover endpoints may be connected to the estimated CEP midpoint for display, while the first-order (Maxwell) surface is built only from adjacent xi slices with common temperature support. No T=0 extrapolation or triangulation is used. The stable public PNG alias is intentionally written to the existing phase-reference figure path; the previous v1 source figure remains preserved under the v1 analysis package.
