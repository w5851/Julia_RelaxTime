## 结论与修复

原 `:rs_reduced_adaptive` 在费米动量处分段，但以压强值估计误差。
很窄的热窗口可能在初始节点之间被漏掉；即使压强已收敛，导数仍可能明显错误。
更密的窗口能解决遗漏，但直接对尖锐分布求高阶导数还会产生大项相消。

本次实现三项改进：

1. 正温积分按 `E-|mu|` 的热宽度安排初始分段，覆盖费米面两侧及 `|mu|≈M`。
2. 求积误差范数包含 ForwardDiff / TaylorDiff 携带的导数分量，统一控制有限段面板。
3. 强简并区 `|mu|-M > 64T` 使用解析费米海加完整热修正，以
   `E=|mu|±Ty` 积分中央窗口；上下剩余区和反粒子项均保留。

第三项利用恒等式。定义 `f(y;Phi,Phibar)=1+3Phi*exp(-y)+3Phibar*exp(-2y)+exp(-3y)`，则

\[
\log f(-y;\Phi,\bar\Phi)=3y+\log f(y;\bar\Phi,\Phi).
\]

解析提取费米海后，化学势导数主要作用于平滑的相空间测度，避免在宽度趋零的分布上
形成很大的正负数值项。这是对原积分的恒等重写，未截断为 Sommerfeld 级数。

同时补齐 `thermo_quadrature_kwargs` 从基态 context、gap 残差、Jacobian、Taylor
递推到最终压强的传递，覆盖质量、热力学、体黏滞组合及纯 B/Q/S 方向响应。
`mass_derivatives` 改用模型自身的质量公式，修复旧辅助函数硬编码
`m_s0=140 MeV` 与默认模型 `140.7 MeV` 不一致的问题。

默认张量 Gauss、PALC、混合介子及输运积分实现保持原设置；本次没有重算生产相图或输运图件。

固定态取质量 `(1.5,1.5,2.5) fm^-1`、`Phi=Phibar=0.1`；切换邻域另用
`Phi=0.12, Phibar=0.28`。求积 `rtol=1e-6,1e-8,1e-10`，`atol=rtol*1e-3`，
`maxevals=200000`。独立 oracle 在原 q 积分上使用不同的能量窗口与固定节点；
近零温四阶响应使用 192 位精度、96→128 节点及 56T→72T 尾部自收敛。

自洽序列从较高温度的解向低温延续，同点比较锁定该分支。它检验同支响应的数值精度，
相稳定性选择仍沿用实际物理计算的分支规则。T=60 MeV 的某些 bulk 比值为负，
这里的收敛核验不将其解释为新的稳定性结论。

内部温度和化学势均为 `fm^-1`，下表的 `P^(n)` 是对共同夸克化学势的 n 阶导数，
单位 `fm^(n-4)`；重子方向另有 `3^-n` 因子。

## 精确零温与近零温的解释

- 固定态 `T=0` 压强、净密度及化学势导数使用解析费米海。`|mu|<M` 时为零，
  `|mu|>M` 时与高精度解析结果一致；`mu=M>0` 附近的压强按
  `(mu-M)_+^(5/2)` 起始，零至二阶导数存在，三阶及更高阶应讨论单侧极限。
- PR3 核验时五场 PNJL 在 `T=0` 的 Polyakov 方向退化，自洽入口要求正温。
  当时用 `0.01,0.1,1 MeV` 检查趋零行为，精确零温采用固定态；下节补充约化自洽入口。
- `chi_n^B=T^(n-4)P_mu_q^(n)/3^n`。有限的二阶有量纲响应可以伴随
  `chi2_B ~ T^-2`；核验零温时先比较有量纲导数。
- 稀薄分支 `mu_q=1.25 fm^-1` 在近零温的密度小于浮点/误差可分辨尺度，
  部分 bulk 比值呈 `NaN` 或对微小量敏感的有限值。结果保留这些值并标为
  `vanishing_density_ratios_unqualified`，其比值不纳入精度结论。

## 固定网格与成本

在同一稠密平均场上比较 24、96、384 个动量节点和 16 个角节点。
`T=60 MeV` 时 384 点与自适应结果接近；`T=5 MeV` 的高阶响应仍明显漂移；
`T=0.01 MeV` 的固定节点可能完全漏掉窄费米面，或给出很大的伪高阶响应。
因此对这类低温消费者，单纯提高全区间节点数的效率有限。

本次预热后三次取最短耗时，在 4 个固定态上同时计算 mu_q 零至四阶和 T 一至二阶：
自适应约 `0.1–0.5 ms`，384×16 张量约数 `ms`。这是核级对照且精度不同，
不据此推断完整扫描或输运链路的加速比。原始计时保存在摘要中。

## 严格零温自洽入口与性能补充

### 方程与选支

`Models.solve_gap(model::PNJLModel, 0.0, mu_vec)` 现在对
`Omega_chiral + Omega_vacuum - P_Fermi` 求三个手征驻点。真空与费米海项使用
既有闭式表达式，内部采用三维梯度和 Jacobian；返回 `MeanFieldState` 中的
`Phi=PhiBar=0` 为零温退化方向的占位。后处理直接调用 `model_pressure`、
`number_densities` 和 `model_rho`。完整合同及例子见
[零温接口](../../../api/models/solver/Overview.md#pnjl-的严格零温入口)。

默认候选使用既有真空、高密与高温初值的不同手征部分，在质量为正且手征 Hessian
半正定的收敛解中选择最低 `Omega`。新增高密候选有直接数值依据：原高温目录
的部分手征初值在低温多解区会落到中间鞍点，高密初值保留较大的 s 味凝聚，
可到达另一局部极小值。显式初值保持单分支驻点语义，支持亚稳及不稳定支的研究。

在 `mu_q=1.85 fm^-1` 的测试中，两支局部极小值及中间鞍点均被求出，
默认选择较低势的高密支。有限候选搜索延续项目现有的选支方式；相边界研究
仍应跟踪候选分支及其竞争，而不能从一次单点求根判断整个相结构。

### 独立零温与趋零结果

五组点为 `mu_q=1.25,1.8,2.2 fm^-1`，稠密点另取 `xi=±0.3`。
零温独立求解；正温从 `60 MeV` 向 `20,5,1,0.1,0.01 MeV` 延续，
在同一分支上做残差精修。独立参考对原径向 `E(q)` 和 `M/E(q)` 进行
128/192 阶 Gauss 积分，避免重复使用闭式表达式及其导数。

- 解析默认零温解的独立积分残差最大约 `1.4e-12`；压强差小于 `6e-12 fm^-4`。
  两档参考节点的压强差小于 `3e-14 fm^-4`。剩余差异与既有真空公式的
  `|M|+1e-12` 正则化量级一致。
- `mu_q=1.25 fm^-1` 的稀薄态保持真空凝聚，密度趋零。
- 稠密态质量、压强与密度趋近各自分支的零温解。在上述代表点，降温十倍时
  偏差约缩小百倍，符合主导 `T^2` 修正。
- 同时计算三维场方程的隐式质量响应和总压强二阶化学势响应，并用三个步长
  在邻近化学势重新求同一零温分支核对，误差随步长减小而收敛。

例如 `mu_q=2.2 fm^-1, xi=0`，相对独立零温解：

| T / MeV | 最大质量绝对偏差 / fm^-1 | 压强绝对偏差 / fm^-4 | 密度最大相对偏差 |
| --- | ---: | ---: | ---: |
| 1 | 3.63e-7 | 1.39e-5 | 5.96e-6 |
| 0.1 | 3.57e-9 | 1.38e-7 | 5.86e-8 |
| 0.01 | 3.56e-11 | 1.38e-9 | 5.85e-10 |

该点零温总 `P_mu_q^(2)=2.95894643248612 fm^-2`，与 PR3 的
`T=0.01 MeV` 值 `2.95894643303504 fm^-2` 连续接近。

`mu_q=1.8 fm^-1` 需要区分选支：PR3 从 60 MeV 延续下来的小质量支，
趋近零温亚稳局部极小值 `M_u=0.3232483837 fm^-1`；默认零温选中的稳定态
是 `M_u=1.8631423323 fm^-1` 的真空支。二者压强分别为
`21.5732546243` 与 `21.6080207230 fm^-4`。这解释了跨分支比较的差异；
同支的质量、密度和响应趋零一致。

### 计时口径与结果

`quote-remote`：i5-14400F，Julia 1.12.5，Julia/OpenBLAS 各一线程，进程固定
CPU 0（实测 affinity=1），每项 30 个样本，报告预热后中位数。初次未固定核心
的预跑出现明显调度波动，最终表格使用固定核心复测。
Julia 启动与 JIT 不计入表内。

各正温均用同一自适应策略 `rtol=1e-8, atol=1e-11, maxevals=200000`；
严格零温使用解析分支。积分表固定 `M=(1.5,1.5,2.5) fm^-1`、
`mu_q=1.8 fm^-1`、`Phi=PhiBar=0.1`，只改变温度。
“零至四阶”一次返回压强及其共同夸克化学势零至四阶导数。

| T / MeV | 热压强积分 / us | 零至四阶响应 / us |
| --- | ---: | ---: |
| 0 | 0.2 | 1.4 |
| 0.01 | 25.1 | 98.5 |
| 0.1 | 26.6 | 96.0 |
| 1 | 77.9 | 384.8 |
| 5 | 34.6 | 203.4 |
| 60 | 33.5 | 110.4 |
| 150 | 34.0 | 113.4 |
| 250 | 33.6 | 85.0 |

近零温没有因热窗口继续收窄而持续变慢。`T=1 MeV` 代表点位于
`(|mu|-M)/T≈59.2`，尚未进入 `>64` 的解析海重写区，直接窗口积分的高阶
误差控制需要更多细分，所以成本高于更低温。零温只代入闭式表达式，
进一步省去正温热修正积分。亚微秒计时主要用于说明数量级。

完整求解固定 `mu_q=2.2 fm^-1, xi=0`，初值统一为收敛态各非零分量的
`1.02` 倍；初值构造不计时，表内每次都实际重新求根。单初值各温度需要
3–4 次 Newton 迭代；默认选解另测现有目录搜索及候选比较。

| T / MeV | 单初值求解 / ms | 默认目录选解 / ms |
| --- | ---: | ---: |
| 0 | 0.0089 | 0.268 |
| 0.01 | 0.959 | 11.4 |
| 0.1 | 1.07 | 12.1 |
| 1 | 1.16 | 13.6 |
| 5 | 1.26 | 16.7 |
| 60 | 2.00 | 26.5 |
| 150 | 2.82 | 401 |
| 250 | 2.82 | 1103 |

在这一对照下，零温单初值求解比 `0.01 MeV` 快约 108 倍，比普通温度
`60–250 MeV` 快约 225–317 倍。零温成本减少同时来自解析积分与五维到三维
的约化；不能仅解释为同一五维求解器的加速。

正温的大部分单初值成本在 Jacobian/根求解，零温 Jacobian 从
约 `0.27–0.58 ms` 降至 `1.8 us`。高温默认目录明显更慢是初值搜索的额外成本，

并未重跑完整相图或输运计算，也不代表默认张量积分生产链的温度性能。
