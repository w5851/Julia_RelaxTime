# PR3：零温与低温消费者的积分精度

2026-11-13 完成代表点核验。计算在 `quote-remote` 执行，Julia 1.12.5，
Julia / OpenBLAS 各一线程。范围由作者确定为实际低温消费者及目标导数，包含精确零温，
并以 PALC 优化交付后的 `abe6dd2b` 为实现起点。

## 结论与修复

原 `:rs_reduced_adaptive` 在费米动量处分段，但以压强值估计误差。
很窄的热窗口可能在初始节点之间被漏掉；即使压强已收敛，导数仍可能明显错误。
更密的窗口能解决遗漏，但直接对尖锐分布求高阶导数还会产生大项相消。

本次实现三项改进：

1. 正温积分按 `E-|mu|` 的热宽度安排初始分段，覆盖费米面两侧及 `|mu|≈M`。
2. 求积误差范数包含 ForwardDiff / TaylorDiff 携带的导数分量，统一控制有限段面板。
3. 强简并区 `|mu|-M > 64T` 使用解析费米海加完整热修正，以
   `E=|mu|±Ty` 积分中央窗口；上下剩余区和反粒子项均保留。

第三项利用恒等式。定义 `f(y;Phi,Phibar)=1+3Phi*exp(-y)+3Phibar*exp(-2y)+exp(-3y)`，则

\[
\log f(-y;\Phi,\bar\Phi)=3y+\log f(y;\bar\Phi,\Phi).
\]

解析提取费米海后，化学势导数主要作用于平滑的相空间测度，避免在宽度趋零的分布上
形成很大的正负数值项。这是对原积分的恒等重写，未截断为 Sommerfeld 级数。

同时补齐 `thermo_quadrature_kwargs` 从基态 context、gap 残差、Jacobian、Taylor
递推到最终压强的传递，覆盖质量、热力学、体黏滞组合及纯 B/Q/S 方向响应。
`mass_derivatives` 改用模型自身的质量公式，修复旧辅助函数硬编码
`m_s0=140 MeV` 与默认模型 `140.7 MeV` 不一致的问题。

默认张量 Gauss、PALC、混合介子及输运积分实现保持原设置；本次没有重算生产相图或输运图件。

## 范围与口径

| 层次 | 代表点 | 目标量 |
| --- | --- | --- |
| 固定平均场，35 点 | T=0、0.01、0.1、1、5、20、60 MeV；mu_q=1.25、1.5、1.8 fm^-1；稠密点 xi=0、±0.3 | 热压强及 mu_q 一至四阶、T 一至二阶导数 |
| 自洽平均场，30 点 | 正温六档；mu_q=1.25、1.8、2.2 fm^-1；mu_q=2.2 另取 xi=±0.3 | 平均场、质量响应、净密度、压强总导数、chi2_B、chi4_B、bulk 组合 |
| 独立复核，11 项 | 4 个张量网格对照、4 个同支总导数对照、3 个高精度 oracle 自收敛 | 节点误差、求解误差、四阶差分及 64T 切换邻域 |

固定态取质量 `(1.5,1.5,2.5) fm^-1`、`Phi=Phibar=0.1`；切换邻域另用
`Phi=0.12, Phibar=0.28`。求积 `rtol=1e-6,1e-8,1e-10`，`atol=rtol*1e-3`，
`maxevals=200000`。独立 oracle 在原 q 积分上使用不同的能量窗口与固定节点；
近零温四阶响应使用 192 位精度、96→128 节点及 56T→72T 尾部自收敛。

自洽序列从较高温度的解向低温延续，同点比较锁定该分支。它检验同支响应的数值精度，
相稳定性选择仍沿用实际物理计算的分支规则。T=60 MeV 的某些 bulk 比值为负，
这里的收敛核验不将其解释为新的稳定性结论。

内部温度和化学势均为 `fm^-1`，下表的 `P^(n)` 是对共同夸克化学势的 n 阶导数，
单位 `fm^(n-4)`；重子方向另有 `3^-n` 因子。

压强差异很小，而二阶响应原值约少一半，高阶响应已失真。
修复后的近零温四阶结果与高精度原积分的绝对差异约 `7e-15`。

整个固定态矩阵的最大参考差异为 `3.9e-9`，三档求积设置的最大差异为 `2.3e-11`；
这里统一使用 `abs(a-b)/max(abs(b),1e-9)`，以免对趋零量报告失真的相对误差。
自洽消费者同口径最大差异 `3.6e-11`，最大基态残差 `9.2e-12`，
总压强一阶导数与直接净密度的最大绝对差异 `2.1e-12 fm^-3`。
这些是代表点的观测精度，非任意参数和任意阶数的统一误差保证。

最大的 `v_n_sq` 绝对变化约 `6.2e-11`。在邻近参数点重新求同一分支、直接积分密度，
然后对密度做三阶有限差分，独立核对压强四阶总响应：

| T / MeV | mu_q / fm^-1 | Taylor P^(4) | 最佳差分相对差异 |
| --- | ---: | ---: | ---: |
| 60 | 2.2 | 31.06314354 | 6.6e-8 |
| 5 | 2.2 | 1.82456098 | 8.1e-7 |
| 0.01 | 2.2 | 1.81600540 | 6.1e-8 |

## 精确零温与近零温的解释

- 固定态 `T=0` 压强、净密度及化学势导数使用解析费米海。`|mu|<M` 时为零，
  `|mu|>M` 时与高精度解析结果一致；`mu=M>0` 附近的压强按
  `(mu-M)_+^(5/2)` 起始，零至二阶导数存在，三阶及更高阶应讨论单侧极限。
- 五场 PNJL 在 `T=0` 的 Polyakov 方向退化，现有自洽入口仍要求正温。
  本次用 `0.01,0.1,1 MeV` 检查趋零行为，精确零温核验采用固定态。
- `chi_n^B=T^(n-4)P_mu_q^(n)/3^n`。有限的二阶有量纲响应可以伴随
  `chi2_B ~ T^-2`；核验零温时先比较有量纲导数。
- 稀薄分支 `mu_q=1.25 fm^-1` 在近零温的密度小于浮点/误差可分辨尺度，
  部分 bulk 比值呈 `NaN` 或对微小量敏感的有限值。结果保留这些值并标为
  `vanishing_density_ratios_unqualified`，其比值不纳入精度结论。

## 固定网格与成本

在同一稠密平均场上比较 24、96、384 个动量节点和 16 个角节点。
`T=60 MeV` 时 384 点与自适应结果接近；`T=5 MeV` 的高阶响应仍明显漂移；
`T=0.01 MeV` 的固定节点可能完全漏掉窄费米面，或给出很大的伪高阶响应。
因此对这类低温消费者，单纯提高全区间节点数的效率有限。

本次预热后三次取最短耗时，在 4 个固定态上同时计算 mu_q 零至四阶和 T 一至二阶：
自适应约 `0.1–0.5 ms`，384×16 张量约数 `ms`。这是核级对照且精度不同，
不据此推断完整扫描或输运链路的加速比。原始计时保存在摘要中。
