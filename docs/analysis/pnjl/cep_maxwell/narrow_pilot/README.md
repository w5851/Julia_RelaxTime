# Narrow CEP Pilot Evidence

This group contains the two versioned narrow-window CEP pilot packages:

- `cep_narrow_pilot_v1/`: the earlier diagnostic-only pilot with an inconclusive oracle gate.
- `cep_narrow_pilot_v2/`: the three-state contract pilot with stable oracle evidence and a separate author-review boundary.

The versions share a research line but have different calculation SHAs, contracts, gates, and evidence tables. They remain separate provenance nodes; this directory only groups them physically.

Neither package promotes a CEP to reference or authorizes production, phase-reference replay, or transport.
