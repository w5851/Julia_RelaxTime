# PALC 路径复用与校正成本

当前状态：实现与远端分项验证中（2026-11-12）。基准为 PR #345 的端点 PALC 与自然密度连续扫描。

本轮比较相邻温度的端点初值、NLsolve 工作区复用、单调段内三次目标预测，以及 PALC ForwardDiff Jacobian。复用初值仍在新参数下重新校正，失败沿用原恢复路径。全部候选根、硬约束、最大压力选态和原容差共同验收。

数值入口：`scripts/analysis/pnjl_bifurcation_spike/run_path_reuse_comparison.jl`。同一进程轮换方法，记录预热后的耗时、分配、残差/Jacobian 调用与迭代数。重点覆盖 T=120 MeV 三根区及细 Tμ 路径，再检查密度、约束温度路径和实际扫描消费者。

远机首轮 4 条代表路径的全部根与热力学比较通过，含细 Tμ 的 111 根。局部 Newton 校正先检查残差，减少终止点上额外的 Jacobian；最终选项与默认值等待 Actions 同机分项及升降温对照。

磁场验证由独立对话负责；本轮完成后继续 PR3 的实际低温消费者及目标导数核验。
