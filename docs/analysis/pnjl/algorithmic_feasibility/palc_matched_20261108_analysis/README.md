## 工作量和判据

- PNJL，`xi=0, u/d=0.876, s_target=0, p_num=8, t_num=4`。
- `T=120 MeV`：`rho/rho0=0.30:0.025:0.40`；`T=130 MeV`：`0.75:0.025:0.85`，按密度下降顺序。
- PALC、SeedContinuation、独立逐点 `solve_multi`、组合扫描 equilibrium 各求 5 个目标点；
  半步长 SeedContinuation 求 9 点，作为路径步长敏感性参考。
- 相同 tensor quadrature，最终检查显式残差无穷范数和密度误差 `<=1e-6`、热力学有限性、
  正质量与 Polyakov-loop 范围。状态距离 `<=1e-4`、压力差 `<=1e-6 fm^-4` 判为同点一致。
- PALC 从 catalog 与高密度路径发现 anchor，逐支双向延拓，随后在目标 rho 上重新求解并选最大压力。
  邻近/线性插值的延拓点只作 seed。首次调用和两次 warm 均重新发现 anchor，未复用前轮结果。

`8 x 4` 是小规模算法诊断的离散方程。这里的半步长参考不是独立积分 oracle，
也未据此改写已接受的相图、输运或介子数密度结果。

## 同点结果和分支差异

| 检查 | 120 MeV | 130 MeV（完整重跑） |
| --- | --- | --- |
| SeedContinuation / 生产 equilibrium | 5/5 一致 | 5/5 一致 |
| PALC / 半步长参考 | 5/5 一致 | 5/5 一致 |
| PALC 最大显式残差 | `7.53e-10` | `2.47e-10` |
| PALC / 半步长最大状态距离 | `8.62e-10` | `2.10e-10` |
| PALC / 半步长最大压力差 | `1.11e-10 fm^-4` | `4.83e-11 fm^-4` |
| 五种方法全部同点一致 | 否 | 是 |

**120 MeV、rho=0.375：**SeedContinuation/生产式扫描选中 `P=18.137943271 fm^-4` 的根，
PALC、独立 `solve_multi` 和半步长参考选中 `P=21.639255076 fm^-4` 的根。
两类结果均通过残差检查；相差约 `3.50131 fm^-4`，不是容差内的微小漂移。
该差异在两个 Actions 批次中复现。

**130 MeV、rho=0.75：**首轮独立 `solve_multi` 选中 `P=18.174705299 fm^-4` 的根，
SeedContinuation/生产式/半步长为 `21.667231076 fm^-4`；完整重跑时独立 `solve_multi`
也选中后者。两个提交间数值实现相同，修改为依赖预热和汇总；该反例说明现有分支选择还存在
跨运行敏感性。每个进程内三次结果均稳定，当前证据尚未区分库/runner 环境和残差舍入顺序的贡献。

代码层可见的机制是：外层按压力选择，内层 `_solve_constraint_fixedasymrho` 每次也遍历
catalog，并按最小残差只返回一个根。已收敛高压力根可能在抵达外层选择器前被舍弃；
增加 previous seed 也可能改变各内层赢家。先保留全部合格根、随后统一压力选择，是有价值的
后续验证方向；本次未改变这条生产语义。

### T=120 MeV 的一阶相变背景

T=120 MeV 位于本项目关注的一阶相变温区。分支并存、亚稳延拓和跨相跳转需要保留，
不能把所有路径依赖都归为求解失败。这里发现的实现问题更具体：内层残差排序可能使
外层选择器看不到已经求得的其它合格根，因而未完整执行约定的候选选择。

本 pilot 沿用现有最大压力策略作算法对照。在固定密度与味道约束下，不同根的化学势不同，
压力排序本身不足以判定物理平衡态；均匀候选应同时检查 Helmholtz 自由能密度
`f = -P + sum(mu_i * n_i)`，相共存还涉及全局自由能的凸化与守恒约束。
例如已有 T=120、rho/rho0=0.35 两根的 `(mu_u, mu_d)` 分别约为 `(291, 299)` 与
`(520, 530) MeV`，由约束密度算得 `f` 约为 `-21.3862` 与 `-17.6886 fm^-4`。
此处较高压力根也有较低的均匀态自由能，但两根并非同化学势下的等压共存对。
这些数值仅描述当前 `8 x 4` 离散方程；下一阶段同时记录各根的化学势、自由能和分支，
在相同候选选择规则下评价算法，而不预设分支一定连续或用插值消除相变跳转。

生产式 parity 覆盖 downstream 介子步骤成功时的 equilibrium 序列。未运行介子谱或密度，
也未模拟介子步骤失败时生产脚本保留旧 seed 的分支。

## 成本

同一 case 的五种方法使用同一 runner、单 Julia/BLAS 线程和独立进程。
预先加载相同依赖，随后每进程单独计加载、首次调用和两次 warm；首次调用含剩余 JIT。

| 方法 | 120 首次调用 / s | 120 warm 中位 / s | 130 首次调用 / s | 130 warm 中位 / s |
| --- | ---: | ---: | ---: | ---: |
| PALC（含 anchor 与同点校正） | 22.997 | 0.818 | 20.674 | 0.380 |
| SeedContinuation | 15.873 | 1.874 | 13.843 | 1.115 |
| 独立 solve_multi | 15.745 | 1.770 | 13.377 | 0.998 |
| 生产 equilibrium | 15.545 | 1.955 | 13.922 | 1.051 |
| 半步长参考（9 点） | 17.131 | 3.591 | 15.301 | 2.068 |

130 MeV 完整重跑的相同结果下，Seed/PALC warm 成本比为 **2.93**。120 MeV 保留各自耗时，
由于分支结果不同，不给生产可替换意义的加速比。只有两次 warm，不能外推到长扫描或其它节点数。
首次调用 PALC 更慢；其加载约 22–23 s，短任务中应考虑这部分开销。

PALC anchor 阶段占最后一次 warm 的约 98.5% / 97.4%，延拓加同点校正仅约 0.012 / 0.009 s。
五方法全部三轮的进程总成本分别为 4.73 / 4.35 runner-minutes，包含各自加载；

首轮 `42477523346` 的 130 MeV PALC 在依赖预编译中触及 480 s 进程限时，尚未输出数值结果。
