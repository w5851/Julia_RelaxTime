### 一阶相变与候选解释

T=120 属于一阶相变温区，但首阶段的两个低密度数值根不是已验证的物理共存对。
在 `rho/rho0=0.375` 和 `0.75` 的已知反例中，低压力根均违反项目已有 `m_s > m_u`
筛选条件。原内层先按残差只返回一个根，可能丢掉合格根；外层随后只能回报被拒绝的根。
首阶段仅依据 `converged`、正质量、Polyakov 范围和残差验收，漏核这条层级条件，现已纠正。
新策略保留这些数值根供诊断，在原硬约束中排除它们；全部候选被拒绝时返回 `converged=false`。

已有对称组成相图在 T=120 的共存密度约为 `0.963–2.503 rho0`，用于选择补充扫描范围；
它与本任务的 `u/d=0.876, n_s=0` 约束不同，不直接移植端点。
本批进一步扫描 `rho/rho0=0.6:0.1:3.0`、T=120、24×8，锚点 1.8，半步长 49 点。
全部新方法在 25 个同点上一致，最大状态距离 `1.22e-8`。
固定组成路径的共轭化学势
`mu_path = 3*(0.876*mu_u + mu_d)/(1+0.876)` 在约 `1.2–2.1 rho0` 下降，
从约 947.6 降到 938.1 MeV，保留了均匀解的负斜率区段。此为机械不稳定分支的有限网格信号，
说明算法能够继续跟踪回弯；热力学两相混合态仍需自由能凸化与守恒约束。
PALC/Seed 对均匀根的数值一致性不等于完成了 Maxwell/Gibbs 相共存构造。

### T=120 MeV 的一阶相变背景

T=120 MeV 位于本项目关注的一阶相变温区。分支并存、亚稳延拓和跨相跳转需要保留，
不能把所有路径依赖都归为求解失败。这里发现的实现问题更具体：内层残差排序可能使
外层选择器看不到已经求得的其它合格根，因而未完整执行约定的候选选择。

本 pilot 沿用现有最大压力策略作算法对照。在固定密度与味道约束下，不同根的化学势不同，
压力排序本身不足以判定物理平衡态；均匀候选应同时检查 Helmholtz 自由能密度
`f = -P + sum(mu_i * n_i)`，相共存还涉及全局自由能的凸化与守恒约束。
例如已有 T=120、rho/rho0=0.35 两根的 `(mu_u, mu_d)` 分别约为 `(291, 299)` 与
`(520, 530) MeV`，由约束密度算得 `f` 约为 `-21.3862` 与 `-17.6886 fm^-4`。
此处较高压力根也有较低的均匀态自由能，但两根并非同化学势下的等压共存对。
进一步将已存状态代入当前质量公式，两个 anchor 的 `(m_u, m_s)` 约为 `(338, 536)` 与
`(638, 352) MeV`；后一数值根被现有质量层级条件排除。T=130 对应为 `(299, 520)` 与
`(620, 321) MeV`，也有同样问题。因此目前这组数值双根并不能作为两条物理共存分支的证据。
这些数值仅描述当前 `8 x 4` 离散方程；下一阶段同时记录各根的化学势、自由能和分支，
在相同候选选择规则下评价算法，而不预设分支一定连续或用插值消除相变跳转。

生产式 parity 覆盖 downstream 介子步骤成功时的 equilibrium 序列。未运行介子谱或密度，
也未模拟介子步骤失败时生产脚本保留旧 seed 的分支。
