#### 回弯、投影与真正分叉

锚点是满足 F(x,lambda)=0 的完整状态与参数对，不只是指定的 lambda 或未收敛初值。
同一等温线在 rho-mu 和 P-mu 图上的投影可不同；P-mu 上压力相等但密度不同的交点
对应不同状态。固定 T、xi，沿驻点分支 dP=nB dmuB=3nB dmuq，因此 mu 的普通折点也使
压强投影的参数导数为零，形成尖点时完整解曲线仍可能正则。

从同一正则连通曲线上的任一已收敛非奇异起点，理想的双向 PALC 可沿曲线经过简单折点。
实际覆盖还受初值收敛、参数范围、步长与最大步数限制；仅请求一个参数点的当前入口
只保留锚点。分叉 F=x(x^2-lambda)=0 在原点有多条切向，当前 detect_bifurcation=0 的
配置不会自动枚举其它分支。T-mu 相图的共存线、spinodal 线和 crossover 线是从不同条件
提取的轨迹，不能将其视觉上的汇合直接当成单参数求根曲线的分叉。

### 提速来自哪些工作量变化

早期单点、单初值求解的成本不能直接作为当前扫描的基准：当前扫描还搜索竞争根并进行
硬约束和压力选择。`single_pass` 消除重复的种子遍历；PALC 把多数点的重新搜索改为
少数锚点的多初值发现、分支延拓和目标校正。

本批 Tμ 的 single_pass 共启动 19,440 次根求解；PALC 为 1,952 次，其中锚点搜索
1,620 次、目标校正 332 次、fallback 0 次，另有 551 个延拓点及 8,646 次延拓残差调用。
因此主要收益确实包含减少多初值搜索。PALC 单步还要解增广系统，并非每次 Newton 本身
必然更快；短路径上的锚点和初始化成本可能更高。

数学上一个已收敛根可以启动一条连通解曲线的 PALC，包括其中的回弯。生产上仍保留
中点/两端多初值搜索，因为单条曲线不能保证覆盖其它不连通分支；稳定态仍需比较候选压力。
这些数据未将“分支复用”与“伪弧长相对普通预测校正”的贡献单独拆分，不能把全部收益
归因于伪弧长参数化本身。其它约束模式的当前能力见
[求解入口总览](../../../../api/models/solver/Overview.md#已实现的约束模式与路径支持)。

### 一阶相变与候选解释

T=120 属于一阶相变温区，但首阶段的两个低密度数值根不是已验证的物理共存对。
在 `rho/rho0=0.375` 和 `0.75` 的已知反例中，低压力根均违反项目已有 `m_s > m_u`
筛选条件。原内层先按残差只返回一个根，可能丢掉合格根；外层随后只能回报被拒绝的根。
首阶段仅依据 `converged`、正质量、Polyakov 范围和残差验收，漏核这条层级条件，现已纠正。
新策略保留这些数值根供诊断，在原硬约束中排除它们；全部候选被拒绝时返回 `converged=false`。

已有对称组成相图在 T=120 的共存密度约为 `0.963–2.503 rho0`，用于选择补充扫描范围；
它与本任务的 `u/d=0.876, n_s=0` 约束不同，不直接移植端点。
本批进一步扫描 `rho/rho0=0.6:0.1:3.0`、T=120、24×8，锚点 1.8，半步长 49 点。
全部新方法在 25 个同点上一致，最大状态距离 `1.22e-8`。
固定组成路径的共轭化学势
`mu_path = 3*(0.876*mu_u + mu_d)/(1+0.876)` 在约 `1.2–2.1 rho0` 下降，
从约 947.6 降到 938.1 MeV，保留了均匀解的负斜率区段。此为机械不稳定分支的有限网格信号，
说明算法能够继续跟踪回弯；热力学两相混合态仍需自由能凸化与守恒约束。
PALC/Seed 对均匀根的数值一致性不等于完成了 Maxwell/Gibbs 相共存构造。

| --- | --- | --- |
| SeedContinuation / 生产 equilibrium | 5/5 一致 | 5/5 一致 |
| PALC / 半步长参考 | 5/5 一致 | 5/5 一致 |
| PALC 最大显式残差 | `7.53e-10` | `2.47e-10` |
| PALC / 半步长最大状态距离 | `8.62e-10` | `2.10e-10` |
| PALC / 半步长最大压力差 | `1.11e-10 fm^-4` | `4.83e-11 fm^-4` |
| 五种方法全部同点一致 | 否 | 是 |

**120 MeV、rho=0.375：**SeedContinuation/生产式扫描选中 `P=18.137943271 fm^-4` 的根，
PALC、独立 `solve_multi` 和半步长参考选中 `P=21.639255076 fm^-4` 的根。
两类结果均通过残差检查；相差约 `3.50131 fm^-4`，不是容差内的微小漂移。
第二阶段明确低压力根违反现有质量层级规则；生产返回值的 `converged` 标记本身不保证通过外层全部硬约束。
该差异在两个 Actions 批次中复现。

**130 MeV、rho=0.75：**首轮独立 `solve_multi` 选中 `P=18.174705299 fm^-4` 的根，
SeedContinuation/生产式/半步长为 `21.667231076 fm^-4`；完整重跑时独立 `solve_multi`
也选中后者。两个提交间数值实现相同，修改为依赖预热和汇总；该反例说明现有分支选择还存在
跨运行敏感性。每个进程内三次结果均稳定，当前证据尚未区分库/runner 环境和残差舍入顺序的贡献。

代码层可见的机制是：外层按压力选择，内层 `_solve_constraint_fixedasymrho` 每次也遍历
catalog，并按最小残差只返回一个根。已收敛高压力根可能在抵达外层选择器前被舍弃；
增加 previous seed 也可能改变各内层赢家。先保留全部合格根、随后统一压力选择，是有价值的
后续验证方向；本次未改变这条生产语义。

### T=120 MeV 的一阶相变背景

T=120 MeV 位于本项目关注的一阶相变温区。分支并存、亚稳延拓和跨相跳转需要保留，
不能把所有路径依赖都归为求解失败。这里发现的实现问题更具体：内层残差排序可能使
外层选择器看不到已经求得的其它合格根，因而未完整执行约定的候选选择。

本 pilot 沿用现有最大压力策略作算法对照。在固定密度与味道约束下，不同根的化学势不同，
压力排序本身不足以判定物理平衡态；均匀候选应同时检查 Helmholtz 自由能密度
`f = -P + sum(mu_i * n_i)`，相共存还涉及全局自由能的凸化与守恒约束。
例如已有 T=120、rho/rho0=0.35 两根的 `(mu_u, mu_d)` 分别约为 `(291, 299)` 与
`(520, 530) MeV`，由约束密度算得 `f` 约为 `-21.3862` 与 `-17.6886 fm^-4`。
此处较高压力根也有较低的均匀态自由能，但两根并非同化学势下的等压共存对。
进一步将已存状态代入当前质量公式，两个 anchor 的 `(m_u, m_s)` 约为 `(338, 536)` 与
`(638, 352) MeV`；后一数值根被现有质量层级条件排除。T=130 对应为 `(299, 520)` 与
`(620, 321) MeV`，也有同样问题。因此目前这组数值双根并不能作为两条物理共存分支的证据。
这些数值仅描述当前 `8 x 4` 离散方程；下一阶段同时记录各根的化学势、自由能和分支，
在相同候选选择规则下评价算法，而不预设分支一定连续或用插值消除相变跳转。

生产式 parity 覆盖 downstream 介子步骤成功时的 equilibrium 序列。未运行介子谱或密度，
也未模拟介子步骤失败时生产脚本保留旧 seed 的分支。
