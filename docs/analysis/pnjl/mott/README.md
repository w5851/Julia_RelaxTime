# PNJL Mott and Complex-Pole Evidence

本目录收纳 PNJL 中各向异性参数 `xi`、Mott 温度、介子质量/宽度、复极点机制和文献定位相关的独立分析材料。它属于 PNJL 域，但不属于 Issue #130 的 C1/C2、CEP/Maxwell 或 phase-reference 决策线。

## Reading order

1. [`xi_dependence_analysis.md`](xi_dependence_analysis.md)：扫描结果、Mott 温度趋势和辅助图集入口。
2. [`causal_chain_analysis.md`](causal_chain_analysis.md)：从分布函数到 Mott 温度的四层因果链。
3. [`complex_pole_mechanism.md`](complex_pole_mechanism.md)：Mott 后复极点质量/宽度耦合的机制说明。
4. [`literature_positioning.md`](literature_positioning.md)：与现有文献和模型路线的定位。
5. [`background/`](background/) 与 [`supporting/`](supporting/)：背景解释和补充讨论，不与核心分析文档并列为新的 verdict。
6. [`figures/`](figures/)：辅助图和可追溯的派生表；图像不单独构成 production 或 external-validation 结论。
