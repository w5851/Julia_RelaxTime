historical implementations. It is not a runtime input directory.

  trees previously staged under `D:\Desktop\legacy`.

[`legacy_extraction_v1/cleanup_execution_v1.md`](legacy_extraction_v1/cleanup_execution_v1.md)

why early include-driven projects, unmanifested outputs, and experimental
