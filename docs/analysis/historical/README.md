# Historical Analysis Records

This namespace contains cross-domain historical audits that are retained for provenance and reuse decisions, not as current numerical evidence:

- `legacy/`: audits of old Fortran/Julia projects and historical workflow ideas.

The records are intentionally separate from the current PNJL and relaxation-time evidence packages. They document what was reviewed and why old code or outputs were not promoted; they do not authorize reusing legacy implementations.
