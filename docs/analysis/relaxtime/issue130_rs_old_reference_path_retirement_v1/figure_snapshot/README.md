# RS `prod_v1` legacy figure snapshot metadata

This companion metadata directory documents the versioned Issue #130 RS
figure snapshot.  The PNG bytes and each `plot_manifest.json` remain under
`data/outputs/figures/relaxtime/transport/phase_guided/legacy_prod_v1_snapshot_v1/`
without occupying the canonical mode roots; this directory is kept under
`docs/analysis/` because the figure-output path guard permits only figure
assets and `plot_manifest.json` in `data/outputs/figures/`.

- current canonical figures remain under the corresponding mode's `prod_v2`
  directory;
- result snapshots are paired under the result tree with the same snapshot
  version;
- `RETIREMENT_MANIFEST.json` records source/snapshot paths and hashes;
- physical deletion is not authorized by this migration.
