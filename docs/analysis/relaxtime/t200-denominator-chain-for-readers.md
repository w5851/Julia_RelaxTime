# T200 异常链路读图说明（零基础版）

## 1) 这份说明要回答什么

- 我们要解释：为什么在 `T=200` 的正窗口里，`tau_u` 会出现“先变小、再变大”。
- 用到两张同结构图：
  1. `docs/analysis/relaxtime/tauu_pos_uubarddbar_uubar_to_ddbar_denominator_chain.png`
  2. `docs/analysis/relaxtime/tauu_pos_uubaruubar_uubar_to_uubar_denominator_chain.png`
- 读图目标：把“分母变化”如何一路传导到 `tau` 讲成一条连续链路。

## 2) 先记住一条最短因果链

- `tau = 1 / tauinv`。
- `tauinv` 由各散射通道贡献相加而来；通道贡献又由该通道的 `rate` 决定。
- 所以：
  - 通道 `rate` 上升 -> `tauinv` 上升 -> `tau` 下降；
  - 通道 `rate` 下降 -> `tauinv` 下降 -> `tau` 上升。

## 3) 四层图各看什么

- 第 1 层（第一幅子图，full）：
  - 看分母核的全尺度变化：`den_re/den_im` 与 `detM_re/detM_im` 随 `Δs` 的走势。
  - 重点不是某一个点，而是“整条曲线的方向和拐点”。
- 第 2 层（第二幅子图，near 0）：
  - 专门放大接近 0 的区域，判断是否出现“靠近零/远离零/符号翻转”。
  - 这一步决定局部放大是否会被触发。
- 第 3 层（第三幅子图，propagator magnitude）：
  - 看上一步如何映射成传播子强弱：`inv|den|^2`、`inv|detM|^2`、`|D_total|^2`。
  - 一般来说，分母模长越小，传播子量级越大。
- 第 4 层（第四幅子图，band bins）：
  - 看每个 `Δs` 带上的 `omega_sigma` 和 `rate_bin`。
  - 这里决定“总方向”：哪些带在拉高、哪些带在拉低，最后谁占上风。

## 4) 为什么这两张图足以解释异常

- 结论不是“只看分母就够了”，而是：
  1. 分母复轨迹（`Re/Im` 随 `Δs`）给出局部增强触发条件；
  2. 传播子层把这种触发变成可见的量级变化；
  3. 带宽加权层把不同 `Δs` 带的增减合成为最终 `rate` 方向；
  4. 最终通过 `tau = 1/tauinv` 映射为 `tau` 的“先降后升”。
- 因此，这两张图已经形成了完整可审计闭环：
  - **分母层 -> 传播子层 -> 截面/rate层 -> tau层**。

## 5) 面向“接近零知识”读者的直观比喻

- 把 `Δs` 想成很多条“车道”，每条车道对总车流（`rate`）有不同贡献。
- 分母接近 0 类似“局部放大器”，会把某些车道的信号放大。
- 但总车流不是看单车道，而是所有车道加权后的和。
- 所以会出现：
  - 某些局部看起来在增强，
  - 但总和可能先增后减，或者先减后增。
- 这正是图里“局部核变化”与“全带宽结果”看起来不总是同方向的原因。

## 6) 这次我们认可的核心表述

- 推荐统一口径：
  - “T200 正窗口异常可由分母复轨迹随 `Δs` 的演化触发，并由全带宽 `omega_sigma_bin/rate_bin` 重分配完成方向判定。”
- 这句话同时覆盖：
  1. 你的重点（分母 `Re/Im` 趋势是关键解释入口）；
  2. 审计要求（最终必须落到可积、可加权的 `rate` 证据）。

## 7) 下一步研究接口（你提出的 `detM_im` 问题）

- 你下一步要研究：“`detM` 虚部为何会随 `Δs` 出现先减后增”。
- 基于当前图，建议把问题拆成三层可检验子问题：
  1. `Π` 的虚部组成项中，哪一项在该 `Δs` 区间改变量最大；
  2. 耦合组合进入 `detM` 时，是否存在项间抵消从“增强”切换到“减弱”；
  3. 该拐点是否与 band 主导权从近阈值带转向中高 `Δs` 带同步。
- 这样做可以把“图上拐点”直接连接到“公式项来源”。
