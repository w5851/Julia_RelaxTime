# `Models.build_default_rho_grid`

`Models.build_default_rho_grid` 是 scan 主题中的公开辅助入口。它不执行扫描，但负责提供 T-ρ 扫描默认使用的多分辨率密度网格。

## 定位

适合以下场景：

- 你希望重用仓库默认的 `ρ` 采样策略
- 你需要在 phase 产线前先检查默认低密度加密是否足够
- 你要做局部调参，但不想从零手写整套 `rho_values`

不适合的场景：

- 只想执行一次常规 T-ρ 扫描，此时通常直接调用 `Models.run_trho_scan` 即可

## 默认分段策略

当前实现通过四段分辨率叠加后去重排序，形成最终网格：

- 粗网格：`Δρ=0.05`，覆盖全区间
- 中网格：`Δρ=0.02`，覆盖 `ρ<=1.0`
- 细网格：`Δρ=0.01`，覆盖 `ρ<=0.3`
- 超细网格：`Δρ=0.005`，覆盖 `ρ<=0.15`

默认参数有三个目的：

- 在全区间保持可接受的成本
- 在低密度与相结构敏感区给出更高分辨率
- 为相图与 Maxwell 链路提供较稳的默认采样起点

## 为什么它值得作为公开导出说明

如果只把它当作 `DEFAULT_RHO_VALUES` 的内部实现细节，调用方很容易做两件不好的事：

- 在脚本里重复维护另一套经验网格，导致口径漂移
- 不理解默认多分辨率策略的重要性，直接退回过粗均匀网格

因此它虽然不是首页首屏主入口，但仍应被主题文档显式吸收。

## 与下游主题的关系

- 它直接服务于 [TrhoScan.md](TrhoScan.md)
- 它定义了 standard 扫描模板默认采用的多分辨率 `ρ` 采样
- 它生成的 `ρ` 网格会影响 [../phase/Algorithms.md](../phase/Algorithms.md) 中的 phase 产线质量

## 何时不要直接用默认网格

以下场景通常需要在默认网格基础上再做局部加密，而不是完全推翻它：

- Maxwell 失败集中在某一窄温度区间
- 低密度端 `|Δμ/Δρ|` 接近 0，怀疑 S 形分辨率不足
- CEP 附近需要更高的 `ρ` 分辨率做 direct / interpolate 对照
