# derived_reference_v1

A uniform xi grid with step 0.00625 is produced by local linear interpolation over adjacent strict slices and their common axis support. No extrapolation across absent support is performed. All non-native rows are `interpolated_noncertified`; CEP brackets remain intervals and midpoint values are boundary estimates.
