# mixed_window_globalmin_xi-0p3_muB0_merged

Merged temporary experiment outputs for eta/eta_prime window diagnostics.

## Scope
- xi = -0.3
- muB = 0
- T window = 220..280 MeV

## Sources
- mixed_window_globalmin_xi-0p3_muB0
- mixed_window_globalmin_xi-0p3_muB0_next2

## Files
- window_eta_etap.csv: merged pointwise outputs (Gamma/mass, residual, selected method)
- window_jump_summary.csv: jump-count summary under jump-threshold=0.25
- fig_gamma/, fig_mass/: copied figures with source-prefix in filenames

## Purpose
This dataset compares optimizer-dependent jump behavior for eta/eta_prime curves and supports follow-up method selection.
