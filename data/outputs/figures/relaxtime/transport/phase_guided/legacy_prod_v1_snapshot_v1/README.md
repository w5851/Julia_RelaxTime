# RS `prod_v1` legacy figure snapshot

This versioned directory preserves the superseded Issue #130 RS figures
without occupying the canonical mode roots.  The PNG bytes and each
`plot_manifest.json` are unchanged; the snapshot is for explicit legacy
comparison, rollback display, and historical reproduction only.

- current canonical figures remain under the corresponding mode's `prod_v2`
  directory;
- result snapshots are paired under the result tree with the same snapshot
  version;
- `RETIREMENT_MANIFEST.json` records source/snapshot paths and hashes;
- physical deletion is not authorized by this migration.
